# 第 7 章　处理按钮与链接

*Chapter 7: Handling Buttons and Links*

我们的浏览器仍然缺少超文本（hypertext）的关键要素：通过超链接（hyperlink）连接在一起的文档。它让我们能「看浪」，却不能让我们「冲浪」——可以观看网页，却无法在网页之间遨游。所以在本章中，我们将实现超链接、地址栏（address bar）以及浏览器界面的其余部分——也就是浏览器中决定我们正在查看哪个页面的那一部分。

## 7.1 链接在哪里？

Web 的核心就是链接（link），所以浏览器界面中最重要的部分就是点击链接。但在真正实现点击链接之前，我们先要回答一个更根本的问题：链接在屏幕上的什么位置？段落和标题的大小与位置都已经记录在布局树（layout tree）中，但格式化文本（比如链接）的大小和位置并没有。我们需要解决这个问题。

核心思路是引入两种新类型的布局对象（layout object）：LineLayout 和 TextLayout。现在，一个 BlockLayout 会为每一行文本生成一个 LineLayout 子对象，而每个 LineLayout 又会为该行中的每个单词包含一个 TextLayout。这些新类可能让布局树看起来与 HTML 树不同。为了避免意外，我们来看一个简单的例子：

```html
<html>
    <body>
    Here is some text that is
    <br>
    spread across multiple lines
    </body>
</html>
```

body 元素中的文本（因为 br 元素的缘故）折成了两行，所以布局树会具有如下结构：

```text
DocumentLayout
    BlockLayout[block] (html 元素)
    BlockLayout[inline] (body 元素)
        LineLayout (第一行文本)
        TextLayout ("Here")
        TextLayout ("is")
        TextLayout ("some")
        TextLayout ("text")
        TextLayout ("that")
        TextLayout ("is")
        LineLayout (第二行文本)
        TextLayout ("spread")
        TextLayout ("across")
        TextLayout ("multiple")
        TextLayout ("lines")
```

注意，一个 body 元素对应于一个内含两个 LineLayout 的 BlockLayout，而两个文本节点总共变成了十个 TextLayout！

我们开始吧。定义 LineLayout 很简单：

```python
class LineLayout:
    def __init__(self, node, parent, previous):
        self.node = node
        self.parent = parent
        self.previous = previous
        self.children = []
```

TextLayout 只是要稍微麻烦一点。单个 TextLayout 引用的不是整个 HTML 节点，而是某个具体的单词。也就是说，TextLayout 需要一个额外的参数来指明是哪个单词：

```python
class TextLayout:
    def __init__(self, node, word, parent, previous):
        self.node = node
        self.word = word
        self.children = []
        self.parent = parent
        self.previous = previous
```

与其他布局模式（layout mode）一样，LineLayout 和 TextLayout 需要各自的 layout 和 paint 方法，但在编写这些方法之前，我们需要先想一想 LineLayout 和 TextLayout 对象将如何创建。这必须发生在换行（word wrapping）的过程中。

回忆一下 BlockLayout 的 word 方法中的换行（见第 3 章）是怎么工作的。该方法会更新一个 line 字段，其中保存着当前行中的所有单词：

```python
self.line.append((self.cursor_x, word, font, color))
```

到了该换到下一行的时候，word 会调用 flush，由它计算这一行以及行内每个单词的位置，并把所有单词添加到一个 display_list 字段中，该字段保存整个 inline 元素中的所有单词。有了 TextLayout 和 LineLayout，这些复杂性有很多都消失了。LineLayout 可以在自己的 layout 方法中计算自己的位置，而不再需要 display_list 字段——每个 TextLayout 都可以像普通布局对象那样绘制自己。我们开始这次重构吧。

先从向一行中添加单词开始。我们不再使用 line 字段，而是创建 TextLayout 对象并把它们添加到 LineLayout 对象中。LineLayout 是 BlockLayout 的子对象，因此当前行可以在 children 数组的末尾找到：

```python
class BlockLayout:
    def word(self, node, word):
        line = self.children[-1]
        previous_word = line.children[-1] if line.children else None
        text = TextLayout(node, word, line, previous_word)
        line.children.append(text)
```

再来想想到达行尾时会发生什么。当前的代码会调用 flush，它会做一些诸如定位文本、清空 line 字段之类的事情。我们不想做这么多——我们只想创建一个新的 LineLayout 对象。所以我们换一种方法来做这件事：

```python
class BlockLayout:
    def word(self, node, word):
        if self.cursor_x + w > self.width:
            self.new_line()
```

这个 new_line 方法只是创建一个新行并重置一些字段：

```python
class BlockLayout:
    def new_line(self):
        self.cursor_x = 0
        last_line = self.children[-1] if self.children else None
        new_line = LineLayout(self.node, self, last_line)
        self.children.append(new_line)
```

现在有很多字段我们不再使用了。来清理一下。在核心的 layout 方法中，我们不需要再初始化 display_list、cursor_y 或 line 字段，因为再也不会用到它们了。我们只需要调用 new_line 并递归即可：

```python
class BlockLayout:
    def layout(self):
        # ...
        else:
            self.new_line()
            self.recurse(self.node)
```

layout 方法本来就会递归进入其子对象进行布局，所以那部分不需要任何修改。而且，现在我们可以通过把各行的高度相加来计算一个文本段落的高度，因此这部分代码不再需要随布局模式的不同而不同：

```python
class BlockLayout:
    def layout(self):
        # ...
        self.height = sum([child.height for child in self.children])
```

你可能还会想删掉 flush 方法，因为已经没有任何地方调用它了。但先把它留一会儿——我们还需要借助它来为行对象和文本对象编写 layout 方法。

> **深入探索**
> 由同一个文本节点生成的布局对象甚至不必是连续的。例如，引用了一段波斯语引文的英文，可以在一行中间从左到右翻转成从右到左。最终文本布局对象的顺序会出人意料 [1]。此外还有竖排书写的语言 [2]……

## 7.2 行布局，再探

现在我们能创建行对象和文本对象了，但还需要对它们进行布局。先从行开始。各行垂直堆叠，并占据其父对象的全部宽度，所以 x、y 和 width 的计算方式与其他盒子相同：¹

```python
class LineLayout:
    def layout(self):
        self.width = self.parent.width
        self.x = self.parent.x
        if self.previous:
            self.y = self.previous.y + self.previous.height
        else:
            self.y = self.parent.y
        # ...
```

不过，高度的计算就不同了——这正是计算最大升部（ascent）、最大降部（descent）等值的用武之地。在动手之前，先来看看 TextLayout 的布局。

布局文本需要字体度量（font metrics）信息，所以我们先用与 BlockLayout 相同的字体构造代码来获取相关字体：

```python
class TextLayout:
    def layout(self):
        weight = self.node.style["font-weight"]
        style = self.node.style["font-style"]
        if style == "normal": style = "roman"
        size = int(float(self.node.style["font-size"][:-2]) * .75)
        self.font = get_font(size, weight, style)
```

接下来，我们需要计算单词的尺寸和 x 位置。尺寸用字体度量来计算，位置则通过把单词从左到右排开来计算。

```python
class TextLayout:
    def layout(self):
        # ...
        self.width = self.font.measure(self.word)
        if self.previous:
            space = self.previous.font.measure(" ")
            self.x = self.previous.x + space + self.previous.width
        else:
            self.x = self.parent.x
        self.height = self.font.metrics("linespace")
```

但是这里没有计算 y 位置的代码。一个单词的垂直位置取决于同一行中的其他单词，所以我们将在 LineLayout 的 layout 方法中计算这个 y 位置。²该方法会从旧的 flush 方法中「借」代码。首先，布局每个单词：

```python
class LineLayout:
    def layout(self):
        # ...
        for word in self.children:
            word.layout()
```

接下来，我们需要基于最大升部和降部来计算这一行的基线（baseline），用的基本上就是旧 flush 方法中的代码：

```python
# ...
max_ascent = max([word.font.metrics("ascent")
                for word in self.children])
baseline = self.y + 1.25 * max_ascent
for word in self.children:
    word.y = baseline - word.font.metrics("ascent")
max_descent = max([word.font.metrics("descent")
                for word in self.children])
```

注意，这段代码读取每个单词的 font 字段并写入每个单词的 y 字段。这意味着在 TextLayout 的 layout 方法中，我们需要计算 x、width、height 和 font，但不算 y——我们正是这么做的。

最后，由于每一行现在都是一个独立的布局对象，它需要有一个高度。我们根据最大升部和降部来计算它：

```python
# ...
self.height = 1.25 * (max_ascent + max_descent)
```

LineLayout 和 TextLayout 的布局就讲完了。剩下的只有绘制。LineLayout 没有什么可绘制的：

```python
class LineLayout:
    def paint(self):
        return []
```

而每个 TextLayout 会创建一条 DrawText 调用：

```python
class TextLayout:
    def paint(self):
        color = self.node.style["color"]
        return [DrawText(self.x, self.y, self.word, self.font,
                        color)]
```

现在 BlockLayout 不再需要 display_list 字段了，我们还可以删掉 BlockLayout 的 paint 方法中处理它的那部分。取而代之的是，paint_tree 直接递归其子对象并绘制它们即可。通过加入 LineLayout 和 TextLayout，我们把 BlockLayout 简化了不少，还让 block 和 inline 两种布局模式共享了更多代码。

呼——这次重构的量可不小。花点时间把一切都测一测——界面看起来应该与重构开始之前一模一样。虽然你看不见，但有一个关键的区别：页面上的每个蓝色链接现在都有关联的布局对象，以及自己的大小和位置。

> **深入探索**
> 实际上，文本渲染 [3] 比这复杂得多。字母 [4] 可以变形和重叠，用户可能想把某些字母——甚至字母的一部分——涂成别的颜色。这一切在 HTML 中都是可能的，真实浏览器也确实实现了对它们的支持。

## 7.3 点击处理

既然我们知道了链接在哪里，就可以着手实现点击它们了。在 Tk 中，点击处理的工作方式与按键处理一样：把一个事件处理器（event handler）绑定到某个事件（event）上。对点击处理来说，这个事件是 <Button-1>，按钮编号 1 指的是鼠标左键。³

```python
class Browser:
    def __init__(self):
        # ...
        self.window.bind("<Button-1>", self.click)
```

在 click 内部，我们要弄清楚用户点击的是哪个链接。幸运的是，事件处理器会收到一个事件对象（event object），它的 x 和 y 字段指明了点击发生的位置：

```python
class Browser:
    def click(self, e):
        x, y = e.x, e.y
```

这里我们得小心对待坐标系（coordinate system）。那些 x、y 坐标是相对于浏览器窗口的。由于画布（canvas）位于窗口的左上角，它们同时也是相对于画布的坐标。而我们要的是相对于网页的坐标，所以需要把滚动考虑进来：

```python
class Browser:
    def click(self, e):
        # ...
        y += self.scroll
```

更一般地说，处理点击这类事件意味着把通常的渲染管线（rendering pipeline）反过来走。正常情况下，渲染从元素走到布局对象，再到页面坐标，再到屏幕坐标；点击处理则反着走，从屏幕坐标开始，然后转换成页面坐标，依此类推。实践中这种对应关系并不完美，⁴但这是个很有价值的类比。

下一步是从页面坐标找到布局对象：⁵

```python
# ...
objs = [obj for obj in tree_to_list(self.document, [])
        if obj.x <= x < obj.x + obj.width
        and obj.y <= y < obj.y + obj.height]
```

原则上，这个列表里可能有不止一个布局对象。⁶但请记住，点击处理是绘制的逆过程。绘制时我们从前往后绘制这棵树，所以做命中测试（hit testing）时应该从最后一个元素开始：⁷

```python
# ...
if not objs: return
elt = objs[-1].node
```

这个 elt 节点是被点击的最具体的节点。对链接来说，它通常是一个文本节点。但由于我们想知道用户实际点击的 URL，就需要沿着 HTML 树向上回溯，找到链接元素：⁸

```python
# ...
while elt:
    if isinstance(elt, Text):
        pass
    elif elt.tag == "a" and "href" in elt.attributes:
        # ...
    elt = elt.parent
```

一旦找到了链接元素本身，我们就需要提取 URL 并加载它：

```python
# ...
elif elt.tag == "a" and "href" in elt.attributes:
    url = self.url.resolve(elt.attributes["href"])
    return self.load(url)
```

注意，这里的 resolve 调用要求保存当前页面的 URL：

```python
class Browser:
    def __init__(self):
        # ...
        self.url = None

    def load(self, url):
        self.url = url
        # ...
```

试一试！现在你应该可以点击链接并导航到新的网页了。

> **深入探索**
> 在移动设备上，「点击」发生在一个区域上，而不仅仅是单个点。这是因为移动设备上的「轻触」往往相当不精确，所以点击的「命中测试」应该使用区域信息而非点信息 [6]。即使用普通鼠标点击 [7]，当点击落在旋转过或缩放过的元素上时，也会出现这种情况。

## 7.4 多页面

如果你跟我一样，点击链接之后接下来尝试的就是中键点击链接、在新标签页中打开。如今每个浏览器都有标签页浏览，说实话，我们的浏览器还没有这个功能，是有点尴尬的。⁹

从根本上说，实现标签页浏览需要我们把浏览器本身与显示单个网页的标签页区分开来。例如，浏览器绘制所用的画布由所有网页共享，而布局树和显示列表（display list）则是单个页面特有的。我们需要把标签页和浏览器拆分开。

计划是这样的：Browser 类将拥有窗口和画布以及所有相关的方法，例如事件处理。它还会包含一个 Tab 对象的列表和浏览器镶边（browser chrome）。而网页本身及其相关的方法将放在一个新的 Tab 类中。首先，把你现有的 Browser 类改名为 Tab，因为到目前为止我们只处理过一个网页：

```python
class Tab:
    # ...
```

然后我们需要一个新的 Browser 类。它要保存一个标签页列表，还要记录哪一个是活动标签页：

```python
class Browser:
    def __init__(self):
        self.tabs = []
        self.active_tab = None
```

它还拥有窗口并处理所有事件：

```python
class Browser:
    def __init__(self):
        self.window = tkinter.Tk()
        self.canvas = tkinter.Canvas(
            # ...
        )
        self.canvas.pack()
        self.window.bind("<Down>", self.handle_down)
        self.window.bind("<Button-1>", self.handle_click)
```

handle_down 和 handle_click 方法需要页面特有的信息，所以这些处理器方法只是把事件转发给活动标签页：

```python
class Browser:
    def handle_down(self, e):
        self.active_tab.scrolldown()
        self.draw()

    def handle_click(self, e):
        self.active_tab.click(e.x, e.y)
        self.draw()
```

你需要微调 Tab 的 scrolldown 和 click 方法：

- scrolldown 现在不接受任何参数（而不是接受一个事件对象）；
- click 现在接受两个坐标（而不是接受一个事件对象）。

最后，Browser 的 draw 调用也会调用到活动标签页：

```python
class Browser:
    def draw(self):
        self.canvas.delete("all")
        self.active_tab.draw(self.canvas)
```

注意，清空屏幕是 Browser 的职责，而不是 Tab 的。之后我们只绘制活动标签页，这正是标签页应有的工作方式。Tab 的 draw 方法需要把画布作为参数传进来：

```python
class Tab:
    def draw(self, canvas):
        # ...
```

由于画布由 Browser 控制且事件由它处理，渲染何时发生、由哪个标签页来绘制，都由 Browser 决定。所以我们还要把 load 和 scrolldown 方法中的 draw 调用删掉。更一般地说，Browser 是「主动的」，Tab 是「被动的」：所有用户交互都从 Browser 开始，再由它酌情调用各个标签页。

Tab 与 Browser 的拆分基本完成了，经过这样的重构之后，我们需要测试。为此，我们需要创建至少一个标签页，像这样：

```python
class Browser:
    def new_tab(self, url):
        new_tab = Tab()
        new_tab.load(url)
        self.active_tab = new_tab
        self.tabs.append(new_tab)
        self.draw()
```

启动时，你现在应该创建一个带有一个标签页的 Browser：

```python
if __name__ == "__main__":
    import sys
    Browser().new_tab(URL(sys.argv[1]))
    tkinter.mainloop()
```

当然，我们还需要一种方式让用户切换标签页、创建新标签页等等。接下来就讲这个。

> **深入探索**
> 浏览器标签页最早出现在 SimulBrowse [8] 中，它是 Internet Explorer 引擎的一种自定义界面。¹⁰SimulBrowse（后来更名为 NetCaptor）还有广告拦截和隐私浏览模式。当年的广告 [9] 很值得一读！

## 7.5 浏览器镶边

真实的浏览器不只是显示网页内容——它们还有标签、图标和按钮。¹¹这些统称为浏览器的「镶边」（chrome）；¹²所有这些东西都由浏览器绘制到与页面内容相同的窗口中，而且它们需要关于整个浏览器的信息（比如所有标签页的列表），所以这必须在浏览器这一层完成，而不能放在每个标签页里。

不过，浏览器的 UI 相当复杂，所以让我们把这部分代码放进一个新的 Chrome 辅助类：

```python
class Chrome:
    def __init__(self, browser):
        self.browser = browser

class Browser:
    def __init__(self):
        # ...
        self.chrome = Chrome(self)
```

那么，我们来设计浏览器镶边吧。最终，我认为它应该有两行（见图 7.1）：

- 顶部一行是标签页名称的列表，以竖线分隔，外加一个用于新建标签页的「+」按钮；
- 下面一行是当前网页的 URL，以及一个代表浏览器后退按钮的「<」按钮。

这个设计中有很多文本，所以我们先来挑一个字体：

```python
class Chrome:
    def __init__(self, browser):
        # ...
        self.font = get_font(20, "normal", "roman")
        self.font_height = self.font.metrics("linespace")
```

由于不同的操作系统绘制字体的方式不同，我们需要根据字体度量来调整浏览器镶边的具体设计。所以后面会用到 font_height。¹³

*图 7.1　浏览器镶边的预期外观。*

利用这个字体高度，我们现在可以确定标签栏从哪里开始、到哪里结束：

```python
class Chrome:
    def __init__(self, browser):
        # ...
        self.padding = 5
        self.tabbar_top = 0
        self.tabbar_bottom = self.font_height + 2*self.padding
```

注意，我加了一些内边距（padding），免得文字贴到窗口边缘。

我们会用一些矩形来表示浏览器镶边中各个元素的尺寸。为此，一个新的 Rect 类会很方便：

```python
class Rect:
    def __init__(self, left, top, right, bottom):
        self.left = left
        self.top = top
        self.right = right
        self.bottom = bottom
```

现在，这个标签行需要包含一个新建标签页按钮和各个标签页的名称。我给新建标签页按钮加上内边距：

```python
class Chrome:
    def __init__(self, browser):
        # ...
        plus_width = self.font.measure("+") + 2*self.padding
        self.newtab_rect = Rect(
            self.padding, self.padding,
            self.padding + plus_width,
            self.padding + self.font_height)
```

然后各个标签页从新建标签页按钮结束处再过一个 padding 的地方开始。由于标签页的数量会变化，我不打算存储每个标签页的位置，而是在需要时即时计算它们的边界：

```python
class Chrome:
    def tab_rect(self, i):
        tabs_start = self.newtab_rect.right + self.padding
        tab_width = self.font.measure("Tab X") + 2*self.padding
        return Rect(
            tabs_start + tab_width * i, self.tabbar_top,
            tabs_start + tab_width * (i + 1), self.tabbar_bottom)
```

注意，我测量了文本「Tab X」，并用它作为所有标签页的宽度。这并不完全正确——在许多字体中，数字 8 比数字 1 更宽——但也足够接近了，况且无论如何，字母 X 通常和最宽的数字一样宽。

要实际绘制这个 UI，我们先让浏览器镶边绘制出一个显示列表，然后由 Browser 把它绘制到屏幕上：

我们先从绘制新建标签页按钮开始：

DrawOutline 命令绘制一个矩形边框：

```python
class DrawOutline:
    def __init__(self, rect, color, thickness):
        self.rect = rect
        self.color = color
        self.thickness = thickness

    def execute(self, scroll, canvas):
        canvas.create_rectangle(
            self.rect.left, self.rect.top - scroll,
            self.rect.right, self.rect.bottom - scroll,
            width=self.thickness,
            outline=self.color)
```

接下来是绘制各个标签页。Python 的 enumerate 函数让你可以同时迭代数组的索引和内容。对每个标签页，我们需要在左右两侧各创建一条边框，然后绘制标签页的名称：

```python
class Chrome:
    def paint(self):
        # ...
        for i, tab in enumerate(self.browser.tabs):
            bounds = self.tab_rect(i)
            cmds.append(DrawLine(
                bounds.left, 0, bounds.left, bounds.bottom,
                "black", 1))
            cmds.append(DrawLine(
                bounds.right, 0, bounds.right, bounds.bottom,
                "black", 1))
            cmds.append(DrawText(
                bounds.left + self.padding, bounds.top + self.padding,
                "Tab {}".format(i), self.font, "black"))
```

最后，为了标识出哪个是活动标签页，我们要做出那种当前标签页向上翘起的文件夹形状：

```python
class Chrome:
    def paint(self):
        for i, tab in enumerate(self.browser.tabs):
            # ...
            if tab == self.browser.active_tab:
                cmds.append(DrawLine(
                    0, bounds.bottom, bounds.left, bounds.bottom,
                    "black", 1))
                cmds.append(DrawLine(
                    bounds.right, bounds.bottom, WIDTH, bounds.bottom,
                    "black", 1))
```

DrawLine 命令绘制一条给定颜色和粗细的直线。它的定义如下：

```python
class DrawLine:
    def __init__(self, x1, y1, x2, y2, color, thickness):
        self.rect = Rect(x1, y1, x2, y2)
        self.color = color
        self.thickness = thickness

    def execute(self, scroll, canvas):
        canvas.create_line(
            self.rect.left, self.rect.top - scroll,
            self.rect.right, self.rect.bottom - scroll,
            fill=self.color, width=self.thickness)
```

最后一件事：我们要确保浏览器镶边总是绘制在页面内容之上。为了做到这一点，我们可以在镶边背后绘制一个白色矩形：

```python
class Chrome:

    def paint(self):

            Rect(0, 0, WIDTH, self.bottom),
            "white"))
        cmds.append(DrawLine(
            0, self.bottom, WIDTH,
            self.bottom, "black", 1))
        # ...
```

务必确保背景在镶边的其他任何部分之前绘制。我还在镶边底部加了一条线，把镶边与页面分隔开。另外注意，我把 DrawRect 改成了传入一个 Rect，而不是四个角点；这需要改动 BlockLayout：

```python
class BlockLayout:
    def self_rect(self):
```

```python
    def paint(self):
```

也给 DrawText 和 DrawLine 加上一个 rect 字段。

现在，绘制这个镶边显示列表就很简单了：

不过，考虑到浏览器镶边占用了一些垂直空间，我们还得对标签页的绘制做一些调整。让我们给 Tabs 加一个 tab_height 参数：

```python

        # ...
        self.tab_height = tab_height
```

我们可以在 new_tab 中传入它：

```python

        new_tab = Tab(HEIGHT - self.chrome.bottom)
        # ...
```

然后我们可以调整 scrolldown，以反映页面内容的高度现在变成了 tab_height：

```python
class Tab:
    def scrolldown(self):
        max_y = max(
            self.document.height + 2*VSTEP - self.tab_height, 0)
        self.scroll = min(self.scroll + SCROLL_STEP, max_y)
```

最后，在 Tab 的 draw 方法中，我们需要把绘制命令向下移动镶边的高度。我把镶边高度作为一个 offset 参数传进来：

```python
class Tab:
    def draw(self, canvas, offset):
        for cmd in self.display_list:
            if cmd.rect.top > self.scroll + self.tab_height:
                continue
            if cmd.rect.bottom < self.scroll: continue
            cmd.execute(self.scroll - offset, canvas)
```

Browser 最终的 draw 方法现在长这样：

```python
class Browser:
    def draw(self):

        self.active_tab.draw(self.canvas, self.chrome.bottom)
        for cmd in self.chrome.paint():
            cmd.execute(0, self.canvas)
```

还有一件事：通过点击标签页来切换。点击由 Browser 处理，现在需要把落在浏览器镶边上的点击委托给 Chrome 对象：

```python

            self.active_tab.click(e.x, tab_y)
```

注意，点击标签页内容时需要把镶边的高度减掉。至于落在浏览器镶边上的点击，我们需要在 Chrome 内部弄清用户点到了什么。为了简化这个工作，我们来给 Rect 加一个便捷方法，测试某个点是否包含在矩形内：

```python
class Rect:
    def containsPoint(self, x, y):
        return x >= self.left and x < self.right \
            and y >= self.top and y < self.bottom
```

我们用这个方法处理 Chrome 内部的点击，再用它来区分点击是要新建标签页，还是要选择一个已打开的标签页。

```python
class Chrome:
    def click(self, x, y):
        if self.newtab_rect.containsPoint(x, y):
            self.browser.new_tab(URL("https://browser.engineering/"))
        else:
            for i, tab in enumerate(self.browser.tabs):
                if self.tab_rect(i).containsPoint(x, y):
                    self.browser.active_tab = tab
                    break
```

作为「新标签页」页面的默认网址，这个再合适不过了，你说呢？总之，你现在应该可以加载多个标签页，独立地在其中滚动和点击，并通过点击标签页来切换了。

## 7.6 导航历史

现在我们随时都在页面之间导航，很容易有点晕头转向，忘记自己正在看的是哪个网页。一个显示当前 URL 的地址栏会大有帮助。我们在镶边里为它腾出位置：

```python
class Chrome:
    def __init__(self, browser):
        # ...
        self.urlbar_top = self.tabbar_bottom
        self.urlbar_bottom = self.urlbar_top + \
            self.font_height + 2*self.padding
        self.bottom = self.urlbar_bottom
```

这个「URL 栏」将包含后退按钮和地址栏：

```python
class Chrome:
    def __init__(self, browser):
        # ...
        back_width = self.font.measure("<") + 2*self.padding
        self.back_rect = Rect(
            self.padding,
            self.urlbar_top + self.padding,
            self.padding + back_width,
            self.urlbar_bottom - self.padding)
        self.address_rect = Rect(
            self.back_rect.top + self.padding,
            self.urlbar_top + self.padding,
            WIDTH - self.padding,
            self.urlbar_bottom - self.padding)
```

绘制后退按钮很简单：

```python
class Chrome:
    def paint(self):
        # ...
        cmds.append(DrawOutline(self.back_rect, "black", 1))
        cmds.append(DrawText(
            self.back_rect.left + self.padding,
            self.back_rect.top,
            "<", self.font, "black"))
```

地址栏需要从浏览器那里获取当前标签页的 URL：

```python
class Chrome:
    def paint(self):
        # ...
        cmds.append(DrawOutline(self.address_rect, "black", 1))
        url = str(self.browser.active_tab.url)
        cmds.append(DrawText(
            self.address_rect.left + self.padding,
            self.address_rect.top,
            url, self.font, "black"))
```

这里，str 是一个 Python 内置函数，我们可以重写（override）它，以便把 URL 对象正确地转换成字符串：

```python
class URL:
    def __str__(self):
        port_part = ":" + str(self.port)
        if self.scheme == "https" and self.port == 443:
            port_part = ""
        if self.scheme == "http" and self.port == 80:
            port_part = ""
        return self.scheme + "://" + self.host + port_part + self.path
```

我觉得，这点用来隐藏端口号的额外逻辑是值得的，它能让 URL 更整洁。

点击后退按钮时应该发生什么？嗯，那个标签页应该后退。其他标签页不受影响。所以 Browser 必须在当前标签页上调用某个方法来后退：

```python
class Chrome:
    def click(self, x, y):
        # ...
        elif self.back_rect.containsPoint(x, y):
            self.browser.active_tab.go_back()
```

要让活动标签页能够「后退」，它需要保存一份「历史」，记录它之前访问过哪些页面：

```python
class Tab:
    def __init__(self, tab_height):
        # ...
        self.history = []
```

每次访问新页面，历史都会增长：

```python
class Tab:
    def load(self, url):
        self.history.append(url)
        # ...
```

后退要使用这份历史。你可能会想这样写：

```python
class Tab:
    def go_back(self):
        if len(self.history) > 1:
            self.load(self.history[-2])
```

这几乎是对的，但如果你连点两次后退按钮，它就不工作了，因为 load 会向历史追加条目。相反，我们需要做的更像是这样：

```python
class Tab:
    def go_back(self):
        if len(self.history) > 1:
            self.history.pop()
            back = self.history.pop()
            self.load(back)
```

现在，后退会缩短历史，点击链接会增长历史，正如所愿。

至此，我们有了一个相当好用的、可以用来阅读本书的网页浏览器：你可以点击链接、四处浏览，甚至可以同时打开多个章节进行交叉引用。但是，要访问一个没有从当前页面链接过去的网站，还是有点难。

> **深入探索**
> 浏览器的导航历史（navigation history）可能包含用户喜欢访问哪些网站的敏感信息，所以保证它的安全非常重要。出人意料的是，这相当困难，因为像 :visited 选择器 [13] 这样的 CSS 特性可以用来检测 [14] 某个 URL 此前是否被访问过。出于这个原因，业界一直在努力 [15] 限制 :visited。

## 7.7 编辑 URL

跳转到另一个页面的方法之一是点击链接。但大多数浏览器还允许你在地址栏中输入，以访问一个新 URL——如果你恰好知道这个 URL 的话。

花点时间留意一下在地址栏中输入内容的那套复杂流程（见图 7.2）：

- 首先，你必须点击地址栏来「聚焦」（focus）它；
- 这同时会选中整个地址，这样一旦你开始输入，旧地址就会被整个删掉；
- 然后，你输入的字母进入地址栏；
- 地址栏随你的输入而更新，但浏览器还不会导航到新页面；
- 最后，你按下「Enter」键，浏览器这才导航到新页面。

*图 7.2　在 Apple Safari 16.6 中编辑地址栏的截图。*

这些步骤表明，浏览器是把地址栏的内容与 url 字段分开存储的，而且还存在某种状态，用来表示你当前是否正在地址栏中输入。我们把内容称为 address_bar，把状态称为 focus：

```python
class Chrome:
    def __init__(self, browser):
        # ...
        self.focus = None
        self.address_bar = ""
```

点击地址栏应当设置 focus，点击地址栏之外则应当清除 focus：

```python
class Chrome:
    def click(self, x, y):
        self.focus = None
        # ...
        elif self.address_rect.containsPoint(x, y):
            self.focus = "address bar"
            self.address_bar = ""
```

注意，点击地址栏还会清空地址栏的内容。这并不完全是真实浏览器的做法，但也相当接近了，而且能让我们省去实现文本选择的麻烦。

现在，绘制地址栏时，我们需要检查该绘制当前 URL，还是当前已输入的文本：

```python
class Chrome:
    def paint(self):
        # ...
        if self.focus == "address bar":
            cmds.append(DrawText(
                self.address_rect.left + self.padding,
                self.address_rect.top,
                self.address_bar, self.font, "black"))
        else:
            url = str(self.browser.active_tab.url)
            cmds.append(DrawText(
                self.address_rect.left + self.padding,
                self.address_rect.top,
                url, self.font, "black"))
```

当用户正在地址栏中输入时，我们还要绘制一个光标。把状态（比如 focus）在屏幕上呈现出来（比如用光标），能让软件更易于使用：

```python
class Chrome:
    def paint(self):
        # ...
        if self.focus == "address bar":
            # ...
            w = self.font.measure(self.address_bar)
            cmds.append(DrawLine(
                self.address_rect.left + self.padding + w,
                self.address_rect.top,
                self.address_rect.left + self.padding + w,
                self.address_rect.bottom,
                "red", 1))
```

接下来，当地址栏处于焦点状态时，我们需要支持在其中输入 URL。在 Tk 中，你可以绑定 <Key> 来捕获所有按键。事件对象的 char 字段包含用户输入的字符。

```python
class Browser:
    def __init__(self):
        # ...
        self.window.bind("<Key>", self.handle_key)

    def handle_key(self, e):
        if len(e.char) == 0: return
        if not (0x20 <= ord(e.char) < 0x7f): return
        self.chrome.keypress(e.char)
        self.draw()
```

这个 handle_key 处理器以一些条件判断开始：<Key> 对每次按键都会触发，而不只是普通字母，所以我们要忽略没有字符输入的情况（按下的是修饰键），以及字符超出 ASCII 范围的情况（那可能是方向键或功能键）。目前，我们先让 Browser 把所有按键都发给 Chrome，然后调用 draw()，好让新输入的字母真正显示出来。然后 Chrome 可以检查 focus，并把字符追加到 address_bar 上：

```python
class Chrome:
    def keypress(self, char):
        if self.focus == "address bar":
            self.address_bar += char
```

最后，一旦新 URL 输入完毕，我们还需要处理「Enter」键——Tk 把它称为 <Return>——并真正让浏览器前往新地址：

```python
class Chrome:
    def enter(self):
        if self.focus == "address bar":
            self.browser.active_tab.load(URL(self.address_bar))
            self.focus = None

class Browser:
    def __init__(self):
        # ...
        self.window.bind("<Return>", self.handle_enter)

    def handle_enter(self, e):
        self.chrome.enter()
        self.draw()
```

## 7.10 练习

**7.1　退格键。** 为在地址栏中输入时的退格键（backspace）添加支持。说实话，做这道题纯粹是为了让你自己不抓狂。

**7.2　中键点击。** 为中键点击链接（Button-2）以在新标签页中打开添加支持。测试时你可能得用一只鼠标。

**7.3　窗口标题。** 浏览器会把窗口标题设置为当前标签页 <title> 元素的内容。让你的浏览器也这样做。（你可以调用 Browser.window 的 title 方法来修改窗口标题。）

**7.4　前进。** 添加一个前进按钮，它应当能撤销后退按钮的操作。如果最近的一次导航操作不是点击后退按钮，前进按钮就不应该做任何事情。¹⁴在这种情况下把它画成灰色，免得用户一直纳闷它为什么不工作。同样，如果没有可以后退的地方，也把后退按钮画成灰色。

**7.5　片段。** URL 可以包含一个片段（fragment），它位于 URL 的末尾，通过井号 # 与路径分隔。当浏览器导航到一个带片段的 URL 时，它应当滚动页面，使具有该标识符的元素出现在屏幕顶部。此外，实现片段链接：以 # 开头的相对 URL 不加载新页面，而是把具有该标识符的元素滚动到屏幕顶部。本章网页版的目录 [19] 使用的就是片段链接。

**7.6　搜索。** 如果用户在地址栏中输入的内容不是 URL，就让你的浏览器自动用搜索引擎搜索它。这通常意味着访问一个特殊的 URL。例如，你可以访问 https://google.com/search?q=QUERY 来搜索 Google，其中 QUERY 是把搜索查询中的每个空格都替换成 + 号得到的。¹⁵

**7.7　已访问链接。** 在真实浏览器中，你以前访问过的链接通常是紫色的。实现这个特性。你需要存储已访问 URL 的集合，为相应的 HTML 元素加上标注，并在绘制文本时检查这些标注。¹⁶

**7.8　书签。** 实现基本的书签功能。在浏览器镶边中加一个按钮；点击它应当收藏当前页面。当你正在查看一个已收藏的页面时，那个书签按钮应当看起来不一样（也许是黄色？），以提醒用户该页面已收藏，而此时点击它应当取消收藏。添加一个特殊网页 about:bookmarks，用于查看书签列表。

**7.9　光标。** 让左右方向键在地址栏获得焦点时移动地址栏中的文本光标。按下退格键应当删除光标前的字符，输入其他按键则应当在光标处添加字符。（记住，光标可以位于第一个字符之前，也可以位于最后一个字符之后！）

**7.10　多窗口。** 在标签页之外，再添加对多个浏览器窗口的支持。这需要跟踪多个 Tk 窗口和画布，并按所属窗口对标签页分组。你还需要某种创建新窗口的方式，也许可以借助一个按键组合，比如 Ctrl+N。

**7.11　经由显示列表处理点击。** 目前，我们的浏览器把点击位置转换成页面坐标，然后找到位于这些坐标处的布局对象。但你也可以先找出位于该位置的绘制命令，再从绘制命令找到生成它的布局对象。实现这种方式。你需要让绘制命令知道是哪个布局对象生成了它们。¹⁷
