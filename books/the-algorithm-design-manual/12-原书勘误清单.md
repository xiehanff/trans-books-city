# 原书勘误清单

## 版本与页码

本清单对应《算法设计指南（第 2 版）》清华大学出版社 2017 年 7 月第 1 版、第 1 次印刷。表中同时给出中文书印刷页码和输入 PDF 页码；正文页通常为 PDF 页码比印刷页码大 13。原作者和译者公开勘误表中的页码若与中文版不同，以本书页码/PDF 页码定位。本次将可确认且影响内容或实现的勘误应用到章节 Markdown。它不是对全书逐句、逐图穷尽的校勘；不涉及 API 时效性核查。

## 代码复评中另行修正的实现问题

以下是对代码示例的实现审查修正，与官方勘误表分开记录：

- 第 4 章整数排序比较函数改用 `qsort` 要求的 `int (const void *, const void *)` 签名，并以 `const int *` 读取元素。
- 第 5、6 章图结构定义恢复为 ASCII C 标点并放入代码围栏；`edgenode` 使用带标签的结构体以支持自引用。
- 第 6 章 Kruskal 示例改为按边数动态分配边数组，使用三向 `qsort` 比较器，并补出 `edge_pair`、`to_edge_array` 和比较器实现。
- 第 6 章 Dijkstra 实现遇到所有剩余顶点距离均为 `MAXINT` 时停止；松弛前检查加法上界，避免不可达顶点参与运算或整数溢出。
- 第 6 章 Dijkstra 伪代码补充 `parent` 初始化和前驱更新，并说明伪代码在目标顶点确定后停止，而 C 实现继续计算所有顶点的距离。
- 第 6 章网络流示例改用单独的 `flow_graph`/`flow_edgenode` 类型和 `flow_bfs`；该搜索只沿残量为正的边扩展，保存实际前驱边，并通过互指的 `reverse` 更新正向边和反向边的流量与残量。`add_residual_edges` 由输入图构造层提供，正文注明初始化与配对契约；`netflow`、`augment_path` 明确声明为 `void`。
- 第 9 章编辑距离归约补上重复值处理：将输入元素标记为 `(数值, 原下标)`，按数值升序、同值下标降序排列，使公共子序列与严格 LIS 对应。

## 扫描插图勘误记录

下列勘误针对扫描版中的插图；交付 Markdown 没有重绘原书插图，因此只在此记录，不改章节正文：

- 第 5 章图 5.14，印刷页 166（PDF 179）：图中的上行跨越边只应属于 BFS 示意，不应画成 DFS 边。
- 第 6 章图 6.13，印刷页 204（PDF 217）：残量图中标注权值 3 的中间连线应为无向线段。
