# 链表：用指针把离散节点连接起来

数组把元素放在一段连续内存中，所以可以通过下标在 `O(1)` 时间访问任意位置。但它也有两个明显限制：数组长度通常需要提前确定，在中间插入或删除元素时还要搬移后面的数据。

当数据量会变化，而且更在意插入、删除而不是随机访问时，可以把每个元素单独放在一个节点里，再用指针把节点串起来。这就是链表。

> 本篇先讲最常用的**单向链表**。对应的可编译实现和单元测试见 [`c_doc_test/`](#code/books/c-notes/code/c_doc_test/README.md)。

## 1. 链表到底解决了什么问题

单向链表的每个节点包含两部分：数据和下一个节点的地址。

```text
head
  │
  ▼
+-------+-------+    +-------+-------+    +-------+-------+
| value | next  |───▶| value | next  |───▶| value |  NULL |
+-------+-------+    +-------+-------+    +-------+-------+
```

节点不要求彼此相邻。只要 `next` 保存了下一个节点的地址，就能从头节点依次走完整条链。

链表的优势是插入、删除节点时不需要整体搬移数据；代价是不能像数组一样直接跳到第 `n` 个元素，而且每个节点都需要额外保存一个指针。

| 操作 | 数组 | 单向链表 |
|------|------|----------|
| 按下标访问 | `O(1)` | `O(n)` |
| 头部插入/删除 | 通常需要搬移，`O(n)` | `O(1)` |
| 已知节点位置后的插入/删除 | 需要搬移后续元素 | 调整几个指针即可 |
| 查找某个值 | `O(n)` | `O(n)` |

**关键认知：**链表的“快”不是所有操作都快，它只是把连续存储换成了指针跳转，适合的访问模式和数组不同。

## 2. 用结构体描述节点

结构体需要包含一个指向自身类型的指针：

```c
typedef struct ListNode {
    int value;
    struct ListNode *next;  // 1. 保存下一个节点的地址
} ListNode;
```

这里必须写 `struct ListNode *`，不能在结构体别名 `ListNode` 完成定义之前直接使用 `ListNode *`。`typedef` 在整个结构体声明结束后才生效。

创建节点时，节点本身通常放在堆上：

```c
#include <stdlib.h>

ListNode *list_node_create(int value) {
    // 1. sizeof *node 自动得到“node 指向的类型”的大小
    ListNode *node = malloc(sizeof *node);
    if (node == NULL) {
        return NULL;  // 2. 分配失败必须交给调用者处理
    }

    // 3. 新节点先初始化完整，避免留下野指针
    node->value = value;
    node->next = NULL;
    return node;
}
```

`malloc` 只分配空间，不会自动把 `value` 和 `next` 初始化为合理值。尤其是 `next`，新节点暂时没有后继节点时必须明确设置为 `NULL`。

## 3. 头指针为什么经常是二级指针

如果函数只读取链表，可以传一级指针：

```c
size_t list_length(const ListNode *head) {
    size_t length = 0;
    for (const ListNode *current = head;
         current != NULL;
         current = current->next) {
        length++;
    }
    return length;
}
```

但头插会改变 `head` 本身。C 语言只有值传递，如果写成 `list_push_front(ListNode *head, ...)`，函数里修改的只是 `head` 的副本。要让函数修改调用者的头指针，就要传 `ListNode **`：

```c
int list_push_front(ListNode **head, int value) {
    if (head == NULL) {
        return 0;
    }

    // 1. 先创建节点，失败时不改变原链表
    ListNode *node = list_node_create(value);
    if (node == NULL) {
        return 0;
    }

    // 2. 新节点接到旧头节点前面
    node->next = *head;

    // 3. 把调用者的 head 更新为新节点
    *head = node;
    return 1;
}
```

调用时传入 `&head`：

```c
ListNode *head = NULL;
if (!list_push_front(&head, 10)) {
    // 内存不足时执行错误处理
}
```

当链表为空时，`*head` 是 `NULL`，上面的代码仍然成立：新节点的 `next` 为 `NULL`，然后新节点成为头节点。

## 4. 尾插与遍历

最直观的尾插需要从头走到最后一个节点：

```c
int list_push_back(ListNode **head, int value) {
    if (head == NULL) {
        return 0;
    }

    // 1. 先创建节点，只有成功后才修改链表
    ListNode *node = list_node_create(value);
    if (node == NULL) {
        return 0;
    }

    // 2. 空链表时，新节点直接成为头节点
    if (*head == NULL) {
        *head = node;
        return 1;
    }

    // 3. 找到最后一个节点
    ListNode *current = *head;
    while (current->next != NULL) {
        current = current->next;
    }

    // 4. 把新节点接到末尾
    current->next = node;
    return 1;
}
```

遍历时不要把当前节点释放后再访问它的 `next`。如果要释放节点，应该先保存后继指针：

```c
void list_free(ListNode **head) {
    if (head == NULL) {
        return;
    }

    ListNode *current = *head;
    while (current != NULL) {
        // 1. free 之前保存下一个节点
        ListNode *next = current->next;

        // 2. 释放当前节点
        free(current);

        // 3. 继续处理下一个节点
        current = next;
    }

    // 4. 让调用者的指针回到安全状态
    *head = NULL;
}
```

这里让 `list_free` 接收二级指针，是为了释放完成后把调用者的 `head` 置为 `NULL`。释放后继续保留原地址会形成悬空指针。

## 5. 查找与删除

查找只需要沿着 `next` 逐个比较：

```c
const ListNode *list_find(const ListNode *head, int value) {
    for (const ListNode *current = head;
         current != NULL;
         current = current->next) {
        if (current->value == value) {
            return current;
        }
    }
    return NULL;
}
```

删除第一个匹配节点时，可能删除头节点，也可能删除中间节点。用普通写法需要分别处理这两种情况；用“指向链接的指针”可以统一处理：

```c
int list_remove_first(ListNode **head, int value) {
    if (head == NULL) {
        return 0;
    }

    // link 指向“保存当前节点地址的指针”
    ListNode **link = head;
    while (*link != NULL) {
        if ((*link)->value == value) {
            // 1. 暂存待删除节点
            ListNode *removed = *link;

            // 2. 让前一个链接越过 removed
            //    如果 removed 是头节点，这一步就是更新 head
            *link = removed->next;

            // 3. 链接修好后再释放节点
            free(removed);
            return 1;
        }

        // 让 link 指向当前节点的 next 成员
        link = &(*link)->next;
    }
    return 0;
}
```

`link = &(*link)->next` 是这段代码的核心。第一次循环时 `link` 等于 `head`，所以 `*link` 就是头节点；后续循环时，`link` 指向前一个节点的 `next` 成员。无论删除哪一个节点，最终都是给 `*link` 赋新的后继地址。

## 6. 原地反转链表

反转不能只交换数据，而要反转每条 `next` 链接。每次循环保存原来的后继节点，然后把当前节点指向前一个节点：

```c
void list_reverse(ListNode **head) {
    if (head == NULL) {
        return;
    }

    ListNode *previous = NULL;
    ListNode *current = *head;

    while (current != NULL) {
        // 1. 保存还没有处理的后半段
        ListNode *next = current->next;

        // 2. 当前节点改为指向前一个节点
        current->next = previous;

        // 3. 两个游标一起向后移动
        previous = current;
        current = next;
    }

    // 4. previous 是反转后的新头节点
    *head = previous;
}
```

这个过程只使用了几个指针变量，没有申请新节点，时间复杂度是 `O(n)`，额外空间复杂度是 `O(1)`。

## 7. 一个完整的使用流程

把上面的函数放入同一个 `.c` 文件后，可以这样使用：

```c
#include <stdio.h>

int main(void) {
    ListNode *head = NULL;

    // 1. 逐个构造：结果为 1 -> 2 -> 3 -> NULL
    if (!list_push_back(&head, 1) ||
        !list_push_back(&head, 2) ||
        !list_push_back(&head, 3)) {
        list_free(&head);
        return 1;
    }

    // 2. 遍历链表
    for (const ListNode *current = head;
         current != NULL;
         current = current->next) {
        printf("%d ", current->value);
    }
    putchar('\n');

    // 3. 删除第一个值为 2 的节点，再反转
    list_remove_first(&head, 2);
    list_reverse(&head);

    // 4. 程序结束前统一释放所有节点
    list_free(&head);
    return 0;
}
```

## 8. 常见错误与扩展方向

### 忘记处理空链表

任何访问 `head->value` 的代码都应该先确认 `head != NULL`。空链表是正常状态，不是异常状态。

### 释放节点后继续使用

```c
free(current);
current = current->next;  // 错误：current 已经失效
```

必须像 `list_free` 那样在 `free` 之前保存 `next`。

### 只释放头节点

```c
free(head);  // 只释放了一个节点，其余节点泄漏
```

动态链表的所有权通常由链表管理者负责。销毁链表时，要沿着链接释放每个节点，并把头指针置空。

### 何时使用其他链表

- **双向链表**：节点同时保存 `prev` 和 `next`，适合需要向前、向后移动的场景。
- **循环链表**：尾节点指回头节点，适合轮询，但遍历结束条件不再是 `NULL`。
- **带尾指针的单链表**：额外保存 `tail`，可以把尾插从 `O(n)` 降到 `O(1)`，但删除尾节点仍需找到前一个节点。

一句话总结：链表的核心不是“节点很多”，而是用节点中的指针保存结构关系，并用清晰的所有权规则管理这些节点。
