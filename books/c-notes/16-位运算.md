# 第16章 位运算与运算符补充

位运算直接操作二进制位，是系统编程、嵌入式开发、性能优化的基础技能。

## 位运算符

### 位与（&）

两个位都为 1 时，结果为 1，否则为 0。

```
  10101010
& 11110000
----------
  10100000
```

常用场景：清零、取特定位、判断奇偶。

```c
// 清零低 4 位
int x = 0xFF;
x = x & 0xF0;  // 0xF0

// 取低 4 位
int y = 0xAB;
int low = y & 0x0F;  // 0x0B

// 判断奇偶
if (x & 1) {
    printf("奇数\n");
} else {
    printf("偶数\n");
}
```

### 位或（|）

两个位有一个为 1，结果为 1，否则为 0。

```
  10101010
| 11110000
----------
  11111010
```

常用场景：置位。

```c
// 设置低 4 位为 1
int x = 0xA0;
x = x | 0x0F;  // 0xAF

// 组合标志位
#define FLAG_READ    0x01
#define FLAG_WRITE   0x02
#define FLAG_EXECUTE 0x04

int perm = FLAG_READ | FLAG_WRITE;  // 可读可写
```

### 位异或（^）

两个位相同为 0，不同为 1。

```
  10101010
^ 11110000
----------
  01011010
```

常用场景：翻转位、交换变量、简单加密。

```c
// 翻转低 4 位
int x = 0xA5;
x = x ^ 0x0F;  // 0xAA

// 不用临时变量交换两数
int a = 10, b = 20;
a = a ^ b;
b = a ^ b;  // b = (a ^ b) ^ b = a
a = a ^ b;  // a = (a ^ b) ^ a = b

// 简单加密解密
char data = 'A';
char key = 0x55;
char encrypted = data ^ key;  // 加密
char decrypted = encrypted ^ key;  // 解密，恢复为 'A'
```

### 取反（~）

单目运算符，0 变 1，1 变 0。

```
~10101010 = 01010101
```

```c
unsigned char x = 0xAA;  // 10101010
x = ~x;                   // 01010101 = 0x55
```

注意：对有符号数取反要小心，因为涉及符号位。

## 移位运算

### 左移（<<）

各位向左移动指定位数，右侧补 0，左侧高位丢弃。

```
00001010 << 2 = 00101000
```

左移 n 位相当于乘以 2ⁿ（未溢出时）。

```c
int x = 5;
x = x << 3;  // 5 * 8 = 40
```

### 右移（>>）

各位向右移动指定位数，右侧低位丢弃。左侧补什么取决于数据类型：

- 无符号数：左侧补 0（逻辑右移）
- 有符号数：取决于编译器，通常补符号位（算术右移）

```c
unsigned int a = 0x80000000;
a = a >> 1;  // 逻辑右移，结果为 0x40000000

int b = -2147483648;  // 0x80000000
b = b >> 1;           // 算术右移，结果为 -1073741824（0xC0000000）
```

右移 n 位相当于除以 2ⁿ并向下取整。

```c
int x = 17;
x = x >> 2;  // 17 / 4 = 4
```

## 位运算应用

### 掩码操作

掩码是一组位，用于选择或屏蔽特定位置的数据。

```c
#define MASK_LOW_4   0x0F
#define MASK_HIGH_4  0xF0
#define MASK_BIT_0   0x01
#define MASK_BIT_1   0x02
#define MASK_BIT_2   0x04

// 取出第 n 位
int get_bit(int x, int n) {
    return (x >> n) & 1;
}

// 设置第 n 位为 1
int set_bit(int x, int n) {
    return x | (1 << n);
}

// 清除第 n 位为 0
int clear_bit(int x, int n) {
    return x & ~(1 << n);
}

// 翻转第 n 位
int toggle_bit(int x, int n) {
    return x ^ (1 << n);
}
```

### 标志位管理

用单个整数的各个位表示多个开关状态。

```c
#include <stdio.h>

// 定义权限标志
#define PERM_READ    (1 << 0)  // 0001
#define PERM_WRITE   (1 << 1)  // 0010
#define PERM_EXECUTE (1 << 2)  // 0100
#define PERM_DELETE  (1 << 3)  // 1000

int main() {
    int permissions = 0;  // 初始无权限

    // 添加权限
    permissions |= PERM_READ | PERM_WRITE;

    // 检查权限
    if (permissions & PERM_READ) {
        printf("可读\n");
    }

    if (permissions & PERM_EXECUTE) {
        printf("可执行\n");  // 不输出
    }

    // 移除权限
    permissions &= ~PERM_WRITE;

    // 翻转权限
    permissions ^= PERM_EXECUTE;

    return 0;
}
```

### 快速计算

```c
// 乘以 2
int mul2(int x) { return x << 1; }

// 除以 2（向下取整）
int div2(int x) { return x >> 1; }

// 对 2 的幂次取模
int mod_power2(int x, int n) { return x & (n - 1); }
// 例: x % 8 等价于 x & 7

// 判断是否为 2 的幂
int is_power2(int x) { return x > 0 && (x & (x - 1)) == 0; }
```

### 颜色处理

RGB 颜色通常用 24 位存储，每 8 位一个分量。

```c
// 提取各分量
unsigned int color = 0xFF8000;  // 橙色
unsigned char r = (color >> 16) & 0xFF;  // 255
unsigned char g = (color >> 8) & 0xFF;   // 128
unsigned char b = color & 0xFF;          // 0

// 组合颜色
unsigned int new_color = (r << 16) | (g << 8) | b;
```

## 逗号运算符

逗号运算符按顺序执行多个表达式，返回最后一个表达式的值。

```c
int a = (1, 2, 3);  // a = 3

int x = 1;
int y = (x++, x * 2);  // x 先变为 2，然后 y = 4
```

实际用途主要在 for 循环中：

```c
// 同时初始化和更新多个变量
for (int i = 0, j = 10; i < j; i++, j--) {
    printf("i=%d, j=%d\n", i, j);
}
```

注意：函数参数中的逗号不是逗号运算符。

```c
func(a, b);   // 传两个参数
func((a, b)); // 传一个参数，值为 b
```

## sizeof 运算符

`sizeof` 返回数据类型或变量占用的字节数，类型为 `size_t`。

### 基本用法

```c
printf("%zu\n", sizeof(int));     // 4
printf("%zu\n", sizeof(char));    // 1
printf("%zu\n", sizeof(double));  // 8

int arr[10];
printf("%zu\n", sizeof(arr));     // 40 = 10 * 4

int x;
printf("%zu\n", sizeof x);        // 4，变量可以不加括号
printf("%zu\n", sizeof(int));     // 类型必须加括号
```

### 计算数组元素个数

```c
int arr[] = {1, 2, 3, 4, 5};
int count = sizeof(arr) / sizeof(arr[0]);  // 5
```

### 与指针

`sizeof` 对指针得到指针本身的大小，不是所指对象的大小。

```c
int arr[10];
int *p = arr;

printf("%zu\n", sizeof(arr));  // 40
printf("%zu\n", sizeof(p));    // 8（64 位系统）或 4（32 位系统）

// 函数参数中的数组退化为指针
void func(int arr[]) {
    printf("%zu\n", sizeof(arr));  // 8，是指针大小，不是数组大小
}
```

### sizeof 是编译期运算

```c
int n = 10;
int arr[n];  // VLA，变长数组

printf("%zu\n", sizeof(arr));  // 运行时计算，C99 支持
```

对于普通数组，`sizeof` 在编译期完成计算，结果可以作为常量使用：

```c
int arr[10];
enum { SIZE = sizeof(arr) };  // 合法，编译期常量
```

## 常见陷阱

### 移位越界

移位位数不能超过类型的位宽，否则是未定义行为。

```c
int x = 1;
int y = x << 32;  // 未定义行为（int 只有 32 位）
```

### 有符号数右移

有符号数的右移行为取决于编译器实现。

```c
int x = -1;
int y = x >> 1;  // 可能是 -1（算术右移）或 0x7FFFFFFF（逻辑右移）
```

建议右移操作使用无符号数。

### 运算符优先级

位运算符的优先级低于算术运算符和比较运算符。

```c
int x = 1, y = 2;
if (x & y == 0) { ... }  // 等价于 x & (y == 0)，不是 (x & y) == 0

// 正确写法
if ((x & y) == 0) { ... }
```

建议：位运算表达式始终用括号明确优先级。
