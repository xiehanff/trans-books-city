# 循环语句

循环用于重复执行某段代码，直到条件不满足为止。C语言有三种循环结构：while、do-while和for。

## while 循环

`while`先判断条件，条件为真就执行循环体，然后再判断，如此反复。

```c
int i = 0;
while (i < 5) {
    printf("%d ", i);
    i++;
}
// 输出：0 1 2 3 4
```

条件一开始为假时，循环体一次都不执行：

```c
while (0) {
    printf("这行不会执行\n");
}
```

死循环的常见写法：

```c
while (1) {
    // 无限循环，需要用break跳出
}
```

## do-while 循环

`do-while`先执行一次循环体，再判断条件。循环体至少执行一次。

```c
int i = 0;
do {
    printf("%d ", i);
    i++;
} while (i < 5);
// 输出：0 1 2 3 4
```

即使条件一开始为假，也会执行一次：

```c
int i = 10;
do {
    printf("%d\n", i);  // 输出10
} while (i < 5);        // 条件为假，退出
```

经典应用：输入验证，确保用户输入有效值。

```c
int score;
do {
    printf("请输入分数(0-100)：");
    scanf("%d", &score);
} while (score < 0 || score > 100);
```

## for 循环

`for`把初始化、条件判断、迭代操作放在一行，适合已知循环次数的场景。

```c
for (int i = 0; i < 5; i++) {
    printf("%d ", i);
}
// 输出：0 1 2 3 4
```

三个部分的作用：

- `int i = 0`：初始化，只执行一次
- `i < 5`：条件，每次循环前判断
- `i++`：迭代，每次循环体执行完后执行

三个部分都可以省略：

```c
// 省略初始化
int i = 0;
for (; i < 5; i++) {
    printf("%d ", i);
}

// 省略条件（死循环）
for (int i = 0; ; i++) {
    if (i >= 5) break;
    printf("%d ", i);
}

// 省略迭代
for (int i = 0; i < 5; ) {
    printf("%d ", i);
    i++;
}

// 全部省略（死循环）
for (;;) {
    // 等同于 while(1)
}
```

## break 与 continue

`break`用于跳出整个循环，`continue`用于跳过本次迭代，进入下一次。

**break示例**：

```c
for (int i = 0; i < 10; i++) {
    if (i == 5) {
        break;  // i=5时跳出循环
    }
    printf("%d ", i);
}
// 输出：0 1 2 3 4
```

查找场景：找到目标后立即退出。

```c
int arr[] = {3, 1, 4, 1, 5, 9, 2, 6};
int len = sizeof(arr) / sizeof(arr[0]);
int target = 5;
int index = -1;

for (int i = 0; i < len; i++) {
    if (arr[i] == target) {
        index = i;
        break;  // 找到了就退出
    }
}
```

**continue示例**：

```c
for (int i = 0; i < 10; i++) {
    if (i % 2 == 0) {
        continue;  // 跳过偶数
    }
    printf("%d ", i);
}
// 输出：1 3 5 7 9
```

过滤场景：跳过不需要处理的情况。

```c
for (int i = 0; i < 100; i++) {
    if (arr[i] < 0) {
        continue;  // 跳过负数
    }
    // 只处理非负数
    sum += arr[i];
}
```

## 循环嵌套

循环内部可以包含另一个循环，称为嵌套循环。外层每执行一次，内层执行一轮。

**打印乘法表**：

```c
for (int i = 1; i <= 9; i++) {
    for (int j = 1; j <= i; j++) {
        printf("%d*%d=%d\t", j, i, i * j);
    }
    printf("\n");
}
```

**打印矩形**：

```c
for (int i = 0; i < 3; i++) {
    for (int j = 0; j < 5; j++) {
        printf("*");
    }
    printf("\n");
}
```

输出：

```text
*****
*****
*****
```

**打印三角形**：

```c
for (int i = 0; i < 5; i++) {
    for (int j = 0; j <= i; j++) {
        printf("*");
    }
    printf("\n");
}
```

输出：

```text
*
**
***
****
*****
```

嵌套循环中的break只能跳出当前层循环。想要跳出多层，需要用标志变量或goto。

```c
int found = 0;
for (int i = 0; i < 3 && !found; i++) {
    for (int j = 0; j < 3 && !found; j++) {
        if (i * j == 4) {
            printf("找到：i=%d, j=%d\n", i, j);
            found = 1;
        }
    }
}
```

## 循环常见陷阱

**分号陷阱**：在for或while后面误加分号。

```c
for (int i = 0; i < 5; i++);  // 分号让循环体为空
{
    printf("%d ", i);  // 这段代码只执行一次，i=5
}
```

**循环变量作用域**：C99允许在for中声明变量，作用域限于循环内。

```c
for (int i = 0; i < 5; i++) {
    // i可用
}
// i不可用
```

**浮点数循环**：浮点数有精度问题，不适合作为循环变量。

```c
// 有问题的写法
for (float f = 0.0; f != 1.0; f += 0.1) {
    // f可能永远不等于1.0
}

// 正确写法：用整数循环
for (int i = 0; i <= 10; i++) {
    float f = i * 0.1;
}
```

**修改循环变量**：在循环体内修改循环变量容易出错。

```c
for (int i = 0; i < 5; i++) {
    printf("%d ", i);
    i++;  // 每次迭代i增加两次，输出0 2 4
}
```

**无限循环**：忘记更新循环变量导致死循环。

```c
int i = 0;
while (i < 5) {
    printf("%d ", i);
    // 忘记i++，死循环
}
```

**数组越界**：循环索引超出数组范围。

```c
int arr[5] = {1, 2, 3, 4, 5};
for (int i = 0; i <= 5; i++) {  // i会到5，越界
    printf("%d ", arr[i]);
}
```
