# 指针

指针是 C 语言的核心概念，也是区分 C 与其他高级语言的关键特性。理解指针，才能真正理解 C 语言如何操作内存。

## 指针的本质

程序运行时，所有数据都存储在内存中。内存以字节为单位编址，每个字节有一个唯一的编号，称为地址。

指针就是地址。指针变量是用来存储地址的变量。

```
内存示意图：

地址    值
----    ---
0x1000  42      ← int a = 42;
0x1004  0x1000  ← int *p = &a; (p 存储的是 a 的地址)
```

指针变量 itself 也占内存。32 位系统上是 4 字节，64 位系统上是 8 字节。

## 指针变量的声明与初始化

声明指针变量：

```c
int *p;       // 指向 int 类型的指针
char *s;      // 指向 char 类型的指针
double *dp;   // 指向 double 类型的指针
void *vp;     // 通用指针，可指向任意类型
```

`*` 写在类型名旁边还是变量名旁边都可以：

```c
int* p;       // 强调 p 的类型是 int*
int *p;       // 强调 *p 的类型是 int
int * p;      // 不推荐的写法
```

声明但不初始化，指针值是随机的：

```c
int *p;       // p 指向哪里？不知道
*p = 10;      // 错误！向随机地址写入数据
```

正确做法是初始化：

```c
int a = 10;
int *p = &a;  // p 指向 a

int *q = NULL;  // 暂时不指向任何地方
```

`NULL` 是空指针常量，值为 0，表示"不指向任何有效地址"。

## & 与 * 运算符

`&` 取地址运算符，获取变量的内存地址。

```c
int a = 10;
int *p = &a;  // &a 得到 a 的地址

printf("a 的值: %d\n", a);      // 10
printf("a 的地址: %p\n", &a);   // 如 0x7fff5694
printf("p 的值: %p\n", p);      // 与 &a 相同
```

`*` 解引用运算符，通过地址访问值。

```c
int a = 10;
int *p = &a;

printf("%d\n", *p);  // 10，通过 p 找到 a 的值
*p = 20;             // 通过 p 修改 a 的值
printf("%d\n", a);   // 20
```

`&` 和 `*` 互为逆运算：

```c
int a = 10;
int *p = &a;

printf("%d\n", *&a);   // 10，先取地址再解引用
printf("%p\n", &*p);   // p 的值，先解引用再取地址
```

图示：

```
变量    内存地址    内存中的值
----    --------    ----------
a       0x1000      10
p       0x1008      0x1000

表达式    结果
--------  -----
&a        0x1000
p         0x1000
*p        10
*p = 20   a 变成 20
```

## 指针与数组的关系

数组名本质上是一个指针，指向数组第一个元素。

```c
int a[5] = {10, 20, 30, 40, 50};

// 以下两种写法等价
int *p = a;
int *p = &a[0];

printf("%p\n", a);   // 数组首元素地址
printf("%p\n", &a[0]); // 同上
```

通过指针访问数组元素：

```c
int a[5] = {10, 20, 30, 40, 50};
int *p = a;

printf("%d\n", *p);       // 10，a[0]
printf("%d\n", *(p + 1)); // 20，a[1]
printf("%d\n", *(p + 2)); // 30，a[2]

// 等价写法
printf("%d\n", p[0]);  // 10
printf("%d\n", p[1]);  // 20
```

关键公式：`a[i]` 等价于 `*(a + i)`

```
数组内存布局：

索引    0    1    2    3    4
值     10   20   30   40   50
地址  ↓    ↓    ↓    ↓    ↓
      a   a+1  a+2  a+3  a+4
```

数组名与指针变量的区别：

```c
int a[5] = {1, 2, 3, 4, 5};
int *p = a;

a = p;    // 错误！数组名是常量，不能修改
p = a;    // 正确，指针变量可以重新赋值

sizeof(a); // 20，整个数组的大小
sizeof(p); // 8（64位系统），指针变量的大小
```

## 指针的算术运算

指针支持与整数的加减运算，移动的单位是指针指向类型的大小。

```c
int a[5] = {10, 20, 30, 40, 50};
int *p = a;

printf("%p\n", p);     // 如 0x1000
printf("%p\n", p + 1); // 0x1004（移动 4 字节，int 大小）
printf("%p\n", p + 2); // 0x1008

char s[] = "hello";
char *q = s;
printf("%p\n", q);     // 如 0x2000
printf("%p\n", q + 1); // 0x2001（移动 1 字节，char 大小）
```

图示：

```
int a[5] 的内存布局（假设 int 为 4 字节）：

地址      值
0x1000    10    ← p
0x1004    20    ← p + 1
0x1008    30    ← p + 2
0x100C    40    ← p + 3
0x1010    50    ← p + 4
```

指针的自增自减：

```c
int a[] = {10, 20, 30};
int *p = a;

printf("%d\n", *p++);  // 10，先取值再移动
printf("%d\n", *p);    // 20

printf("%d\n", *++p);  // 30，先移动再取值
printf("%d\n", *p);    // 30
```

两个指针相减，得到元素个数差：

```c
int a[] = {10, 20, 30, 40, 50};
int *p = a;
int *q = &a[4];

printf("%ld\n", q - p);  // 4，相隔 4 个 int 元素
```

## 指针与字符串

字符串字面量返回的是首字符地址：

```c
char *s = "hello";  // s 指向 'h' 的地址

printf("%c\n", *s);     // 'h'
printf("%c\n", s[1]);   // 'e'
printf("%s\n", s);      // "hello"
```

字符串字面量存储在只读区，不能修改：

```c
char *s = "hello";
s[0] = 'H';  // 错误！运行时崩溃
```

要修改字符串，用字符数组：

```c
char s[] = "hello";  // 在栈上分配并复制
s[0] = 'H';          // 正确
printf("%s\n", s);    // "Hello"
```

遍历字符串：

```c
char *s = "hello";

// 下标法
for (int i = 0; s[i] != '\0'; i++) {
    printf("%c\n", s[i]);
}

// 指针法
for (char *p = s; *p != '\0'; p++) {
    printf("%c\n", *p);
}
```

## 指针数组与数组指针

指针数组：元素是指针的数组。

```c
int a = 1, b = 2, c = 3;
int *arr[3] = {&a, &b, &c};  // arr 是数组，元素是 int*

printf("%d\n", *arr[0]);  // 1
printf("%d\n", *arr[1]);  // 2
```

常用场景：字符串数组：

```c
char *names[] = {
    "Alice",
    "Bob",
    "Charlie"
};

for (int i = 0; i < 3; i++) {
    printf("%s\n", names[i]);
}
```

数组指针：指向数组的指针。

```c
int a[3] = {1, 2, 3};
int (*p)[3] = &a;  // p 指向一个包含 3 个 int 的数组

printf("%d\n", (*p)[0]);  // 1
printf("%d\n", (*p)[1]);  // 2
```

区分的关键：看 `*` 和 `[]` 的优先级。

```c
int *arr[3];    // 指针数组：[] 优先级高于 *
int (*p)[3];    // 数组指针：() 让 * 先结合
```

图示：

```
指针数组：

arr[0] ──→ [地址] ──→ 值1
arr[1] ──→ [地址] ──→ 值2
arr[2] ──→ [地址] ──→ 值3

数组指针：

p ──→ [数组: 值1, 值2, 值3]
```

## 多级指针

指针本身也有地址，可以用另一个指针来存储：

```c
int a = 10;
int *p = &a;
int **pp = &p;  // pp 是指向指针的指针

printf("%d\n", a);    // 10
printf("%d\n", *p);   // 10
printf("%d\n", **pp); // 10
```

图示：

```
变量    地址      值
----    ----      --
a       0x1000    10
p       0x1008    0x1000 (指向 a)
pp      0x1010    0x1008 (指向 p)

*pp     = p       = 0x1000
**pp    = *p      = 10
```

多级指针常用于函数中修改指针参数：

```c
void allocate(int **pp, int size) {
    *pp = malloc(size * sizeof(int));
}

int *p = NULL;
allocate(&p, 10);
// 现在 p 指向分配的内存
```

## 函数指针

函数名是函数代码的入口地址。函数指针可以存储这个地址，实现间接调用。

声明函数指针：

```c
int add(int a, int b) {
    return a + b;
}

int (*fp)(int, int) = add;  // fp 指向 add 函数
```

通过函数指针调用：

```c
int result = fp(10, 20);     // 简洁写法
int result = (*fp)(10, 20);  // 显式写法
```

函数指针的用途：回调函数。

```c
// 排序时的比较函数
int compare_asc(const void *a, const void *b) {
    return *(int*)a - *(int*)b;
}

int compare_desc(const void *a, const void *b) {
    return *(int*)b - *(int*)a;
}

int arr[] = {3, 1, 4, 1, 5};
qsort(arr, 5, sizeof(int), compare_asc);   // 升序
qsort(arr, 5, sizeof(int), compare_desc);  // 降序
```

函数指针数组：

```c
int add(int a, int b) { return a + b; }
int sub(int a, int b) { return a - b; }
int mul(int a, int b) { return a * b; }

int (*ops[])(int, int) = {add, sub, mul};

int result = ops[0](10, 5);  // 15，加法
result = ops[1](10, 5);      // 5，减法
result = ops[2](10, 5);      // 50，乘法
```

## const 与指针

`const` 和指针配合有三种情况：

1. 指向常量的指针（指针可改，指向的值不可改）

```c
int a = 10;
int b = 20;
const int *p = &a;  // 或 int const *p = &a;

*p = 20;  // 错误！不能通过 p 修改值
p = &b;   // 正确，可以指向其他地址
```

2. 常量指针（指针不可改，指向的值可改）

```c
int a = 10;
int b = 20;
int * const p = &a;

*p = 20;  // 正确，可以修改值
p = &b;   // 错误！不能修改指针本身
```

3. 指向常量的常量指针（都不能改）

```c
int a = 10;
int b = 20;
const int * const p = &a;

*p = 20;  // 错误
p = &b;   // 错误
```

记忆方法：`const` 修饰谁，谁就不能改。

```c
const int *p;   // const 修饰 *p，*p 不能改
int * const p;  // const 修饰 p，p 不能改
```

## 指针常见错误

### 未初始化的指针（野指针）

```c
int *p;      // 未初始化，p 是野指针
*p = 10;     // 危险！向随机地址写入
```

正确做法：

```c
int *p = NULL;  // 初始化为空
// 使用前检查
if (p != NULL) {
    *p = 10;
}
```

### 悬空指针

指针指向的内存已释放，但指针仍然保留着那个地址：

```c
int *p = malloc(sizeof(int));
*p = 10;
free(p);    // 释放内存

*p = 20;    // 错误！访问已释放的内存

p = NULL;   // 正确做法：释放后置空
```

函数返回局部变量的指针：

```c
int* bad_func() {
    int a = 10;
    return &a;  // 错误！返回局部变量的地址
}               // 函数结束，a 被销毁

int* good_func() {
    static int a = 10;
    return &a;  // 正确，静态变量生命周期是整个程序
}
```

### 数组越界

```c
int a[5] = {1, 2, 3, 4, 5};
int *p = a;

printf("%d\n", p[5]);   // 越界访问
printf("%d\n", *(p + 5)); // 同上
```

### 指针类型不匹配

```c
int a = 0x12345678;
char *p = (char*)&a;  // 强制类型转换

printf("%x\n", *p);  // 只读取一个字节
// 小端序输出 78，大端序输出 12
```

类型不匹配可能导致数据截断或读取错误。

### 混淆指针与指针指向的值

```c
int a = 10;
int *p = &a;

if (p == 10) { }   // 错误！比较的是地址和整数
if (*p == 10) { }  // 正确，比较的是值

p = 100;           // 错误！把整数当地址赋给指针
*p = 100;          // 正确，修改 a 的值
```
