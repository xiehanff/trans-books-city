# S03 - 复杂声明解读技巧

C 语言的声明可以写得相当复杂，尤其是当指针、数组、函数这些元素组合在一起时。解读复杂声明有一套系统的方法，掌握之后就不怕看到 `void (*signal(int, void(*)(int)))(int)` 这样的代码了。

## 右左法则（顺时针/螺旋法则）

这是解读复杂声明最经典的方法，也叫"顺时针/螺旋法则"（Clockwise/Spiral Rule）。

**核心规则**：从变量名出发，先向右看，再向左看，遇到括号就跳出当前层次，重复这个过程。

具体步骤：

1. 找到变量名，从这里开始
2. 向右看，读到 `[]` 表示数组，读到 `()` 表示函数
3. 向左看，读到 `*` 表示指针
4. 遇到右括号 `)` 就跳出当前括号对
5. 重复 2-4，直到读完整个声明

用图来表示就是这样：

```
        +-------+
        |  <--  |
        |       v
    --> [变量名] -->
        ^       |
        |  -->  |
        +-------+
```

先右后左，螺旋向外扩展。

## 运算符优先级回顾

解读声明之前，先明确一组优先级关系：

| 运算符 | 含义 | 优先级 |
|--------|------|--------|
| `[]`   | 数组下标 | 高 |
| `()`   | 函数调用 | 高 |
| `*`    | 指针 | 低 |

`[]` 和 `()` 的优先级相同，都高于 `*`。这决定了声明中各部分的结合顺序：

- `int *p[5]` — `p` 先与 `[5]` 结合，是数组，数组元素是 `int*`
- `int (*p)[5]` — 括号让 `p` 先与 `*` 结合，是指针，指向 `int[5]`

括号可以改变默认的结合顺序，这在复杂声明中大量使用。

## 典型声明逐个拆解

### 指针数组：`int *p[5]`

从 `p` 开始：

1. 向右看：`[5]` — p 是一个有 5 个元素的数组
2. 向左看：`*` — 数组的元素是指针
3. 向左看：`int` — 指针指向 int 类型

**结论**：p 是一个指针数组，包含 5 个指向 int 的指针。

```c
int a = 1, b = 2, c = 3, d = 4, e = 5;
int *p[5] = {&a, &b, &c, &d, &e};
// p[0] 指向 a，p[1] 指向 b，以此类推
```

### 数组指针：`int (*p)[5]`

从 `p` 开始：

1. 向右看：`)`，遇到括号，暂时跳过
2. 向左看：`*` — p 是一个指针
3. 跳出括号，向右看：`[5]` — 指针指向一个有 5 个元素的数组
4. 向左看：`int` — 数组的元素是 int 类型

**结论**：p 是一个数组指针，指向一个包含 5 个 int 的数组。

```c
int arr[5] = {1, 2, 3, 4, 5};
int (*p)[5] = &arr;
// (*p)[0] == arr[0] == 1
```

指针数组 vs 数组指针，这两个容易混淆。记住：`[]` 优先级高，没有括号时先和数组结合。

### 返回指针的函数：`int *f(int)`

从 `f` 开始：

1. 向右看：`(int)` — f 是一个函数，接受一个 int 参数
2. 向左看：`*` — 函数返回一个指针
3. 向左看：`int` — 指针指向 int 类型

**结论**：f 是一个函数，接受 int 参数，返回 `int*`。

```c
int *f(int x) {
    static int result;
    result = x * 2;
    return &result;
}
```

### 函数指针：`int (*pf)(int)`

从 `pf` 开始：

1. 向右看：`)`，遇到括号
2. 向左看：`*` — pf 是一个指针
3. 跳出括号，向右看：`(int)` — 指针指向的函数接受一个 int 参数
4. 向左看：`int` — 函数返回 int

**结论**：pf 是一个函数指针，指向接受 int 参数、返回 int 的函数。

```c
int add(int x) { return x + 1; }
int sub(int x) { return x - 1; }

int (*pf)(int) = add;
pf(5);  // 返回 6

pf = sub;
pf(5);  // 返回 4
```

### 函数指针数组：`int (*a[5])(int)`

这个声明开始复杂了，但按步骤来：

从 `a` 开始：

1. 向右看：`[5]` — a 是一个有 5 个元素的数组
2. 向左看：`*` — 数组元素是指针
3. 跳出括号，向右看：`(int)` — 指针指向的函数接受一个 int 参数
4. 向左看：`int` — 函数返回 int

**结论**：a 是一个函数指针数组，包含 5 个函数指针，每个指针指向接受 int、返回 int 的函数。

```c
int add(int x) { return x + 1; }
int sub(int x) { return x - 1; }
int mul(int x) { return x * 2; }
int div(int x) { return x / 2; }
int mod(int x) { return x % 2; }

int (*a[5])(int) = {add, sub, mul, div, mod};

for (int i = 0; i < 5; i++) {
    printf("%d\n", a[i](10));
}
// 输出：11, 9, 20, 5, 0
```

### 指向函数指针数组的指针：`int (*(*pf)[5])(int)`

这个更复杂，但方法一样：

从 `pf` 开始：

1. 向右看：`)`，遇到括号
2. 向左看：`*` — pf 是一个指针
3. 跳出内层括号，向右看：`[5]` — 指针指向一个有 5 个元素的数组
4. 向左看：`*` — 数组元素是指针
5. 跳出外层括号，向右看：`(int)` — 这些指针指向的函数接受 int 参数
6. 向左看：`int` — 函数返回 int

**结论**：pf 是一个指针，指向一个包含 5 个函数指针的数组，每个函数指针指向接受 int、返回 int 的函数。

```c
int add(int x) { return x + 1; }
int sub(int x) { return x - 1; }

int (*funcArray[5])(int) = {add, sub, add, sub, add};
int (*(*pf)[5])(int) = &funcArray;

(*pf)[0](10);  // 调用 add(10)，返回 11
(*pf)[1](10);  // 调用 sub(10)，返回 9
```

实际工作中极少直接写这种声明，通常会用 typedef 简化。

### signal 函数声明：`void (*signal(int, void(*)(int)))(int)`

这是 C 标准库中的 signal 函数声明，也是复杂声明的经典例子。

从 `signal` 开始：

1. 向右看：`(int, void(*)(int))` — signal 是一个函数，接受两个参数：
   - 第一个参数是 int
   - 第二个参数是 `void(*)(int)`，即一个函数指针
2. 向左看：`*` — signal 函数返回一个指针
3. 跳出括号，向右看：`(int)` — 返回的指针指向一个接受 int 参数的函数
4. 向左看：`void` — 函数返回 void

**结论**：signal 是一个函数，接受一个 int 和一个函数指针作为参数，返回一个函数指针。返回的函数指针和第二个参数类型相同：`void(*)(int)`。

signal 用于注册信号处理函数，它的第二个参数是新的信号处理函数，返回值是之前的信号处理函数。

```c
#include <signal.h>

void handler(int sig) {
    printf("Caught signal %d\n", sig);
}

int main() {
    // 注册 SIGINT 的处理函数
    void (*old_handler)(int) = signal(SIGINT, handler);

    // old_handler 是之前的处理函数，可以保存起来以后恢复

    while(1) {}
    return 0;
}
```

## typedef 简化声明

面对复杂声明，typedef 可以把声明拆分成易读的几个步骤。

以 signal 为例，先定义函数指针类型：

```c
typedef void (*sighandler_t)(int);

// 现在 signal 的声明变成
sighandler_t signal(int sig, sighandler_t handler);
```

清晰多了。`sighandler_t` 是一个函数指针类型，signal 接受并返回这个类型。

再看函数指针数组的例子：

```c
// 原声明
int (*a[5])(int);

// 用 typedef 拆解
typedef int (*func_t)(int);  // func_t 是函数指针类型
func_t a[5];                  // a 是包含 5 个 func_t 的数组
```

对于指向函数指针数组的指针：

```c
// 原声明
int (*(*pf)[5])(int);

// 用 typedef 拆解
typedef int (*func_t)(int);   // 函数指针类型
typedef func_t (*func_array_ptr)[5];  // 指向函数指针数组的指针类型
func_array_ptr pf;
```

typedef 的策略是**由内向外逐层定义**：

1. 先定义最内层的类型（通常是函数指针）
2. 再用定义好的类型去声明更外层的结构

## 实战建议

### 什么时候该用 typedef

当声明嵌套超过两层时，就应该考虑 typedef。像 `int (*a[5])(int)` 这种虽然能读懂，但用 typedef 会更清晰。

typedef 还有一个好处：类型别名有语义。`sighandler_t` 比 `void(*)(int)` 更能表达"信号处理函数"的含义。

### 避免写出过于复杂的声明

几点原则：

1. **不要炫技**。写出 `int(*(*p)[5])(int)` 不是水平高，是让维护的人痛苦。
2. **用 typedef 逐层拆解**。复杂声明都可以分解成简单的类型组合。
3. **声明和定义分开写**。先给出 typedef 类型定义，再声明变量。
4. **加注释**。如果声明确实复杂，花一行注释说明它的含义。

### 解读技巧总结

1. 找到变量名，从它开始
2. 先右后左，螺旋向外
3. `[]` 和 `()` 优先级高于 `*`
4. 括号改变结合顺序
5. 用 typedef 简化复杂声明

只要记住这些规则，再复杂的声明也能一步步拆解出来。遇到特别复杂的声明，不要慌，画个螺旋图，从变量名开始，一步一步往外读。
