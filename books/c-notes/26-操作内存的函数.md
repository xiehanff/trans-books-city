# C语言中操作内存的函数

C 语言里最常用的内存函数分成两类：动态分配和内存块操作。

| 函数 | 作用 | 头文件 | 备注 |
|------|------|--------|------|
| `malloc` | 分配一块未初始化内存 | `<stdlib.h>` | 返回 `void*` |
| `calloc` | 分配并清零 | `<stdlib.h>` | 适合数组 |
| `realloc` | 调整已有内存块大小 | `<stdlib.h>` | 失败时原指针仍有效 |
| `free` | 释放动态内存 | `<stdlib.h>` | 只释放一次 |
| `memcpy` | 复制内存块 | `<string.h>` | 不处理重叠 |
| `memmove` | 复制内存块 | `<string.h>` | 可以处理重叠 |
| `memset` | 填充字节 | `<string.h>` | 常用于清零 |
| `memcmp` | 比较内存块 | `<string.h>` | 按字节比较 |

## 动态分配

### malloc

`malloc` 只负责分配，不负责初始化。

```c
int *arr = malloc(10 * sizeof(int));
if (!arr) {
    return 1;
}
```

申请后记得自己初始化：

```c
for (int i = 0; i < 10; i++) {
    arr[i] = 0;
}
```

### calloc

`calloc` 会把分配出来的内存清零。

```c
int *arr = calloc(10, sizeof(int));
if (!arr) {
    return 1;
}
```

如果本来就要全零初始化，`calloc` 比 `malloc + memset` 更直接。

### realloc

`realloc` 用来扩容或缩容。

```c
int *tmp = realloc(arr, 20 * sizeof(int));
if (!tmp) {
    free(arr);
    return 1;
}
arr = tmp;
```

这里先接到临时指针，再回写到原指针。这样可以避免扩容失败时把原内存弄丢。

### free

`free` 只释放动态分配的内存。

```c
free(arr);
arr = NULL;
```

把指针置空不是必须，但能减少重复释放和悬空指针的误用。

## 内存块操作

### memcpy

`memcpy` 复制一段内存到另一段内存，源和目标不能重叠。

```c
int src[4] = {1, 2, 3, 4};
int dst[4];
memcpy(dst, src, sizeof(src));
```

### memmove

`memmove` 和 `memcpy` 类似，但允许源和目标重叠。

```c
char text[] = "abcdef";
memmove(text + 2, text, 4);  // 结果是 "ababcd"
```

如果不确定是否重叠，直接用 `memmove` 更稳。

### memset

`memset` 按字节填充内存。

```c
int arr[10];
memset(arr, 0, sizeof(arr));  // 清零
```

它适合清零和填充字节模式，不适合拿来给复杂对象做“初始化魔法”。

### memcmp

`memcmp` 按字节比较两个内存块。

```c
if (memcmp(a, b, sizeof(a)) == 0) {
    // 两块内存内容相同
}
```

它比较的是原始字节，不是“语义上的相等”。

## 常见写法

### 动态数组

```c
int *arr = malloc(n * sizeof(int));
if (!arr) return 1;

for (size_t i = 0; i < n; i++) {
    arr[i] = (int)i;
}
```

### 扩容

```c
size_t new_count = count * 2;
int *tmp = realloc(arr, new_count * sizeof(int));
if (!tmp) {
    free(arr);
    return 1;
}
arr = tmp;
count = new_count;
```

### 交换或移动数据

```c
int a[3] = {1, 2, 3};
int b[3];
memcpy(b, a, sizeof(a));
```

如果是同一块内存内部移动，就改用 `memmove`。

## 选用顺序

- 需要一块新内存：先看 `malloc`，要清零就用 `calloc`
- 需要调整大小：用 `realloc`
- 释放内存：用 `free`
- 拷贝不重叠数据：用 `memcpy`
- 拷贝可能重叠数据：用 `memmove`
- 按字节清空：用 `memset`
- 比较原始字节：用 `memcmp`
