# 数据类型、格式化输出与类型转换

## 基本数据类型

C语言的基本数据类型分为整型和浮点型。

### 整型

整型按大小和符号分为多种：

| 类型 | 占用字节 | 范围 |
|------|----------|------|
| char | 1 | -128 ~ 127（或0 ~ 255，取决于实现） |
| short | 2 | -32768 ~ 32767 |
| int | 4 | -2147483648 ~ 2147483647 |
| long | 4或8 | 至少和int一样大 |
| long long | 8 | 更大的范围 |

加上 `unsigned` 修饰符表示无符号：

```c
unsigned char c;      // 0 ~ 255
unsigned int n;       // 0 ~ 4294967295
```

`char` 类型存储字符，但本质上是小整数。可以赋值整数：

```c
char c = 65;     // 等价于 c = 'A'
```

### 浮点型

| 类型 | 占用字节 | 精度 |
|------|----------|------|
| float | 4 | 约6-7位有效数字 |
| double | 8 | 约15-16位有效数字 |

```c
float f = 3.14f;     // f后缀表示float类型
double d = 3.14;     // 默认是double
```

浮点数采用IEEE 754标准存储，精度有限：

```c
float f = 0.1;
if (f == 0.1)        // 可能为假！
```

浮点数比较要用误差范围：

```c
if (fabs(f - 0.1) < 0.0001)  // 在误差范围内认为相等
```

### sizeof 运算符

查询类型或变量占用的字节数：

```c
printf("%zu\n", sizeof(int));      // 4
printf("%zu\n", sizeof(double));   // 8

int a = 10;
printf("%zu\n", sizeof a);         // 4，变量可以不加括号
```

注意：`sizeof` 返回的类型是 `size_t`，用 `%zu` 格式输出。

## 格式化输出

`printf` 函数用于格式化输出，格式字符串中的占位符会被替换成对应参数。

### 常用占位符

| 占位符 | 类型 |
|--------|------|
| %d, %i | 有符号整数 |
| %u | 无符号整数 |
| %f | float, double |
| %c | 字符 |
| %s | 字符串 |
| %p | 指针地址 |
| %x, %X | 十六进制整数 |
| %o | 八进制整数 |
| %% | 输出%本身 |

```c
int n = 42;
printf("n = %d\n", n);        // n = 42
printf("n = %x\n", n);        // n = 2a

double d = 3.14159;
printf("d = %f\n", d);        // d = 3.141590
```

### 宽度和精度

控制输出宽度和精度：

```c
printf("%5d\n", 42);          // 输出宽度5，右对齐：   42
printf("%-5d\n", 42);         // 左对齐：42
printf("%05d\n", 42);         // 用0填充：00042

printf("%.2f\n", 3.14159);    // 保留2位小数：3.14
printf("%8.2f\n", 3.14);      // 宽度8，2位小数：    3.14
```

宽度和精度的组合格式：`%[flags][width][.precision]type`

```c
printf("%08.2f\n", 3.14);     // 00003.14
```

### long 和 long long

`long` 类型用 `%ld`，`long long` 用 `%lld`：

```c
long l = 12345678L;
printf("%ld\n", l);

long long ll = 12345678901234LL;
printf("%lld\n", ll);
```

### size_t 类型

`sizeof` 返回 `size_t` 类型，用 `%zu`：

```c
size_t size = sizeof(int);
printf("%zu\n", size);
```

## 类型转换

### 隐式类型转换

当不同类型的值一起运算时，编译器自动转换：

```c
int a = 5;
float b = 2.0;
float c = a + b;    // a自动转为float，结果7.0
```

转换规则：小类型向大类型转换，整型向浮点型转换。

```c
int a = 5;
int b = 2;
float c = a / b;    // 先整数除法得2，再转为2.0
```

这不是想要的结果。要让其中一个操作数变成浮点数：

```c
float c = a / 2.0;          // 5 / 2.0 = 2.5
float c = (float)a / b;     // 显式转换
```

### 显式类型转换（强制转换）

用括号指定目标类型：

```c
int a = 5, b = 2;
float c = (float)a / b;     // a转为5.0f，结果2.5

double d = 3.7;
int n = (int)d;             // n = 3，截断小数
```

强制转换可能导致精度丢失或数据溢出：

```c
int n = 300;
char c = (char)n;           // 溢出，c的值不确定
```

### 整数提升

`char` 和 `short` 在运算时会自动提升为 `int`：

```c
char a = 'A', b = 1;
char c = a + b;   // a + b 是int运算，结果再截断为char
```

## 可移植类型

不同平台上基本类型的字节数可能不同。`stdint.h` 提供了固定大小的整数类型：

```c
#include <stdint.h>

int32_t i;        // 固定32位有符号整数
uint32_t u;       // 固定32位无符号整数
int64_t big;      // 固定64位有符号整数
```

打印这些类型需要用 `inttypes.h` 中定义的宏：

```c
#include <stdint.h>
#include <inttypes.h>

int32_t n = 42;
printf("n = %" PRId32 "\n", n);
```

`PRId32` 展开成正确的格式说明符，保证跨平台兼容。

## 常见问题

**整数溢出**

```c
int a = 2147483647;
a = a + 1;        // 溢出，变成-2147483648
```

有符号整数溢出是未定义行为，结果不可预测。用更大的类型或检查边界。

**浮点数精度**

```c
float f = 0.1 + 0.2;
if (f == 0.3)     // 可能为假
```

浮点数计算有精度误差，不要用 `==` 直接比较。

**sizeof 的时机**

```c
int n = 10;
int arr[n];       // 变长数组（C99）
printf("%zu\n", sizeof(arr));  // 运行时确定大小
```

普通数组的大小在编译时确定，变长数组在运行时确定。

**格式字符串不匹配**

```c
long n = 100;
printf("%d\n", n);    // 错误：long应该用%ld
```

格式字符串和参数类型不匹配会导致输出错误或程序崩溃。编译器通常会警告。
