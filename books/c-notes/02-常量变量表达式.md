# 常量、变量、表达式与字符

## 常量

常量是程序中固定不变的值。直接写在代码里的数值、字符、字符串都是常量。

```c
int a = 10;        // 10 是整数常量
float b = 3.14;    // 3.14 是浮点数常量
char c = 'A';      // 'A' 是字符常量
```

整数常量可以用不同进制表示：

```c
int a = 10;        // 十进制
int b = 012;       // 八进制（以0开头）
int c = 0xA;       // 十六进制（以0x开头）
```

上面三个值都是十进制的10。

### 符号常量

用 `#define` 定义符号常量：

```c
#define PI 3.14159
#define MAX_SIZE 100

int main(void)
{
    float area = PI * 5 * 5;  // 编译时替换为 3.14159 * 5 * 5
    return 0;
}
```

注意：`#define` 是预处理指令，不是语句，末尾不加分号。加了分号会被一起替换：

```c
#define PI 3.14159;    // 错误写法

float a = PI * 2;      // 展开成 3.14159; * 2，语法错误
```

### const 关键字

C语言也支持 `const` 关键字定义常量：

```c
const int MAX = 100;
const float PI = 3.14159;
```

`const` 定义的常量有类型检查，比 `#define` 更安全。但C语言中 `const` 定义的"常量"实际上只是只读变量，不能用作数组长度等需要编译期常量的场景。

## 变量

变量是存储数据的容器，其值可以改变。使用前必须先声明。

### 声明与初始化

```c
int a;           // 声明，未初始化
int b = 10;      // 声明并初始化
int c = 10, d = 20;  // 同时声明多个变量
```

未初始化的变量值是未定义的（可能是任意值），使用前应该赋值。

### 赋值

赋值用 `=` 运算符：

```c
int a;
a = 10;          // 赋值
a = a + 1;       // 赋值表达式，a变为11
```

赋值是"覆盖"操作，新值会替换旧值。

### 命名规则

变量名只能包含字母、数字和下划线，且不能以数字开头：

```c
int score;       // 合法
int _count;      // 合法
int max_value;   // 合法
int 2nd_place;   // 非法：以数字开头
int my-var;      // 非法：包含减号
```

C语言区分大小写，`score` 和 `Score` 是两个不同的变量。

避免使用C语言关键字作为变量名：

```c
int int;         // 非法：int是关键字
int if;          // 非法：if是关键字
```

## 表达式

表达式是由运算符和操作数组成的式子，计算后产生一个值。

```c
10               // 常量是表达式
a                // 变量是表达式
a + b            // 算术表达式
a = 10           // 赋值表达式，值为10
func()           // 函数调用是表达式
```

表达式的特点是可以求值。`a = 10` 这个表达式的值就是10，所以可以写出：

```c
a = b = 10;      // 等价于 a = (b = 10)
```

先把10赋给b，表达式 `b = 10` 的值是10，再赋给a。

### 语句

表达式加上分号就是语句：

```c
a + b;           // 合法但无意义：计算了a+b但没使用结果
a = 10;          // 赋值语句
```

语句执行操作，不一定产生值。

## 字符与字符集

### 字符常量

字符常量用单引号括起来：

```c
char c = 'A';
char d = '0';     // 字符'0'，不是数字0
```

`char` 类型占用1个字节，存储的是字符的编码值（整数）。

### ASCII编码

计算机用数字编码表示字符。最常用的是ASCII编码：

| 字符 | 编码(十进制) |
|------|--------------|
| '0'-'9' | 48-57 |
| 'A'-'Z' | 65-90 |
| 'a'-'z' | 97-122 |

所以字符可以参与算术运算：

```c
char c = 'A';
char d = c + 1;   // d是'B'，因为'A'的编码是65，加1是66，即'B'
```

判断小写字母：

```c
if (c >= 'a' && c <= 'z') {
    // c是小写字母
}
```

大小写转换：

```c
char upper = 'A';
char lower = upper + 32;  // 'a'，或者写成 upper + ('a' - 'A')
```

### 转义字符

有些字符无法直接写在单引号里，需要用转义序列：

```c
char newline = '\n';    // 换行
char tab = '\t';        // 制表符
char backslash = '\\';  // 反斜杠本身
char quote = '\'';      // 单引号本身
```

常用转义字符：

| 转义序列 | 含义 |
|----------|------|
| \n | 换行 |
| \t | 水平制表 |
| \\ | 反斜杠 |
| \' | 单引号 |
| \" | 双引号 |
| \0 | 空字符(null) |

### 字符串

字符串用双引号括起来，末尾自动加一个空字符 `\0`：

```c
char s[] = "Hello";  // 实际存储：H e l l o \0
```

字符串和字符是不同的：

```c
char c = 'A';        // 字符，占1字节
char *s = "A";       // 字符串，占2字节（'A'和'\0'）
```

## 常见问题

**混淆 = 和 ==**

```c
if (a = 10)   // 赋值表达式，值为10，永远为真
if (a == 10)  // 判断相等
```

编译器可能会警告，但这是合法代码。养成习惯：判断相等时把常量写在左边：

```c
if (10 == a)  // 写成 10 = a 会直接报错
```

**变量未初始化**

```c
int a;
printf("%d\n", a);  // 危险：a的值不确定
```

局部变量不会自动初始化，值是内存中的随机数据。声明时就初始化是个好习惯：

```c
int a = 0;
```

**字符和数字混淆**

```c
char c = '0';    // 字符'0'，编码值是48
int n = 0;       // 数字0
```

字符 '0' 和数字 0 完全不同。

**整数除法**

```c
int a = 5 / 2;   // a是2，不是2.5
```

两个整数相除，结果还是整数，小数部分被截断。
