# 函数指针与指针函数：先看清声明，再理解回调

`int *func(int)` 和 `int (*func)(int)` 只多了一对括号，却代表完全不同的东西。前者是一个**返回指针的函数**，常被称为“指针函数”；后者是一个**指向函数的指针**，称为“函数指针”。

这两个概念经常一起出现，是因为它们都使用了 `*` 和函数参数列表。不要靠背诵名称区分，直接从标识符向外读声明更可靠。

> [`S01_指针相关概念辨析.md`](31-S01-%E6%8C%87%E9%92%88%E7%9B%B8%E5%85%B3%E6%A6%82%E5%BF%B5%E8%BE%A8%E6%9E%90.md) 适合快速查表；本篇重点讲它们为什么有用，以及如何写成可运行的回调和函数表。对应测试见 [`c_doc_test/`](#code/books/c-notes/code/c_doc_test/README.md)。

## 1. 先从括号看声明

C 声明中，函数调用括号 `()` 和数组下标 `[]` 的结合优先级高于 `*`。因此可以先看标识符旁边有没有括号：

```c
int *make_value(int value);   // make_value 先和 () 结合：它是函数，返回 int*
int (*operation)(int, int);   // (*operation) 先结合：它是指针，指向一个函数
```

把两种声明放在一起对比：

| 声明 | 谁是什么 | 含义 |
|------|----------|------|
| `int *func(int)` | `func` 是函数 | 接收一个 `int`，返回 `int *` |
| `int (*pf)(int)` | `pf` 是指针 | 指向接收一个 `int`、返回 `int` 的函数 |
| `int *(*factory)(int)` | `factory` 是指针 | 指向接收一个 `int`、返回 `int *` 的函数 |
| `int (*ops[3])(int, int)` | `ops` 是数组 | 数组元素是函数指针 |

**记忆方法：**先找到变量名，再从变量名向外读；如果 `*` 被括号包住，它通常是在说明“这是一个指针”，而不是说明函数返回指针。

## 2. 指针函数：函数返回一个指针

### 为什么函数要返回指针

函数结束后，普通局部变量的生命周期也结束了。因此不能返回局部变量的地址：

```c
int *wrong(void) {
    int value = 10;
    return &value;  // 错误：函数返回后 value 已经不存在
}
```

如果返回的指针指向堆内存，内存生命周期可以超过当前函数，但必须明确由谁释放：

```c
#include <stdlib.h>

// 这是“指针函数”：函数名后面是参数列表，返回类型是 int*
int *create_int(int value) {
    // 1. 在堆上申请一个 int
    int *result = malloc(sizeof *result);
    if (result == NULL) {
        return NULL;
    }

    // 2. 初始化堆内存
    *result = value;
    return result;  // 3. 把所有权交给调用者
}

int main(void) {
    int *number = create_int(42);
    if (number == NULL) {
        return 1;
    }

    // 4. 使用返回的指针
    /* printf("%d\n", *number); */

    // 5. 谁获得堆内存，谁负责释放
    free(number);
    return 0;
}
```

上例中 `create_int` 返回的是 `int *`，但 `create_int` 自己仍然是一个函数，不是指针。

如果返回的是字符串字面量，应使用 `const char *` 表示调用者不能修改它；如果返回静态变量，虽然地址有效，但所有调用者共享同一份数据，通常不适合表达独立对象。

## 3. 函数指针：把函数当作数据传递

### 为什么需要函数指针

假设有一个“执行二元运算”的流程。如果把加法、减法、乘法分别复制一份流程，代码会重复；如果把具体运算作为参数传入，流程就能复用。函数指针就是这种“把行为传进去”的工具。

先定义几个普通函数，再定义函数指针类型：

```c
typedef int (*BinaryOperation)(int left, int right);

int add(int left, int right) {
    return left + right;
}

int subtract(int left, int right) {
    return left - right;
}

int multiply(int left, int right) {
    return left * right;
}
```

`BinaryOperation` 表示“指向接收两个 `int` 并返回 `int` 的函数的指针”。用 `typedef` 给复杂声明起名字后，接口会更容易阅读。

通过函数指针调用函数有两种等价写法：

```c
BinaryOperation operation = add;

int a = operation(2, 3);    // 推荐：函数指针可以像函数一样调用
int b = (*operation)(2, 3); // 显式解引用，含义相同
```

函数名在表达式中通常会转换成指向该函数的指针，所以 `operation = add` 不需要手写 `&add`。

### 把函数指针作为参数

```c
int apply_operation(BinaryOperation operation,
                    int left,
                    int right,
                    int *result) {
    if (operation == NULL || result == NULL) {
        return 0;
    }

    // 1. 调用调用者传入的具体操作
    *result = operation(left, right);
    return 1;
}

int result = 0;
apply_operation(add, 2, 3, &result);       // result 为 5
apply_operation(multiply, 2, 3, &result);  // result 为 6
```

这里的 `apply_operation` 不需要知道具体是加法还是乘法，它只依赖函数指针的签名。这种由调用者提供行为的方式就是回调的基础。

## 4. 回调函数与上下文参数

C 没有内置闭包。回调除了传入函数指针，通常还要额外传一个 `void *context`，让回调获得调用者的上下文数据：

```c
#include <stddef.h>

typedef void (*IntVisitor)(int *value, void *context);

void visit_ints(int *values,
                size_t count,
                IntVisitor visitor,
                void *context) {
    if (visitor == NULL || (values == NULL && count > 0)) {
        return;
    }

    for (size_t i = 0; i < count; i++) {
        // 1. 把当前元素和上下文交给回调
        visitor(&values[i], context);
    }
}

static void add_offset(int *value, void *context) {
    // 2. 调用者决定 context 实际指向什么类型
    const int offset = *(const int *)context;
    *value += offset;
}

int main(void) {
    int values[] = {1, 2, 3};
    const int offset = 10;

    // 3. 同一个遍历函数可以执行不同回调
    visit_ints(values, sizeof values / sizeof values[0],
               add_offset, (void *)&offset);
    return 0;
}
```

`void *` 只负责传递地址，不负责告诉编译器地址指向的真实类型。回调和调用者必须约定好上下文类型，否则强制转换后会产生未定义行为。

## 5. 函数指针数组：实现操作表或命令分发

当多个函数签名相同，可以把它们放进数组，用索引选择行为：

```c
#include <stddef.h>

typedef int (*BinaryOperation)(int, int);

int add(int left, int right) { return left + right; }
int subtract(int left, int right) { return left - right; }
int multiply(int left, int right) { return left * right; }

int calculate(size_t operation_index, int left, int right) {
    static const BinaryOperation operations[] = {
        add,
        subtract,
        multiply
    };

    if (operation_index >= sizeof operations / sizeof operations[0]) {
        return 0;  // 实际项目可使用更明确的错误码
    }
    return operations[operation_index](left, right);
}
```

典型场景包括命令行菜单、状态机的动作表、协议消息处理表等。所有函数必须拥有兼容的签名；不能把参数类型不同的函数强行放进同一个函数指针数组。

## 6. 标准库回调：`qsort`

`qsort` 不知道数组元素应该如何比较，所以把比较函数交给调用者：

```c
#include <stdlib.h>

int compare_int_ascending(const void *left, const void *right) {
    const int left_value = *(const int *)left;
    const int right_value = *(const int *)right;

    // 返回负数、0、正数分别表示小于、等于、大于
    // 不直接写 left_value - right_value，避免整数减法溢出
    return (left_value > right_value) - (left_value < right_value);
}

int values[] = {4, -2, 9, 0};
qsort(values,
      sizeof values / sizeof values[0],
      sizeof values[0],
      compare_int_ascending);
```

`qsort` 的比较函数参数是 `const void *`，因为它要支持任意元素类型。转换回真实类型时，要保证传入的数组元素类型和转换类型一致。

## 7. 既是“指针函数”又能用函数指针指向它

声明 `int *create_int(int)` 表示一个返回 `int *` 的函数。要声明一个“指向这类函数的指针”，需要再加一层括号：

```c
#include <stdlib.h>

int *create_int(int value);

int main(void) {
    // factory 是函数指针；它指向的函数接收 int，返回 int*
    int *(*factory)(int) = create_int;

    int *number = factory(42);
    if (number != NULL) {
        free(number);
    }
    return 0;
}
```

对比下面两行：

```c
int *create_int(int);     // 函数：调用 create_int(42)
int *(*factory)(int);     // 指针：先让 factory 指向某个兼容函数，再调用 factory(42)
```

括号改变了 `*` 的结合对象，这就是函数指针声明中最重要的语法细节。

## 8. 使用函数指针时的边界

### 不要调用空函数指针

```c
BinaryOperation operation = NULL;
// operation(1, 2);  // 错误：调用空指针
```

如果函数指针来自可选配置或查表结果，调用前要检查是否为 `NULL`。

### 签名必须兼容

函数指针不是“任意函数地址”。参数数量、参数类型和返回类型不兼容时，强制转换并不能让调用变得安全。

### 注意返回指针的所有权

函数指针只描述“如何调用函数”，不自动管理函数返回的堆内存。像 `create_int` 这样的函数把内存所有权交给调用者，调用者仍然必须 `free`。

可直接编译的实现位于 [`c_doc_test/lib/function_pointer.c`](#code/books/c-notes/code/c_doc_test/lib/function_pointer.c)，对应测试位于 [`c_doc_test/test/test_function_pointer.c`](#code/books/c-notes/code/c_doc_test/test/test_function_pointer.c)。

一句话总结：看到复杂声明时先围绕变量名向外读；函数指针用于传递行为，指针函数只是返回指针的普通函数。
