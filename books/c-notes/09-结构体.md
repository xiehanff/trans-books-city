# 结构体

数组存储相同类型的多个数据，结构体则可以把不同类型的数据组合在一起，形成自定义类型。

## 结构体的定义与初始化

使用`struct`关键字定义结构体类型。

```c
struct Student {
    char name[20];
    int age;
    float score;
};
```

定义结构体变量：

```c
struct Student stu1;  // 声明一个结构体变量
```

可以在定义类型的同时声明变量：

```c
struct Student {
    char name[20];
    int age;
    float score;
} stu1, stu2;  // 同时声明两个变量
```

初始化方式：

```c
// 方式1：按顺序初始化
struct Student stu1 = {"张三", 20, 85.5};

// 方式2：指定成员初始化（C99）
struct Student stu2 = {
    .name = "李四",
    .age = 19,
    .score = 90.0
};

// 方式3：部分初始化，未指定成员自动初始化为0
struct Student stu3 = {.name = "王五"};
```

## 结构体成员访问

使用点运算符`.`访问结构体成员。

```c
struct Student stu = {"张三", 20, 85.5};

printf("姓名：%s\n", stu.name);
printf("年龄：%d\n", stu.age);
printf("分数：%.1f\n", stu.score);

// 修改成员
stu.age = 21;
stu.score = 88.0;
```

结构体之间可以直接赋值：

```c
struct Student stu1 = {"张三", 20, 85.5};
struct Student stu2;

stu2 = stu1;  // 直接赋值，所有成员都被复制
```

## 结构体数组

数组的每个元素都是结构体类型。

```c
struct Student class[3] = {
    {"张三", 20, 85.5},
    {"李四", 19, 90.0},
    {"王五", 21, 78.5}
};

// 遍历
for (int i = 0; i < 3; i++) {
    printf("%s: %d岁, %.1f分\n",
           class[i].name, class[i].age, class[i].score);
}
```

## 结构体指针

指针可以指向结构体。

```c
struct Student stu = {"张三", 20, 85.5};
struct Student* p = &stu;
```

通过指针访问成员有两种方式：

```c
// 方式1：先解引用再访问
(*p).age = 21;

// 方式2：箭头运算符（更常用）
p->age = 21;
```

`->`运算符是`(*p).`的简写，两者完全等价。

结构体指针常用于函数参数，避免复制整个结构体：

```c
void print_student(struct Student* p) {
    printf("%s: %d岁\n", p->name, p->age);
}

// 调用
print_student(&stu);
```

## 结构体作为函数参数

结构体作为参数传递时，是值传递（复制整个结构体）。

```c
void add_age(struct Student s) {
    s.age++;  // 修改的是副本，不影响原结构体
}

struct Student stu = {"张三", 20, 85.5};
add_age(stu);
printf("%d\n", stu.age);  // 还是20
```

要修改原结构体，需要传指针：

```c
void add_age(struct Student* s) {
    s->age++;  // 修改原结构体
}

add_age(&stu);
printf("%d\n", stu.age);  // 21
```

对于较大的结构体，传指针比传值更高效，因为只复制一个指针。

## 嵌套结构体

结构体成员可以是另一个结构体。

```c
struct Date {
    int year;
    int month;
    int day;
};

struct Employee {
    char name[20];
    struct Date birthday;  // 嵌套结构体
    float salary;
};

struct Employee emp = {
    .name = "张三",
    .birthday = {1990, 5, 15},
    .salary = 8000.0
};

// 访问嵌套成员
printf("出生日期：%d-%d-%d\n",
       emp.birthday.year,
       emp.birthday.month,
       emp.birthday.day);
```

嵌套结构体的指针访问：

```c
struct Employee* p = &emp;
printf("%d\n", p->birthday.year);  // 注意用点不是箭头
```

结构体可以包含指向自身类型的指针，用于构建链表等数据结构：

```c
struct Node {
    int data;
    struct Node* next;  // 指向下一个节点
};
```

## typedef 与结构体

`typedef`可以为结构体类型起别名，简化书写。

```c
// 方式1
struct Student {
    char name[20];
    int age;
};
typedef struct Student Student;

// 方式2：定义时起别名
typedef struct {
    char name[20];
    int age;
} Student;

// 使用
Student stu = {"张三", 20};  // 不需要写struct
```

## 结构体大小与内存对齐

结构体的大小不一定是各成员大小之和，因为存在内存对齐。

```c
struct Example {
    char a;    // 1字节
    int b;     // 4字节
    char c;    // 1字节
};

printf("%zu\n", sizeof(struct Example));  // 可能是12，不是6
```

内存对齐是为了提高CPU访问效率。编译器会在成员之间插入padding字节。

```
内存布局（假设按4字节对齐）：
a | padding | padding | padding | b | b | b | b | c | padding | padding | padding
```

可以调整成员顺序减少padding：

```c
struct Optimized {
    int b;     // 4字节
    char a;    // 1字节
    char c;    // 1字节
};
// sizeof 可能是8
```

使用`offsetof`宏查看成员偏移量：

```c
#include <stddef.h>

printf("a的偏移：%zu\n", offsetof(struct Example, a));  // 0
printf("b的偏移：%zu\n", offsetof(struct Example, b));  // 4
```
