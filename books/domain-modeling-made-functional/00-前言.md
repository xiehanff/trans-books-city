# 前言

很多人认为函数式编程（functional programming）全是数学抽象和晦涩难懂的代码。在本书中，我想表明的是：函数式编程实际上是领域建模（domain modeling）的绝佳选择，它能够产出既清晰又简洁的设计。

## 本书适合谁？

本书面向希望在自己的编程工具箱里增添一些新工具的有经验的软件开发者。如果你属于以下情况，就应该阅读本书：

- 你好奇如何仅用类型（type）和函数来对一个领域进行建模和实现。
- 你想要一份领域驱动设计（domain-driven design，DDD）的简单入门，并想了解它与面向对象设计或数据库优先设计有何不同。
- 你是一位经验丰富的领域驱动设计实践者，想了解为什么 DDD 与函数式编程是天作之合。
- 你想学习函数式编程，却被过多的理论和抽象吓退了。
- 你想看看 F# 和函数式编程如何应用于真实世界的领域。

阅读本书不需要预先掌握领域驱动设计或函数式编程的知识。这是一本入门书，所有重要概念都会在需要用到时加以解释。

## 本书包含什么内容？

本书分为三个部分：

- 理解领域
- 领域建模
- 实现模型

每个部分都建立在前一部分的基础上，所以最好按顺序阅读。

在第一部分“理解领域”中，我们将了解领域驱动设计背后的思想，以及对领域形成共同理解的重要性。我们会简要了解一些有助于建立这种共同理解的技术，比如事件风暴（Event Storming），然后会看到如何把一个大型领域分解成可以独立实现和演化的更小组件。

需要说明的是，本书并不打算对领域驱动设计做全面深入的探讨。那是一个庞大的主题，已经有许多优秀的书籍和网站对其做了详细论述。本书的目标是把领域驱动设计作为函数式领域建模的搭档介绍给你。我们当然会涵盖领域驱动设计中最重要的概念，但不会深入细节，而是停留在较高的层面，强调两件事：(a) 与领域专家及其他非技术团队成员沟通的重要性；(b) 基于真实世界概念的共享领域模型的价值。

在第二部分“领域建模”中，我们将从领域中选取一个工作流（Workflow），并以函数式的方式对它建模。我们将看到工作流的函数式分解与面向对象方法的区别，还将学习如何用类型来捕获需求。到最后，我们会写出兼具双重用途的简洁代码：首先它是领域的可读文档，同时它也是可编译的框架，其余的实现可以在此之上构建。

在第三部分“实现模型”中，我们将把同一个已建模的工作流加以实现。在此过程中，我们将学习如何使用常见的函数式编程技术，比如组合（composition）、偏应用（partial application），以及听起来很吓人的“单子”（monad）。

本书无意成为函数式编程的完备指南。我们只覆盖对领域进行建模和实现所需的内容，不会涉及更高级的技术。尽管如此，到第三部分结束时，你将熟悉所有最重要的函数式编程概念，并掌握一套可应用于大多数编程场景的技能工具箱。

正如太阳必然升起，需求也必然变化，因此在最后一章中，我们将考察领域可能演进的一些常见方向，以及我们的设计如何做出调整来适应变化。

## 领域建模的其他方法

本书聚焦于领域建模的“主流”做法：先定义数据结构，再定义作用于这些数据结构上的函数。但在某些情况下，其他方法可能更为适用。我在这里提及其中的两种，供你进一步探索。

如果领域围绕半结构化数据展开，那么本书讨论的这类刚性模型并不合适，更好的做法是使用映射（map，也称为字典 dictionary）这样的灵活结构来存储键值对。Clojure 社区在这方面有许多良好的实践。

如果领域的重点在于把元素组合起来构成其他元素，那么先聚焦于这些组合规则（即所谓的“代数”），再聚焦于数据，往往很有用。这样的领域非常普遍，从金融合约到图形设计工具皆是如此，而“无处不在的组合”原则使它们尤其适合用函数式方式建模。遗憾的是，由于篇幅所限，我们不会在本书中覆盖这类领域。

## 使用本书中的代码

本书将使用 F# 编程语言来演示函数式编程的概念与技术。书中代码已在 2017 年 6 月时最新的 F# 版本上测试过，即 F# 4.1（包含在 Visual Studio 2017 中，也可以单独安装）。所有代码在更早版本的 F# 上同样可用，任何重要差异都会在正文中指出。

F# 的一大优点是它可以像脚本语言一样使用。如果你打算一边阅读本书一边尝试示例代码，我建议你把代码输入文件中交互式求值，而不是去编译它。具体做法可以在互联网上搜索 “F# scripting tips”。

本书的全部代码都可以在 Pragmatic Programmers 网站上本书的页面获取。[1]

### F# 入门

如果你刚接触 F#，这里有一些有用的信息：

- F# 是一门开源、跨平台的语言。下载和安装的详细说明见 fsharp.org。[2]
- 有许多免费的开发环境可用于 F#。最流行的是 Visual Studio（适用于 Windows 和 Mac），以及带 Ionide 插件的 Visual Studio Code（支持所有平台）。[3][4]
- 在学习 F# 方面，有 StackOverflow（使用 “F#” 标签），还有由 F# Software Foundation 运营的 Slack 论坛。[5] F# 社区非常友好，如果你有问题，大家会很乐意帮忙。
- 想了解 F# 的新闻动态，可以关注 Twitter 上的 “#fsharp” 标签，并阅读 F# Weekly 周刊。[6]

本书只用到 F# 的一小部分特性，而且大部分语法都会随讲解逐步说明。如果你需要更完整的 F# 语法概览，建议在互联网上搜索 “F# cheat sheet” 或 “F# syntax”。
