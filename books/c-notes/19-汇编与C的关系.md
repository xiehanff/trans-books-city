# 第19章 汇编与 C 的关系

C 语言被称为"可移植的汇编"，理解 C 代码与汇编的对应关系，有助于写出更高效的代码，也便于调试疑难问题。

## C 代码到汇编的映射

### 编译过程

C 代码经过编译器生成汇编，再由汇编器生成机器码。

```bash
# 生成汇编文件（不进行汇编和链接）
gcc -S -o test.s test.c

# 查看汇编（附带源码）
gcc -g test.c -o test
objdump -d -S test
```

### 基本映射

简单的表达式计算：

```c
int add(int a, int b) {
    return a + b;
}
```

```asm
add:
    mov eax, edi    ; 第一个参数
    add eax, esi    ; 加上第二个参数
    ret
```

变量赋值：

```c
int compute(int x) {
    int y = x * 2;
    return y + 1;
}
```

```asm
compute:
    lea eax, [rdi+rdi]   ; y = x * 2（lea 比 imul 快）
    inc eax              ; return y + 1
    ret
```

编译器优化后，局部变量可能直接存放在寄存器中，不占用栈空间。

## 函数调用的汇编实现

### 参数传递

```c
void func(int a, int b, int c);

int main() {
    func(1, 2, 3);
    return 0;
}
```

x86-64 汇编（System V ABI）：

```asm
main:
    sub rsp, 8          ; 对齐栈
    mov edi, 1          ; 第一个参数
    mov esi, 2          ; 第二个参数
    mov edx, 3          ; 第三个参数
    call func
    xor eax, eax        ; 返回 0
    add rsp, 8
    ret
```

### 返回值

```c
int get_value() {
    return 42;
}
```

```asm
get_value:
    mov eax, 42
    ret
```

返回值通过 EAX/RAX 返回。如果返回值是结构体，调用者分配空间，将地址作为隐式参数传递。

## 局部变量与栈帧

### 栈帧结构

```c
int func(int a, int b) {
    int x = a + b;
    int y = x * 2;
    return y;
}
```

```
高地址
+----------------+
|    参数 b      |  [ebp+12]
+----------------+
|    参数 a      |  [ebp+8]
+----------------+
|   返回地址     |  [ebp+4]
+----------------+
|   保存的 ebp   |  [ebp]      <-- ebp 指向这里
+----------------+
|    局部变量 x  |  [ebp-4]
+----------------+
|    局部变量 y  |  [ebp-8]
+----------------+  <-- esp 指向这里
低地址
```

### 汇编实现

```asm
func:
    push ebp
    mov ebp, esp
    sub esp, 8          ; 分配局部变量空间

    mov eax, [ebp+8]    ; a
    add eax, [ebp+12]   ; a + b
    mov [ebp-4], eax    ; x = a + b

    shl eax, 1          ; x * 2
    mov [ebp-8], eax    ; y = x * 2

    mov esp, ebp
    pop ebp
    ret
```

### 优化后

编译器开启优化（-O2）后，局部变量可能直接使用寄存器，不存储到栈：

```asm
func:
    lea eax, [rdi+rsi]  ; a + b
    lea eax, [rax+rax]  ; * 2
    ret
```

## 数组与指针的汇编视角

### 数组访问

```c
int arr[5] = {1, 2, 3, 4, 5};

int get_element(int index) {
    return arr[index];
}
```

```asm
get_element:
    mov eax, [arr + rdi*4]  ; arr[index]，每个元素 4 字节
    ret
```

### 指针运算

```c
int sum_array(int *arr, int n) {
    int sum = 0;
    for (int i = 0; i < n; i++) {
        sum += arr[i];
    }
    return sum;
}
```

```asm
sum_array:
    xor eax, eax        ; sum = 0
    test esi, esi       ; n == 0 ?
    jle .end

    xor ecx, ecx        ; i = 0
.loop:
    add eax, [rdi+rcx*4]; sum += arr[i]
    inc ecx
    cmp ecx, esi
    jl .loop

.end:
    ret
```

### 指针与数组

指针和数组访问生成的汇编代码相似：

```c
int arr[10];

// 这两种写法生成的汇编相同
int x = arr[5];
int y = *(arr + 5);
```

```asm
mov eax, [arr + 20]  ; 5 * 4 = 20
```

## 结构体

### 内存布局

```c
struct Point {
    int x;
    int y;
};

struct Point p = {10, 20};
```

```
偏移  内容
+--------+
|   10   |  p.x  (+0)
+--------+
|   20   |  p.y  (+4)
+--------+
```

### 访问成员

```c
int get_x(struct Point *p) {
    return p->x;
}

int get_y(struct Point *p) {
    return p->y;
}
```

```asm
get_x:
    mov eax, [rdi]      ; p->x 在偏移 0
    ret

get_y:
    mov eax, [rdi+4]    ; p->y 在偏移 4
    ret
```

### 结构体作为参数和返回值

较小的结构体可能通过寄存器传递：

```c
struct Point create_point(int x, int y) {
    struct Point p = {x, y};
    return p;
}
```

较大结构体通过隐式指针参数传递：

```c
struct Big {
    int data[100];
};

struct Big get_big() {
    struct Big b;
    // ...
    return b;  // 调用者分配空间，地址作为隐式参数
}
```

## 反汇编分析基本方法

### 使用 objdump

```bash
# 反汇编可执行文件
objdump -d program

# 反汇编并显示源码（需要编译时加 -g）
objdump -d -S program

# 只反汇编特定函数
objdump -d program | sed -n '/<func>:/,/^$/p'
```

### 使用 gdb

```bash
gdb program

(gdb) disassemble main    # 反汇编 main 函数
(gdb) info registers      # 查看寄存器
(gdb) x/10x $rsp          # 查看栈内容（16 进制，10 个单位）
(gdb) x/s "hello"         # 查看字符串
(gdb) info frame          # 查看当前栈帧信息
```

### 调试技巧

在 C 代码中插入断点：

```c
void debug_break() {
    __asm__ volatile("int $3");  // 触发断点
}
```

查看变量的地址和内存：

```bash
(gdb) print &variable
(gdb) x/4xb &variable    # 以 16 进制显示 4 字节
```

### 常见模式识别

**循环**：通常是一个标签 + 条件跳转回开头

```asm
.loop:
    ; 循环体
    dec ecx
    jnz .loop
```

**条件分支**：CMP + 条件跳转

```asm
    cmp eax, ebx
    jg .greater
    ; eax <= ebx 的情况
    jmp .end
.greater:
    ; eax > ebx 的情况
.end:
```

**函数调用**：PUSH 参数 + CALL + 清理栈（32 位）

```asm
    push 2
    push 1
    call func
    add esp, 8
```

## 内联汇编

在 C 代码中嵌入汇编，用于性能优化或访问特殊指令。

### 基本格式（GCC）

```c
__asm__ (
    "汇编代码"
    : 输出操作数
    : 输入操作数
    : 被破坏的寄存器
);
```

### 示例

```c
int add(int a, int b) {
    int result;
    __asm__ (
        "add %1, %0"
        : "=r" (result)    // 输出：%0
        : "r" (a), "0" (b) // 输入：%1=a, %0 初始值为 b
    );
    return result;
}
```

读取 CPU 时间戳计数器：

```c
static inline unsigned long long rdtsc() {
    unsigned int lo, hi;
    __asm__ volatile (
        "rdtsc"
        : "=a" (lo), "=d" (hi)
    );
    return ((unsigned long long)hi << 32) | lo;
}
```

注意：内联汇编降低可移植性，应谨慎使用。编译器内置函数通常是更好的选择。

```c
// 编译器内置函数，更可取
int count = __builtin_popcount(x);  // 统计 1 的个数
```
