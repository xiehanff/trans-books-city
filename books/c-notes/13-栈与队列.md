# 栈与队列

栈和队列是两种基本的数据结构，限制元素的存取方式。栈是"后进先出"，队列是"先进先出"。

## 栈的概念与数组实现

栈（Stack）只允许在一端（栈顶）进行插入和删除操作。

```
入栈顺序：A → B → C
栈中状态：[C, B, A]  （C在栈顶）
出栈顺序：C → B → A

特性：后进先出（LIFO，Last In First Out）
```

栈的基本操作：
- push：入栈，将元素放入栈顶
- pop：出栈，移除并返回栈顶元素
- peek：查看栈顶元素，不移除
- is_empty：判断栈是否为空

## 栈的基本操作实现

用数组实现一个固定大小的栈：

```c
#include <stdio.h>
#include <stdlib.h>

#define MAX_SIZE 100

typedef struct {
    int data[MAX_SIZE];
    int top;  // 栈顶指针，-1表示空栈
} Stack;

// 初始化栈
void stack_init(Stack* s) {
    s->top = -1;
}

// 判断栈是否为空
int stack_is_empty(Stack* s) {
    return s->top == -1;
}

// 判断栈是否已满
int stack_is_full(Stack* s) {
    return s->top == MAX_SIZE - 1;
}

// 入栈
void stack_push(Stack* s, int value) {
    if (stack_is_full(s)) {
        printf("栈已满，无法入栈\n");
        return;
    }
    s->data[++s->top] = value;
}

// 出栈
int stack_pop(Stack* s) {
    if (stack_is_empty(s)) {
        printf("栈为空，无法出栈\n");
        exit(1);
    }
    return s->data[s->top--];
}

// 查看栈顶元素
int stack_peek(Stack* s) {
    if (stack_is_empty(s)) {
        printf("栈为空\n");
        exit(1);
    }
    return s->data[s->top];
}
```

使用示例：

```c
int main(void) {
    Stack s;
    stack_init(&s);

    stack_push(&s, 10);
    stack_push(&s, 20);
    stack_push(&s, 30);

    printf("栈顶：%d\n", stack_peek(&s));     // 30
    printf("出栈：%d\n", stack_pop(&s));      // 30
    printf("出栈：%d\n", stack_pop(&s));      // 20
    printf("栈空：%d\n", stack_is_empty(&s)); // 0（假）

    return 0;
}
```

## 栈的应用：括号匹配

检查表达式中的括号是否匹配：

```c
int is_bracket_match(const char* expr) {
    Stack s;
    stack_init(&s);

    for (int i = 0; expr[i] != '\0'; i++) {
        char c = expr[i];
        // 左括号入栈
        if (c == '(' || c == '[' || c == '{') {
            stack_push(&s, c);
        }
        // 右括号检查匹配
        else if (c == ')' || c == ']' || c == '}') {
            if (stack_is_empty(&s)) {
                return 0;  // 没有匹配的左括号
            }
            char top = stack_pop(&s);
            if ((c == ')' && top != '(') ||
                (c == ']' && top != '[') ||
                (c == '}' && top != '{')) {
                return 0;  // 括号不匹配
            }
        }
    }

    return stack_is_empty(&s);  // 栈空则全部匹配
}
```

## 队列的概念与数组实现

队列（Queue）在一端（队尾）插入元素，在另一端（队头）删除元素。

```
入队顺序：A → B → C
队列状态：[A, B, C]  （A在队头，C在队尾）
出队顺序：A → B → C

特性：先进先出（FIFO，First In First Out）
```

队列的基本操作：
- enqueue：入队，将元素放入队尾
- dequeue：出队，移除并返回队头元素
- front：查看队头元素
- is_empty：判断队列是否为空

## 队列的数组实现

简单实现（非循环，空间利用率低）：

```c
#define MAX_SIZE 100

typedef struct {
    int data[MAX_SIZE];
    int front;  // 队头指针
    int rear;   // 队尾指针（最后一个元素的下一个位置）
} Queue;

void queue_init(Queue* q) {
    q->front = 0;
    q->rear = 0;
}

int queue_is_empty(Queue* q) {
    return q->front == q->rear;
}

int queue_is_full(Queue* q) {
    return q->rear == MAX_SIZE;
}

void queue_enqueue(Queue* q, int value) {
    if (queue_is_full(q)) {
        printf("队列已满\n");
        return;
    }
    q->data[q->rear++] = value;
}

int queue_dequeue(Queue* q) {
    if (queue_is_empty(q)) {
        printf("队列为空\n");
        exit(1);
    }
    return q->data[q->front++];
}
```

问题：出队后`front`后移，前面的空间无法再利用。

## 循环队列

循环队列把数组首尾相连，解决空间浪费问题。

```c
#define MAX_SIZE 5  // 实际容量为 MAX_SIZE - 1

typedef struct {
    int data[MAX_SIZE];
    int front;
    int rear;
} CircularQueue;

void cqueue_init(CircularQueue* q) {
    q->front = 0;
    q->rear = 0;
}

int cqueue_is_empty(CircularQueue* q) {
    return q->front == q->rear;
}

// 牺牲一个存储单元来区分空和满
int cqueue_is_full(CircularQueue* q) {
    return (q->rear + 1) % MAX_SIZE == q->front;
}

void cqueue_enqueue(CircularQueue* q, int value) {
    if (cqueue_is_full(q)) {
        printf("循环队列已满\n");
        return;
    }
    q->data[q->rear] = value;
    q->rear = (q->rear + 1) % MAX_SIZE;
}

int cqueue_dequeue(CircularQueue* q) {
    if (cqueue_is_empty(q)) {
        printf("循环队列为空\n");
        exit(1);
    }
    int value = q->data[q->front];
    q->front = (q->front + 1) % MAX_SIZE;
    return value;
}

int cqueue_front(CircularQueue* q) {
    if (cqueue_is_empty(q)) {
        printf("循环队列为空\n");
        exit(1);
    }
    return q->data[q->front];
}
```

使用示例：

```c
int main(void) {
    CircularQueue q;
    cqueue_init(&q);

    cqueue_enqueue(&q, 1);
    cqueue_enqueue(&q, 2);
    cqueue_enqueue(&q, 3);
    cqueue_enqueue(&q, 4);  // 队列满（容量为4）

    printf("出队：%d\n", cqueue_dequeue(&q));  // 1
    printf("出队：%d\n", cqueue_dequeue(&q));  // 2

    cqueue_enqueue(&q, 5);  // 入队成功（复用空间）
    cqueue_enqueue(&q, 6);  // 再次满

    return 0;
}
```

关键点：
- 取模运算实现循环：`(index + 1) % MAX_SIZE`
- 牺牲一个单元区分空和满：rear追上front时为满，front等于rear时为空
- 实际容量为 `MAX_SIZE - 1`

## 栈与队列对比

| 特性 | 栈 | 队列 |
|------|-----|------|
| 存取规则 | 后进先出（LIFO） | 先进先出（FIFO） |
| 入操作 | push（栈顶） | enqueue（队尾） |
| 出操作 | pop（栈顶） | dequeue（队头） |
| 典型应用 | 函数调用栈、括号匹配、表达式求值 | 任务调度、缓冲区、BFS |

## 用两个栈实现队列

栈和队列可以互相实现：

```c
typedef struct {
    Stack s1;  // 入队栈
    Stack s2;  // 出队栈
} QueueByStacks;

void qbs_init(QueueByStacks* q) {
    stack_init(&q->s1);
    stack_init(&q->s2);
}

void qbs_enqueue(QueueByStacks* q, int value) {
    stack_push(&q->s1, value);
}

int qbs_dequeue(QueueByStacks* q) {
    if (stack_is_empty(&q->s2)) {
        // 将s1所有元素倒入s2
        while (!stack_is_empty(&q->s1)) {
            stack_push(&q->s2, stack_pop(&q->s1));
        }
    }
    return stack_pop(&q->s2);
}
```

原理：s1入栈的元素，倒入s2后顺序反转，实现了先进先出。
