# 数组与字符串

数组是存储多个同类型数据的连续内存空间。字符串是字符数组的特殊形式，以空字符`\0`结尾。

## 一维数组定义与初始化

数组定义需要指定类型和长度。

```c
int arr[5];  // 声明一个包含5个int的数组，内容未初始化
```

初始化方式：

```c
// 完全初始化
int arr1[5] = {1, 2, 3, 4, 5};

// 部分初始化，剩余元素为0
int arr2[5] = {1, 2};  // {1, 2, 0, 0, 0}

// 初始化为全0
int arr3[5] = {0};

// 自动确定长度
int arr4[] = {1, 2, 3, 4, 5};  // 长度为5
```

C99支持指定位置初始化：

```c
int arr[5] = {[0] = 1, [2] = 3};  // {1, 0, 3, 0, 0}
```

## 数组遍历与越界

用下标访问数组元素，下标从0开始。

```c
int arr[5] = {10, 20, 30, 40, 50};

printf("%d\n", arr[0]);  // 10（第一个元素）
printf("%d\n", arr[4]);  // 50（最后一个元素）
```

计算数组长度的常用方法：

```c
int arr[] = {1, 2, 3, 4, 5};
int len = sizeof(arr) / sizeof(arr[0]);  // 5
```

遍历数组：

```c
for (int i = 0; i < len; i++) {
    printf("%d ", arr[i]);
}
```

数组越界是常见错误，C语言不会自动检查：

```c
int arr[5] = {1, 2, 3, 4, 5};
printf("%d\n", arr[5]);   // 越界！访问了数组外的内存
printf("%d\n", arr[-1]);  // 越界！
```

越界的后果不确定：可能读到垃圾值、可能改写其他变量、可能程序崩溃。

## 多维数组

多维数组本质上是数组的数组。

```c
int matrix[3][4];  // 3行4列的二维数组
```

初始化：

```c
// 完全初始化
int matrix[2][3] = {
    {1, 2, 3},
    {4, 5, 6}
};

// 按顺序初始化
int matrix[2][3] = {1, 2, 3, 4, 5, 6};

// 部分初始化
int matrix[2][3] = {{1}, {4}};  // {{1,0,0}, {4,0,0}}
```

遍历二维数组：

```c
int matrix[2][3] = {{1, 2, 3}, {4, 5, 6}};

for (int i = 0; i < 2; i++) {
    for (int j = 0; j < 3; j++) {
        printf("%d ", matrix[i][j]);
    }
    printf("\n");
}
```

多维数组在内存中是按行存储的，理解这一点对理解指针访问很重要：

```c
// matrix在内存中的顺序：1,2,3,4,5,6
// matrix[0][0] -> matrix[0][1] -> matrix[0][2] -> matrix[1][0] -> ...
```

## 数组退化

数组名在大多数表达式中会退化为指向首元素的指针。

```c
int arr[] = {1, 2, 3, 4, 5};
int *p = arr;   // arr 退化为 &arr[0]
```

这也是函数参数里看起来像数组、实际却是指针的原因：

```c
void print_array(int arr[]) {
    printf("%zu\n", sizeof(arr));  // 这里得到的是指针大小
}
```

所以不能在函数参数里用 `sizeof(arr) / sizeof(arr[0])` 计算长度。调用方要把长度一并传进来：

```c
void print_array(int arr[], int len) {
    for (int i = 0; i < len; i++) {
        printf("%d ", arr[i]);
    }
}
```

`sizeof(arr) / sizeof(arr[0])` 只适用于数组本体还在当前作用域的场景：

```c
int arr[] = {1, 2, 3, 4, 5};
size_t len = sizeof(arr) / sizeof(arr[0]);
```

## 字符串的本质

C语言没有专门的字符串类型，字符串是以`\0`结尾的字符数组。

```c
// 这两种写法等价
char str1[] = "hello";       // {'h','e','l','l','o','\0'}
char str2[] = {'h','e','l','l','o','\0'};
```

字符串字面量`"hello"`在内存中占6个字节（5个字符+1个`\0`）。

```c
char str[] = "hello";
printf("%zu\n", sizeof(str));   // 6（数组大小）
printf("%zu\n", strlen(str));   // 5（字符串长度，不含\0）
```

字符指针和字符数组的区别：

```c
// 字符指针：指向字符串字面量，内容不应修改
const char *s1 = "hello";
s1[0] = 'H';  // 错误！可能崩溃

// 字符数组：复制到栈上，内容可修改
char s2[] = "hello";
s2[0] = 'H';  // 正确
```

## 字符串输入输出

**输出字符串**：

```c
char str[] = "hello";

printf("%s\n", str);  // 打印到\0为止
puts(str);            // 自动加换行
```

**输入字符串**：

```c
char str[100];

scanf("%s", str);     // 遇空格停止，不读空格
// 注意：不需要&str，str本身是地址

gets(str);            // 读取一行，但不安全（已弃用）
fgets(str, 100, stdin);  // 安全读取一行，包含换行符
```

`fgets`更安全，因为它限制了读取的最大字符数：

```c
char str[10];
fgets(str, sizeof(str), stdin);  // 最多读9个字符+1个\0
```

## 字符串函数

需要包含`<string.h>`头文件。

### strlen - 字符串长度

返回字符串长度（不含`\0`）。

```c
char str[] = "hello";
printf("%zu\n", strlen(str));  // 5
```

### strcpy - 字符串复制

将源字符串复制到目标数组。

```c
char dest[20];
char src[] = "hello";
strcpy(dest, src);
printf("%s\n", dest);  // hello
```

目标数组必须足够大，否则会溢出。使用`strncpy`更安全：

```c
char dest[5];
strncpy(dest, "hello world", sizeof(dest) - 1);
dest[sizeof(dest) - 1] = '\0';  // 手动添加结束符
```

### strcat - 字符串连接

将源字符串追加到目标字符串末尾。

```c
char str[20] = "hello";
strcat(str, " world");
printf("%s\n", str);  // hello world
```

目标数组必须足够大。使用`strncat`更安全：

```c
char str[10] = "hello";
strncat(str, " world", sizeof(str) - strlen(str) - 1);
```

### strcmp - 字符串比较

比较两个字符串，返回比较结果。

```c
strcmp("abc", "abc");  // 返回0（相等）
strcmp("abc", "abd");  // 返回负数（abc < abd）
strcmp("abd", "abc");  // 返回正数（abd > abc）
```

判断两个字符串是否相等：

```c
if (strcmp(s1, s2) == 0) {
    printf("相等\n");
}
```

### strchr - 查找字符

在字符串中查找字符，返回首次出现的位置（指针）。

```c
char str[] = "hello";
char* p = strchr(str, 'l');
if (p != NULL) {
    printf("找到：%s\n", p);  // llo
}
```

### strstr - 查找子串

在字符串中查找子串。

```c
char str[] = "hello world";
char* p = strstr(str, "world");
if (p != NULL) {
    printf("找到：%s\n", p);  // world
}
```

### sprintf - 格式化字符串

将格式化数据写入字符串。

```c
char buffer[100];
int score = 85;
sprintf(buffer, "分数是%d分", score);
printf("%s\n", buffer);  // 分数是85分
```

### 其他常用函数

```c
// 大小写转换（需要<ctype.h>）
char c = 'a';
toupper(c);  // 'A'
tolower('A');  // 'a'

// 检查字符类型
isalpha('a');   // 非零（字母）
isdigit('5');   // 非零（数字）
isspace(' ');   // 非零（空白字符）
```

## 字符串数组

存储多个字符串有两种方式：二维字符数组或指针数组。

**二维字符数组**：

```c
char fruits[3][10] = {
    "apple",
    "banana",
    "orange"
};
```

**指针数组**：

```c
char* fruits[] = {
    "apple",
    "banana",
    "orange"
};
```

指针数组更节省空间，但字符串内容不可修改。
