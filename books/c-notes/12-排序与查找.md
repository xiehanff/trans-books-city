# 排序与查找

排序是将数据按特定顺序排列，查找是在数据中定位目标。这是两个经典的算法问题。

## 冒泡排序

冒泡排序通过反复交换相邻的逆序对，让较大的元素逐渐"冒泡"到数组末端。

```c
void bubble_sort(int arr[], int n) {
    for (int i = 0; i < n - 1; i++) {
        for (int j = 0; j < n - 1 - i; j++) {
            if (arr[j] > arr[j + 1]) {
                // 交换相邻元素
                int temp = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = temp;
            }
        }
    }
}
```

执行过程（从小到大排序）：

```
初始：5  3  8  1  2
第1轮：3  5  1  2  8
第2轮：3  1  2  5  8
第3轮：1  2  3  5  8
第4轮：1  2  3  5  8（已有序）
```

优化：如果某轮没有发生交换，说明已经有序。

```c
void bubble_sort_optimized(int arr[], int n) {
    for (int i = 0; i < n - 1; i++) {
        int swapped = 0;
        for (int j = 0; j < n - 1 - i; j++) {
            if (arr[j] > arr[j + 1]) {
                int temp = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = temp;
                swapped = 1;
            }
        }
        if (!swapped) break;  // 已有序，提前结束
    }
}
```

时间复杂度：O(n^2)

## 选择排序

选择排序每轮从未排序部分选出最小元素，放到已排序部分末尾。

```c
void selection_sort(int arr[], int n) {
    for (int i = 0; i < n - 1; i++) {
        // 找最小元素的下标
        int min_idx = i;
        for (int j = i + 1; j < n; j++) {
            if (arr[j] < arr[min_idx]) {
                min_idx = j;
            }
        }
        // 交换到已排序部分末尾
        int temp = arr[i];
        arr[i] = arr[min_idx];
        arr[min_idx] = temp;
    }
}
```

执行过程：

```
初始：5  3  8  1  2
第1轮：1 | 3  8  5  2  （选1，放到开头）
第2轮：1  2 | 8  5  3  （选2）
第3轮：1  2  3 | 5  8  （选3）
第4轮：1  2  3  5 | 8  （选5）
```

时间复杂度：O(n^2)。交换次数比冒泡少，但比较次数相同。

## 插入排序

插入排序将元素逐个插入已排序部分的正确位置，类似整理扑克牌。

```c
void insertion_sort(int arr[], int n) {
    for (int i = 1; i < n; i++) {
        int key = arr[i];  // 待插入元素
        int j = i - 1;
        // 将比key大的元素后移
        while (j >= 0 && arr[j] > key) {
            arr[j + 1] = arr[j];
            j--;
        }
        arr[j + 1] = key;  // 插入到正确位置
    }
}
```

执行过程：

```
初始：  5  3  8  1  2
插3：   3  5  8  1  2
插8：   3  5  8  1  2  （8已在正确位置）
插1：   1  3  5  8  2
插2：   1  2  3  5  8
```

时间复杂度：O(n^2)，但对接近有序的数组效率很高。

## 快速排序

快速排序选一个基准值，把数组分成两部分，再递归处理左右两边。

```c
static int partition(int arr[], int left, int right) {
    int pivot = arr[right];
    int i = left;

    for (int j = left; j < right; j++) {
        if (arr[j] <= pivot) {
            int temp = arr[i];
            arr[i] = arr[j];
            arr[j] = temp;
            i++;
        }
    }

    int temp = arr[i];
    arr[i] = arr[right];
    arr[right] = temp;
    return i;
}

void quick_sort(int arr[], int left, int right) {
    if (left >= right) return;

    int mid = partition(arr, left, right);
    quick_sort(arr, left, mid - 1);
    quick_sort(arr, mid + 1, right);
}
```

平均时间复杂度是 `O(n log n)`，最坏情况是 `O(n^2)`。它通常比前面的 `O(n^2)` 排序快得多，但不是稳定排序。

## 归并排序

归并排序把数组不断二分，再把两个有序子数组合并起来。

```c
static void merge(int arr[], int temp[], int left, int mid, int right) {
    int i = left;
    int j = mid + 1;
    int k = left;

    while (i <= mid && j <= right) {
        if (arr[i] <= arr[j]) {
            temp[k++] = arr[i++];
        } else {
            temp[k++] = arr[j++];
        }
    }

    while (i <= mid) temp[k++] = arr[i++];
    while (j <= right) temp[k++] = arr[j++];

    for (int t = left; t <= right; t++) {
        arr[t] = temp[t];
    }
}

void merge_sort(int arr[], int temp[], int left, int right) {
    if (left >= right) return;

    int mid = left + (right - left) / 2;
    merge_sort(arr, temp, left, mid);
    merge_sort(arr, temp, mid + 1, right);
    merge(arr, temp, left, mid, right);
}
```

归并排序的时间复杂度是 `O(n log n)`，而且是稳定排序。缺点是需要额外的 `O(n)` 空间。

## 排序算法比较

| 算法 | 平均时间 | 最坏时间 | 空间 | 稳定性 |
|------|----------|----------|------|--------|
| 冒泡排序 | O(n^2) | O(n^2) | O(1) | 稳定 |
| 选择排序 | O(n^2) | O(n^2) | O(1) | 不稳定 |
| 插入排序 | O(n^2) | O(n^2) | O(1) | 稳定 |
| 快速排序 | O(n log n) | O(n^2) | O(log n) | 不稳定 |
| 归并排序 | O(n log n) | O(n log n) | O(n) | 稳定 |

稳定性：相等元素的相对位置是否保持不变。例如 `[3a, 2, 3b]` 排序后是否还为 `3a, 3b`。

## 顺序查找

逐个检查每个元素，直到找到目标或遍历完整个数组。

```c
int linear_search(int arr[], int n, int target) {
    for (int i = 0; i < n; i++) {
        if (arr[i] == target) {
            return i;  // 找到，返回下标
        }
    }
    return -1;  // 未找到
}
```

适用于无序数组。时间复杂度O(n)。

## 二分查找

二分查找要求数组有序，每次将搜索范围缩小一半。

```c
int binary_search(int arr[], int n, int target) {
    int left = 0;
    int right = n - 1;

    while (left <= right) {
        int mid = left + (right - left) / 2;  // 避免溢出

        if (arr[mid] == target) {
            return mid;  // 找到
        } else if (arr[mid] < target) {
            left = mid + 1;  // 目标在右半边
        } else {
            right = mid - 1; // 目标在左半边
        }
    }

    return -1;  // 未找到
}
```

执行过程（在有序数组中查找7）：

```
数组：1  3  5  7  9  11  13

第1轮：left=0, right=6, mid=3, arr[3]=7 → 找到！
```

另一个例子（查找4）：

```
数组：1  3  5  7  9  11  13

第1轮：left=0, right=6, mid=3, arr[3]=7 > 4 → right=2
第2轮：left=0, right=2, mid=1, arr[1]=3 < 4 → left=2
第3轮：left=2, right=2, mid=2, arr[2]=5 > 4 → right=1
left > right，未找到
```

时间复杂度：O(log n)

**计算mid的陷阱**：

```c
// 可能溢出
int mid = (left + right) / 2;

// 推荐写法
int mid = left + (right - left) / 2;
```

## 二分查找的变体

**查找第一个等于目标的元素**（有重复元素时）：

```c
int find_first(int arr[], int n, int target) {
    int left = 0, right = n - 1;
    int result = -1;

    while (left <= right) {
        int mid = left + (right - left) / 2;

        if (arr[mid] == target) {
            result = mid;
            right = mid - 1;  // 继续向左找
        } else if (arr[mid] < target) {
            left = mid + 1;
        } else {
            right = mid - 1;
        }
    }

    return result;
}
```

**查找第一个大于目标的元素**：

```c
int find_first_greater(int arr[], int n, int target) {
    int left = 0, right = n - 1;

    while (left <= right) {
        int mid = left + (right - left) / 2;

        if (arr[mid] <= target) {
            left = mid + 1;
        } else {
            right = mid - 1;
        }
    }

    return left < n ? left : -1;
}
```

## 查找算法比较

| 算法 | 时间复杂度 | 空间复杂度 | 要求 |
|------|------------|------------|------|
| 顺序查找 | O(n) | O(1) | 无 |
| 二分查找 | O(log n) | O(1) | 数组有序 |

实际应用中，如果只查找一次，直接顺序查找即可。如果需要多次查找，先排序再二分查找更高效。
