## 前言

传统的计算机科学学位通常包含操作系统、编译器和数据库等课程，它们用代码取代神秘感。这些课程把 Linux、Postgres 和 LLVM 变成对一个可理解的核心架构所做的改进、扩充与优化。这一课的意义超越了所学习的具体系统：所有计算机系统，无论多么庞大、看似多么复杂，都是可以研究和理解的。

但网页浏览器至今仍是不透明的，不仅对学生如此，对工业界程序员、甚至对研究者也是如此。本书通过系统性地讲解现代浏览器的所有主要组件，来驱散这层神秘感。

### 如何阅读本书

本书第 2–4 部分将构建一个基础浏览器，代码量约为 1000 行，做完习题后翻倍。对于有几年编程经验的读者，平均每章需要 4–6 小时来阅读、实现和调试。本书第 5 部分涵盖高级主题；这些章节篇幅更长，代码也更多。最终的浏览器代码量约为 3000 行。

你的浏览器¹ 在每一步都会“工作”，而且每一章都会在上一章的基础上继续构建。² 这样，你还能顺便练习如何扩展和改进复杂软件。如果你对某个组件特别感兴趣，请务必把它充实完善、完成习题、补上缺失的功能。我们已尽量合理安排，使这样做不会让后续章节变得更难。

本书的代码使用 Python 3 [3]，我们也建议你用同样的语言跟着做。书中展示 Python 命令行时，调用的 Python 可执行文件是 python3。³ 话虽如此，正文已尽量避免依赖，你也可以尝试用其他语言跟着实现。请确保你的语言有支持 TLS 连接的库（Python 自带一个）、图形库（书中使用了 Tk、Skia 和 SDL），以及 JavaScript 执行库（书中使用了 DukPy）。

本书的浏览器对标准并不敬畏：它只处理完整的 HTML、CSS 和 JavaScript 语言中的一小部分，会错误地处理出错情形，也无法抵御恶意输入。它还相当慢。尽管如此，它的架构与真实浏览器一致，能让你洞悉那些上千万行代码的庞然大物。

话虽如此，当本书的浏览器做了简化或偏离标准时，我们已尽量明确指出。如果你不确定你的浏览器在某个边界情况（edge case）下应如何表现，打开你最喜欢的网页浏览器试一下就好。

## 脚注

¹ 本书假设你会在阅读过程中一路构建一个网页浏览器。不过，书中确实为每一章给出了一个可运行浏览器所需的几乎全部代码——直接内嵌在书中。因此，大多数时候书中使用“我们的浏览器”（our browser）这一说法，指的是我们（你和本书作者）到目前为止构建的那个概念上的浏览器；而当书中专门指你所构建的那份实现时，则会说“你的浏览器”（your browser）。

² 这一想法来自 J. R. Wilcox [1]，其灵感又源自 S. Zdancewic [2] 的编译器课程。

³ 这是为了表述清晰。在某些操作系统上，python 指的是 Python 3，而在另一些系统上则指 Python 2。请确认你安装的是哪个版本！
