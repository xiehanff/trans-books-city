# 第17章 计算机体系结构基础

理解程序如何在硬件上运行，需要先了解计算机的基本组成和工作原理。

## 冯·诺依曼架构

现代计算机大多基于冯·诺依曼体系结构，核心思想是"存储程序"。

### 三大组成部分

```
+-------------+     +-------------+     +-------------+
|    CPU      | <=> |    内存     | <=> |   I/O设备   |
+-------------+     +-------------+     +-------------+
```

**CPU（中央处理器）**：执行指令，进行运算。

**内存**：存储程序和数据。

**I/O 设备**：输入输出，与外部交互。

### 存储程序原理

程序和数据以二进制形式存储在同一内存中，CPU 从内存中逐条取出指令执行。这意味着程序本身也是数据，可以被其他程序处理（如编译器）。

### 冯·诺依曼瓶颈

CPU 和内存通过总线连接，速度差异导致 CPU 经常等待内存，这被称为冯·诺依曼瓶颈。现代 CPU 使用高速缓存缓解这个问题。

## CPU

CPU 是计算机的核心，负责执行指令和处理数据。

### 组成部分

**运算器（ALU）**：执行算术运算和逻辑运算。

**控制器**：取指令、译码、控制执行流程。

**寄存器组**：高速存储单元，暂存操作数和结果。

### 工作流程

```
取指令 -> 译码 -> 执行 -> 写回 -> 取指令 -> ...
```

1. **取指令**：从内存中读取下一条指令到 CPU
2. **译码**：分析指令含义，确定操作类型
3. **执行**：ALU 执行相应运算
4. **写回**：将结果写回寄存器或内存

### 指令周期

执行一条指令所需的时间称为指令周期。不同指令的周期不同，简单指令可能只需 1 个时钟周期，复杂指令可能需要多个。

## 内存

内存是程序运行时数据和指令的存储场所。

### 内存地址

内存以字节为单位编址。32 位系统可寻址 4GB 内存（2³² 字节），64 位系统理论上可寻址 16EB（2⁶⁴ 字节），但实际受硬件限制。

```c
#include <stdio.h>

int main() {
    int x = 10;
    printf("x 的地址: %p\n", (void*)&x);
    printf("指针大小: %zu 字节\n", sizeof(void*));
    return 0;
}
```

### 字节序

多字节数据在内存中的存储顺序。

**小端序（Little-Endian）**：低位字节存放在低地址。x86、ARM 等常用架构采用小端序。

**大端序（Big-Endian）**：高位字节存放在低地址。网络协议通常使用大端序（网络字节序）。

```
数值 0x12345678 在内存中的存储：

小端序（地址从低到高）:
| 0x78 | 0x56 | 0x34 | 0x12 |

大端序（地址从低到高）:
| 0x12 | 0x34 | 0x56 | 0x78 |
```

检测当前系统的字节序：

```c
#include <stdio.h>

int main() {
    int x = 1;
    char *p = (char*)&x;

    if (*p == 1) {
        printf("小端序\n");
    } else {
        printf("大端序\n");
    }
    return 0;
}
```

### 内存对齐

CPU 访问内存时，数据地址通常需要是对齐的。访问未对齐的数据可能导致性能下降甚至程序崩溃。

```c
struct A {
    char a;   // 1 字节
    // 3 字节填充
    int b;    // 4 字节，需要 4 字节对齐
};

printf("%zu\n", sizeof(struct A));  // 8，不是 5
```

## 总线

总线是连接各组件的通信线路。

### 数据总线

传输数据，宽度决定一次能传输的数据量。64 位数据总线一次可传输 8 字节。

### 地址总线

传输地址信息，宽度决定可寻址空间大小。32 根地址线可寻址 4GB。

### 控制总线

传输控制信号，如读/写信号、中断请求等。

## 寄存器

寄存器是 CPU 内部的高速存储单元，访问速度远超内存。

### 通用寄存器

用于存放操作数和运算结果。不同架构寄存器数量和命名不同。

**x86-32**：EAX、EBX、ECX、EDX、ESI、EDI、EBP、ESP（8 个）

**x86-64**：RAX、RBX、RCX、RDX、RSI、RDI、RBP、RSP，以及 R8-R15（16 个）

**ARM**：R0-R15（16 个）

### 特殊寄存器

**程序计数器（PC/IP）**：存放下一条指令的地址。

**栈指针（SP）**：指向栈顶。

**帧指针（FP/BP）**：指向当前栈帧底部。

**状态寄存器（FLAGS/PSR）**：存储条件码（零标志、进位标志等）。

### 寄存器与变量的关系

C 语言中的局部变量通常存储在寄存器或栈中。编译器优化时会尽量使用寄存器以提高速度。

```c
void func() {
    register int x = 10;  // 建议编译器使用寄存器（现代编译器通常忽略）
    int y = 20;           // 可能存储在寄存器或栈中
}
```

## 指令执行过程

以执行 `add a, b`（将 b 加到 a）为例：

```
1. 取指：PC -> 地址总线 -> 内存 -> 指令寄存器
2. 译码：控制器解析指令为"加法操作"
3. 取操作数：读取 a 和 b 的值
4. 执行：ALU 计算 a + b
5. 写回：结果写入目标寄存器
6. 更新 PC：PC 指向下一条指令
```

### 流水线

现代 CPU 使用流水线技术，多条指令的不同阶段并行执行，提高吞吐量。

```
指令1: 取指 | 译码 | 执行 | 写回 |
指令2:      | 取指 | 译码 | 执行 | 写回 |
指令3:      |      | 取指 | 译码 | 执行 | 写回 |
```

分支预测、乱序执行等技术进一步提升了性能。

## 存储层次结构

从快到慢、从小到大、从贵到便宜：

```
+-------------------+
|  CPU 寄存器       |  ~1ns, ~几百字节
+-------------------+
|  L1 Cache         |  ~2ns, ~32KB
+-------------------+
|  L2 Cache         |  ~4ns, ~256KB
+-------------------+
|  L3 Cache         |  ~10ns, ~几MB
+-------------------+
|  主内存           |  ~100ns, ~几GB到几TB
+-------------------+
|  SSD              |  ~10μs, ~几百GB到几TB
+-------------------+
|  HDD              |  ~10ms, ~几TB
+-------------------+
```

### 局部性原理

程序访问内存具有良好的局部性，这是缓存有效的基础。

**时间局部性**：刚访问的数据不久后可能再次访问。

```c
for (int i = 0; i < 1000; i++) {
    sum += arr[i];  // sum 被反复访问
}
```

**空间局部性**：访问某位置后，附近位置很可能被访问。

```c
for (int i = 0; i < 1000; i++) {
    sum += arr[i];  // 顺序访问数组
}
```

### 缓存命中率

缓存命中时数据从缓存读取，未命中时从更慢的存储读取。优化程序时提高缓存命中率是重要手段。

```c
// 低效：跳跃访问，缓存命中率低
for (int j = 0; j < COLS; j++) {
    for (int i = 0; i < ROWS; i++) {
        sum += matrix[i][j];
    }
}

// 高效：顺序访问，缓存命中率高
for (int i = 0; i < ROWS; i++) {
    for (int j = 0; j < COLS; j++) {
        sum += matrix[i][j];
    }
}
```

## 中断

中断是外部事件打断 CPU 正常执行流程的机制。

### 中断类型

**硬件中断**：外设产生的中断，如键盘输入、磁盘读写完成。

**软件中断**：程序主动触发，如系统调用。

**异常**：程序执行过程中产生的，如除零错误、缺页异常。

### 中断处理过程

```
1. 保存当前上下文（寄存器、PC 等）
2. 查找中断向量表，跳转到中断处理程序
3. 执行中断处理程序
4. 恢复上下文，返回被中断的程序继续执行
```

### 系统调用

用户程序通过系统调用请求操作系统服务，如文件操作、网络通信。系统调用涉及从用户态切换到内核态。

```c
#include <unistd.h>
#include <sys/syscall.h>

int main() {
    // 使用库函数（内部通过系统调用实现）
    write(1, "Hello\n", 6);

    // 直接使用系统调用
    syscall(SYS_write, 1, "Hello\n", 6);

    return 0;
}
```
