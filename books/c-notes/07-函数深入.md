# 函数深入：return、递归与增量式开发

函数是C语言程序的基本组成单元。本章深入讨论return语句、递归，以及如何按增量方式开发函数。

## return 语句详解

`return`有两个作用：结束函数执行，并可选地返回一个值。

```c
int max(int a, int b) {
    if (a > b) {
        return a;
    }
    return b;
}
```

函数可以在多个位置return，执行到任意一个return时立即结束。

```c
int find_index(int arr[], int len, int target) {
    for (int i = 0; i < len; i++) {
        if (arr[i] == target) {
            return i;  // 找到就返回
        }
    }
    return -1;  // 没找到返回-1
}
```

`void`函数可以没有return语句，或者用`return;`提前结束。

```c
void print_positive(int n) {
    if (n <= 0) {
        return;  // 提前退出
    }
    printf("%d\n", n);
}
```

返回值的类型必须与函数声明一致。如果不一致，编译器可能警告或隐式转换。

## 递归的概念与实现

函数直接或间接调用自身，称为递归。递归需要两个要素：

1. 递归公式：将问题分解为更小的同类问题
2. 终止条件：存在最小的子问题可以直接求解

**阶乘的递归实现**：

```c
int factorial(int n) {
    if (n <= 1) {
        return 1;  // 终止条件：0! = 1! = 1
    }
    return n * factorial(n - 1);  // 递归公式：n! = n * (n-1)!
}
```

递归执行过程（以factorial(4)为例）：

```
factorial(4)
  → 4 * factorial(3)
       → 3 * factorial(2)
            → 2 * factorial(1)
                 → 1  (终止)
            ← 2 * 1 = 2
       ← 3 * 2 = 6
  ← 4 * 6 = 24
```

**斐波那契数列**：

斐波那契数列定义：F(1)=1, F(2)=1, F(n)=F(n-1)+F(n-2)

```c
int fib(int n) {
    if (n <= 2) {
        return 1;
    }
    return fib(n - 1) + fib(n - 2);
}
```

这个实现效率很低，因为存在大量重复计算。fib(5)会计算fib(4)和fib(3)，而fib(4)又要计算fib(3)。

## 递归与迭代比较

递归代码简洁直观，但效率通常不如迭代。

**阶乘的迭代实现**：

```c
int factorial_iter(int n) {
    int result = 1;
    for (int i = 2; i <= n; i++) {
        result *= i;
    }
    return result;
}
```

| 特性 | 递归 | 迭代 |
|------|------|------|
| 代码简洁度 | 通常更简洁 | 可能需要更多代码 |
| 空间效率 | 需要栈空间，可能栈溢出 | 只需常数空间 |
| 时间效率 | 可能有重复计算 | 通常更快 |
| 适用场景 | 问题本身递归定义（树、图） | 简单循环问题 |

递归深度过大时，会耗尽栈空间导致栈溢出：

```c
void infinite(int n) {
    printf("%d\n", n);
    infinite(n + 1);  // 没有终止条件，最终栈溢出
}
```

尾递归是一种特殊情况，递归调用是函数最后一步操作。某些编译器可以优化尾递归，转化为迭代：

```c
// 尾递归版本的阶乘
int factorial_tail(int n, int acc) {
    if (n <= 1) {
        return acc;
    }
    return factorial_tail(n - 1, n * acc);
}

// 调用方式
factorial_tail(5, 1);
```

## 增量式开发方法

编写复杂函数时，一下子写完容易出错。增量式开发的思路是：

1. 写一个能运行的骨架
2. 添加少量代码
3. 测试验证
4. 重复步骤2-3

**例子：判断一个数是否为素数**

首先写骨架：

```c
int is_prime(int n) {
    return 0;  // 先让函数能编译通过
}

int main(void) {
    printf("%d\n", is_prime(2));  // 预期1
    printf("%d\n", is_prime(4));  // 预期0
    return 0;
}
```

添加边界条件处理：

```c
int is_prime(int n) {
    if (n <= 1) {
        return 0;
    }
    return 0;
}
```

添加核心逻辑：

```c
int is_prime(int n) {
    if (n <= 1) {
        return 0;
    }
    for (int i = 2; i < n; i++) {
        if (n % i == 0) {
            return 0;  // 找到因子，不是素数
        }
    }
    return 1;  // 没找到因子，是素数
}
```

进一步优化（只需检查到sqrt(n)）：

```c
#include <math.h>

int is_prime(int n) {
    if (n <= 1) {
        return 0;
    }
    for (int i = 2; i * i <= n; i++) {  // i <= sqrt(n)
        if (n % i == 0) {
            return 0;
        }
    }
    return 1;
}
```

## 函数设计原则

**单一职责**：一个函数只做一件事。

```c
// 不好：一个函数做了多件事
void process(int arr[], int len) {
    // 排序
    // 计算平均值
    // 打印结果
}

// 好：拆分成多个函数
void sort(int arr[], int len);
double average(int arr[], int len);
void print_result(int arr[], int len);
```

**输入验证**：在函数开头检查参数有效性。

```c
int find_max(int arr[], int len) {
    if (arr == NULL || len <= 0) {
        return -1;  // 或使用其他错误处理方式
    }
    int max = arr[0];
    for (int i = 1; i < len; i++) {
        if (arr[i] > max) {
            max = arr[i];
        }
    }
    return max;
}
```

**命名清晰**：函数名应说明其功能。

```c
// 不好
int f(int x);
int calc(int a, int b, int c);

// 好
int square(int x);
int max_of_three(int a, int b, int c);
```

**避免副作用**：函数应该尽量通过返回值输出结果，而不是修改参数或全局变量。

```c
// 有副作用：修改了原数组
void to_uppercase(char str[]);

// 无副作用：返回新字符串
char* to_uppercase_copy(const char str[]);
```
