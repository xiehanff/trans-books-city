# 程序、编程语言与第一个程序

## 程序是什么

程序是一组指令的集合，告诉计算机要做什么。就像菜谱告诉厨师做菜的步骤，程序告诉计算机处理的步骤。

程序存储在文件中，计算机逐条执行这些指令，完成特定任务。

## 编程语言

计算机只能理解机器语言——由0和1组成的二进制指令。直接用机器语言写程序极其繁琐：

```
10110000 01100001  // 把数字97放入寄存器
```

编程语言的出现解决了这个问题。它用接近人类语言的方式编写代码，再由编译器翻译成机器语言。

编程语言分为两类：

| 类型 | 特点 | 例子 |
|------|------|------|
| 编译型 | 源代码编译成可执行文件后运行 | C、C++ |
| 解释型 | 逐行翻译执行 | Python、JavaScript |

C语言属于编译型语言。写好源代码后，需要编译器将其编译成可执行文件，然后才能运行。

## C语言简介

C语言诞生于1972年，由Dennis Ritchie在贝尔实验室开发。它的设计目标是：

- 提供对硬件的直接控制能力
- 保持语言简洁高效
- 可移植到不同平台

C语言的特点：

- 语法简洁，只有32个关键字
- 执行效率高，接近汇编
- 可移植性好，几乎所有平台都有C编译器
- 是C++、Java、Python等语言的基石

## 第一个程序

学习新语言的传统：写一个输出 "Hello, World!" 的程序。

```c
#include <stdio.h>

int main(void)
{
    printf("Hello, World!\n");
    return 0;
}
```

逐行解释：

```c
#include <stdio.h>
```
包含标准输入输出库。`printf` 函数就定义在这个库中。

```c
int main(void)
```
主函数，程序的入口。`int` 表示返回整数类型，`void` 表示不接收参数。

```c
printf("Hello, World!\n");
```
调用 `printf` 函数输出字符串。`\n` 是换行符。

```c
return 0;
```
返回0给操作系统，表示程序正常结束。

## 编译与运行

假设将上面的代码保存为 `hello.c`，编译运行步骤如下：

**编译：**

```bash
gcc hello.c -o hello
```

`-o hello` 指定输出文件名为 `hello`（Windows下会自动加 `.exe` 后缀）。

**运行：**

```bash
./hello      # Linux/Mac
hello        # Windows
```

输出：

```
Hello, World!
```

编译过程分几个阶段：

1. **预处理**：处理 `#include`、`#define` 等指令
2. **编译**：将源代码编译成汇编代码
3. **汇编**：将汇编代码汇编成目标文件
4. **链接**：将目标文件和库文件链接成可执行文件

日常开发中用 `gcc` 一条命令完成全部步骤即可，了解分阶段的意义在于调试时能定位问题发生在哪个阶段。

## 常见问题

**忘记分号**

C语言语句以分号结尾，忘记分号会报错：

```c
printf("Hello")   // 错误：缺少分号
```

编译器会提示语法错误，但提示的位置可能在下一行，因为编译器是读到下一行才发现问题。

**中文乱码**

如果输出中文乱码，通常是编码问题。Windows下源文件用GBK编码，或编译时加参数：

```bash
gcc -fexec-charset=GBK hello.c -o hello
```

**main函数的写法**

常见几种写法都是合法的：

```c
int main(void)    // 推荐：明确不接收参数
int main()        // 也合法：参数列表未显式声明
void main()       // 不推荐：非标准写法
```

推荐使用 `int main(void)`，符合C语言标准，返回值表示程序退出状态。
