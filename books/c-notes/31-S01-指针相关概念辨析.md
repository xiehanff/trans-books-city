# 指针相关概念辨析

指针是 C 语言的核心，但相关术语容易混淆。这里把常见概念放在一起对比。

## 核心区分方法

判断一个声明的关键：**看 `*` 和谁结合**。

```c
int *p;        // p 是指针，指向 int（指针变量）
int (*p);      // 同上，括号多余
int* p;        // 同上，写法不同
```

当有其他修饰符时，优先级变得重要：

| 优先级 | 运算符 | 结合性 |
|-------|--------|--------|
| 高 | `[]` `()` | 后缀 |
| 中 | `*` | 前缀 |
| 低 | 类型名 | - |

**口诀**：`[]` 和 `()` 优先级高于 `*`。

## 1. 指针数组 vs 数组指针

### 指针数组（Array of Pointers）

**本质**：一个数组，数组的每个元素都是指针。

```c
int *arr[5];     // arr 是数组，有 5 个元素，每个元素是 int*
```

解析：
1. `arr` 先和 `[5]` 结合 → `arr` 是长度为 5 的数组
2. 剩下 `int *` → 每个元素是 `int*` 类型

**典型用途**：字符串数组。

```c
char *names[3] = {
    "Alice",
    "Bob",
    "Carol"
};

for (int i = 0; i < 3; i++) {
    printf("%s\n", names[i]);
}
```

### 数组指针（Pointer to Array）

**本质**：一个指针，指向一个数组。

```c
int (*p)[5];     // p 是指针，指向一个长度为 5 的 int 数组
```

解析：
1. `(*p)` 先结合 → `p` 是指针
2. 剩下 `int [5]` → 指向的类型是"长度为 5 的 int 数组"

**典型用途**：遍历二维数组。

```c
int matrix[3][5] = {0};
int (*p)[5] = matrix;    // p 指向 matrix 的第一行

for (int i = 0; i < 3; i++) {
    for (int j = 0; j < 5; j++) {
        printf("%d ", p[i][j]);    // 等价于 *(*(p + i) + j)
    }
}
```

### 对比

| 声明 | 类型 | 含义 |
|-----|------|------|
| `int *arr[5]` | 指针数组 | 5 个 `int*` 元素的数组 |
| `int (*p)[5]` | 数组指针 | 指向 `int[5]` 的指针 |

```c
int a[5] = {1, 2, 3, 4, 5};

int *p1 = a;          // p1 指向 a[0]，类型是 int*
int (*p2)[5] = &a;    // p2 指向整个数组，类型是 int(*)[5]

printf("%d\n", *p1);           // 1
printf("%d\n", (*p2)[0]);      // 1
printf("%p %p\n", p1, p2);     // 地址值相同
printf("%p %p\n", p1+1, p2+1); // 地址值不同！p1+1 移动 4 字节，p2+1 移动 20 字节
```

## 2. 函数指针 vs 指针函数

### 指针函数（Function Returning Pointer）

**本质**：一个函数，返回值是指针。

```c
int *func(int a);    // func 是函数，返回 int*
```

解析：
1. `func(int a)` 先结合 → `func` 是函数，参数是 `int a`
2. 剩下 `int *` → 返回值是 `int*`

**示例**：

```c
int *create_int(int value) {
    int *p = malloc(sizeof(int));
    if (p) *p = value;
    return p;
}

// 使用
int *num = create_int(42);
printf("%d\n", *num);    // 42
free(num);
```

### 函数指针（Pointer to Function）

**本质**：一个指针，指向一个函数。

```c
int (*pf)(int);      // pf 是指针，指向"参数为 int、返回 int"的函数
```

解析：
1. `(*pf)` 先结合 → `pf` 是指针
2. `(int)` → 指向的函数参数是 int
3. 剩下 `int` → 返回值是 int

**示例**：

```c
int add(int a, int b) { return a + b; }
int sub(int a, int b) { return a - b; }

int (*op)(int, int);    // 函数指针

op = add;
printf("%d\n", op(3, 2));    // 5

op = sub;
printf("%d\n", op(3, 2));    // 1
```

### 函数指针数组

```c
int (*ops[4])(int, int) = {add, sub, mul, div};

int result = ops[0](10, 5);    // 调用 add(10, 5)
```

### 对比

| 声明 | 类型 | 含义 |
|-----|------|------|
| `int *func(int)` | 指针函数 | 函数，返回 `int*` |
| `int (*pf)(int)` | 函数指针 | 指针，指向函数 |
| `int (*ops[4])(int)` | 函数指针数组 | 4 个函数指针的数组 |

## 3. 字符串指针 vs 字符数组

### 字符串指针

```c
char *s = "Hello";    // s 指向字符串字面量
```

字符串字面量存储在**常量区**，不可修改。

```c
s[0] = 'h';    // 未定义行为，可能崩溃
```

### 字符数组

```c
char s[] = "Hello";    // s 是数组，内容在栈上或全局区
```

数组内容可以修改。

```c
s[0] = 'h';    // OK
```

### 对比

| 特性 | `char *s = "..."` | `char s[] = "..."` |
|-----|-------------------|-------------------|
| 存储位置 | 常量区 | 栈/全局区 |
| 可修改 | 否 | 是 |
| sizeof | 指针大小（4 或 8） | 数组大小（含 `\0`） |
| 可重新赋值 | `s = "other"` OK | 不行，数组名是常量 |

```c
char *s1 = "Hello";
char s2[] = "Hello";

printf("%zu %zu\n", sizeof(s1), sizeof(s2));    // 8 6（64 位系统）

s1 = "World";     // OK，s1 指向新的字面量
// s2 = "World";  // 错误，数组名不能赋值
```

### const 推荐用法

```c
const char *s = "Hello";    // 推荐写法，明确表示不可修改
```

## 4. const 与指针

`const` 位置不同，含义不同。

```c
const int *p;      // p 可变，*p 不可变（指向常量）
int const *p;      // 同上
int * const p;     // p 不可变，*p 可变（常量指针）
const int * const p;   // 都不可变
```

**记忆方法**：从右往左读。

```c
int * const p;     // p 是 const，*p 是 int
const int *p;      // p 是指针，指向 const int
```

**示例**：

```c
int a = 10, b = 20;

int * const p1 = &a;    // p1 不能指向其他地址
// p1 = &b;             // 错误
*p1 = 100;              // OK，a 变成 100

const int *p2 = &a;     // *p2 不能修改
p2 = &b;                // OK
// *p2 = 100;           // 错误
```

## 5. 多级指针

```c
int a = 10;
int *p = &a;        // 一级指针
int **pp = &p;      // 二级指针
int ***ppp = &pp;   // 三级指针（少见）
```

**典型用途**：函数内修改指针本身。

```c
void allocate(int **pp, int size) {
    *pp = malloc(size);
}

int *p = NULL;
allocate(&p, sizeof(int) * 10);
```

## 速查表

| 声明 | 名称 | 含义 |
|-----|------|------|
| `int *p[5]` | 指针数组 | 5 个 `int*` 的数组 |
| `int (*p)[5]` | 数组指针 | 指向 `int[5]` 的指针 |
| `int *f(int)` | 指针函数 | 返回 `int*` 的函数 |
| `int (*pf)(int)` | 函数指针 | 指向函数的指针 |
| `int (*pf[5])(int)` | 函数指针数组 | 5 个函数指针的数组 |
| `int *(*f)(int)` | 返回指针的函数指针 | 指向返回 `int*` 的函数的指针 |
| `char *s` | 字符串指针 | 指向字符串字面量 |
| `char s[]` | 字符数组 | 可修改的字符串 |
| `const int *p` | 指向常量的指针 | `*p` 不可修改 |
| `int * const p` | 常量指针 | `p` 不可修改 |

## 常见错误

### 混淆指针数组和数组指针

```c
int a[3][5];
int *p1[5] = a;     // 错误！类型不匹配
int (*p2)[5] = a;   // 正确
```

### 函数指针调用时漏写 *

```c
int (*pf)(int) = func;
int result = pf(10);      // OK，函数名本身就是地址
int result = (*pf)(10);   // 也 OK，更直观
```

### 字符串指针误修改

```c
char *s = "hello";
s[0] = 'H';    // 危险！
```

应改为：

```c
char s[] = "hello";
s[0] = 'H';    // 安全
```

### sizeof 误用

```c
char *s = "hello";
printf("%zu\n", sizeof(s));    // 指针大小，不是 6

char arr[] = "hello";
printf("%zu\n", sizeof(arr));  // 6，含 '\0'
```
