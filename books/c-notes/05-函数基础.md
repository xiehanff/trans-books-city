# 函数基础

函数是完成特定任务的代码块。把重复的逻辑封装成函数，可以在多处调用，避免代码重复。

## 函数的定义与调用

### 定义函数

函数定义包括返回类型、函数名、参数列表和函数体：

```c
// 计算两个整数的较大值
int max(int a, int b)
{
    return (a > b) ? a : b;
}
```

返回类型 `int` 表示函数返回一个整数。`void` 表示不返回值：

```c
void print_line(void)
{
    printf("--------------------\n");
}
```

### 调用函数

```c
int main(void)
{
    int result = max(10, 20);   // 调用max函数
    printf("较大值: %d\n", result);

    print_line();               // 调用无返回值函数

    return 0;
}
```

函数必须先声明或定义，才能调用。

## 函数原型声明

如果函数定义在调用之后，需要在调用前声明函数原型：

```c
// 函数原型声明
int max(int a, int b);

int main(void)
{
    int result = max(10, 20);   // 调用
    return 0;
}

// 函数定义
int max(int a, int b)
{
    return (a > b) ? a : b;
}
```

原型声明中的参数名可以省略：

```c
int max(int, int);    // 也合法
```

但保留参数名能提高可读性。如果函数没有参数，参数列表写 `void`：

```c
void print_line(void);    // 明确表示无参数
void print_line();        // 也合法，但不推荐
```

## 参数传递

### 值传递

C语言函数参数是值传递：实参的值复制给形参，形参的修改不影响实参。

```c
void increment(int n)
{
    n++;    // 只修改了形参n
}

int main(void)
{
    int a = 10;
    increment(a);
    printf("%d\n", a);    // 仍然是10
    return 0;
}
```

要在函数内修改外部变量，需要传递指针：

```c
void increment(int *n)
{
    (*n)++;    // 修改指针指向的值
}

int main(void)
{
    int a = 10;
    increment(&a);
    printf("%d\n", a);    // 11
    return 0;
}
```

### 数组作为参数

数组作为参数时，传递的是首元素地址：

```c
// 计算数组元素之和
int sum(int arr[], int len)
{
    int total = 0;
    for (int i = 0; i < len; i++) {
        total += arr[i];
    }
    return total;
}

int main(void)
{
    int nums[] = {1, 2, 3, 4, 5};
    int result = sum(nums, 5);
    return 0;
}
```

函数内修改数组元素会影响原数组，因为传递的是指针。`arr[]` 等价于 `*arr`：

```c
int sum(int *arr, int len)    // 等价写法
```

## 返回值

函数通过 `return` 返回值，返回值的类型必须与函数声明的返回类型一致或兼容。

```c
int add(int a, int b)
{
    return a + b;    // 返回int
}
```

返回类型为 `void` 的函数可以没有 `return`，或有空的 `return`：

```c
void greet(const char *name)
{
    if (name == NULL) {
        return;    // 提前返回
    }
    printf("Hello, %s!\n", name);
}
```

函数执行到 `return` 就结束，后面的代码不会执行。

### 返回指针

函数可以返回指针，但不能返回局部变量的指针：

```c
int* bad_function(void)
{
    int local = 10;
    return &local;    // 错误：返回了局部变量的地址
}
```

函数返回后，局部变量 `local` 已经失效，指针悬空。正确做法：

```c
int* create_value(int n)
{
    int *p = malloc(sizeof(int));    // 动态分配
    *p = n;
    return p;    // 返回动态内存的地址
}
// 调用者负责free
```

## 作用域规则

### 局部变量

在函数内部声明的变量是局部变量，只在声明点到函数结束之间有效：

```c
void func(void)
{
    int a = 10;    // a从这里开始有效
    // ...
}    // a到这里失效
```

不同函数的同名变量互不影响：

```c
void func1(void)
{
    int a = 1;
}

void func2(void)
{
    int a = 2;    // 不同的变量
}
```

### 全局变量

在所有函数外部声明的变量是全局变量，可以在整个程序中访问：

```c
int counter = 0;    // 全局变量

void increment(void)
{
    counter++;
}

int main(void)
{
    increment();
    printf("%d\n", counter);    // 1
    return 0;
}
```

全局变量默认初始化为0。局部变量不自动初始化。

同名时，局部变量会遮蔽全局变量：

```c
int a = 10;       // 全局

void func(void)
{
    int a = 20;   // 局部a遮蔽全局a
    printf("%d\n", a);  // 20
}
```

### 块作用域

C99允许在代码块内部声明变量：

```c
void func(void)
{
    int a = 10;
    {
        int b = 20;    // b只在这个块内有效
        printf("%d\n", a + b);
    }
    // b已经失效
}
```

for循环的初始化部分声明的变量只在循环内有效（C99）：

```c
for (int i = 0; i < 10; i++) {
    // i在循环内有效
}
// i失效
```

## 递归初步

函数可以调用自身，这就是递归。

### 递归基本结构

递归函数必须有两个部分：

1. 基准条件（终止条件）
2. 递推公式（调用自身）

计算阶乘：

```c
int factorial(int n)
{
    if (n <= 1) {
        return 1;    // 基准条件：0! = 1, 1! = 1
    }
    return n * factorial(n - 1);    // 递推：n! = n * (n-1)!
}
```

计算过程：

```
factorial(4)
= 4 * factorial(3)
= 4 * (3 * factorial(2))
= 4 * (3 * (2 * factorial(1)))
= 4 * (3 * (2 * 1))
= 4 * 3 * 2 * 1
= 24
```

### 递归示例：斐波那契数列

斐波那契数列：1, 1, 2, 3, 5, 8, 13, ...

```c
int fibonacci(int n)
{
    if (n <= 2) {
        return 1;    // 前两项都是1
    }
    return fibonacci(n - 1) + fibonacci(n - 2);
}
```

注意：这个实现效率很低，因为有大量重复计算。实际项目中应该用迭代或记忆化优化。

### 递归与栈

每次函数调用都会在栈上分配新的局部变量。递归层数过多会导致栈溢出：

```c
int recursive(int n)
{
    if (n <= 0) return 0;
    return recursive(n + 1);   // 永远达不到终止条件！
}
```

深层递归要考虑栈空间限制。可以用迭代替代时优先迭代。

## 函数设计建议

**单一职责**

一个函数只做一件事：

```c
// 不推荐：一个函数做多件事
void process(int arr[], int len, int *sum, int *max)
{
    *sum = 0;
    *max = arr[0];
    for (int i = 0; i < len; i++) {
        *sum += arr[i];
        if (arr[i] > *max) *max = arr[i];
    }
}

// 推荐：分开设计
int array_sum(int arr[], int len);
int array_max(int arr[], int len);
```

**参数数量**

参数过多说明函数职责可能不单一。一般不超过4个参数。

**避免全局变量**

全局变量增加了函数间的耦合。尽量通过参数传递数据。

## 常见问题

**忘记返回值**

```c
int get_value(void)
{
    int a = 10;
    // 忘记return a;
}
```

非void函数忘记返回值是未定义行为，编译器通常会警告。

**返回局部变量地址**

```c
int* func(void)
{
    int a = 10;
    return &a;    // 返回悬空指针
}
```

栈上的局部变量在函数返回后失效。

**递归无限循环**

```c
int bad_recursion(int n)
{
    return bad_recursion(n - 1);  // 没有终止条件
}
```

递归必须有终止条件，否则无限循环导致栈溢出。

**参数顺序错误**

```c
void draw_rect(int width, int height);

draw_rect(10, 20);  // width=10, height=20
draw_rect(20, 10);  // 宽高反了
```

调用时参数顺序必须和声明一致。清晰命名有助于减少这类错误。
