# 附录 B　变化中的格局

*Appendix B: A Changing Landscape*

Web 是一个动态的、不断变化的地方。1989 年诞生的第一个网页浏览器，既不支持颜色，也不支持图片、样式或脚本。随后的三十年间，市场力量、实现上的种种怪癖（implementation quirks），以及 Web 不断扩展的疆域，共同造就了今天的浏览器。这些力量一如既往地强大。浏览器仍在继续演进！

这本书迟早会过时。¹ 无论是 WebAssembly 还是 WebGPU，是硬件访问还是新的 CSS 特性，是集成支付还是 AI 助手，我都确信未来的浏览器将在计算和我们的生活中扮演许多全新的、不同的角色。

话虽如此，在 Web 的头三十年里，众多敬业而才华横溢的工程师为它倾注了心血。Web 的结构中凝结着他们的想法、发明和品味，也凝结着他们的价值观和对计算的期望。亲爱的读者，你我都追随着他们的足迹，研习着他们的工作。如果几年之后这本书过时了，我希望那些价值观得以延续，那些期望得以实现。

## 脚注

¹ 从某种意义上说，越快越好，因为那意味着 Web 正在继续蓬勃发展！
