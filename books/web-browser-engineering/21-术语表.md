# 术语表

*Glossary*

Web 浏览器理解起来可能相当令人困惑，尤其是当你考虑到它全部功能的广度时。与所有软件工程——实际上也与所有复杂学科——一样，避免困惑的最好办法就是使用清晰且一致的名称。

## 关键 Web 术语

**Accessibility**

任何人都能够访问和使用网页的能力——无论其自身能力如何，也无论用于实现这一目标的技术如何。

**Browser chrome**

浏览器的 UI，例如标签页或 URL 栏，不包括浏览器正在显示的网页本身。

**HTML**

HyperText Markup Language（超文本标记语言），一种类似 XML 的格式，用于描述网页。

**HTTP**

HyperText Transport Protocol（超文本传输协议），用于加载网页的网络协议。

**HTTPS**

HTTP 的一种变体，使用密码学来提供网络安全性。

**Hyperlink**

从一个网页指向另一个网页的引用。

**Hypertext**

一种非线性的信息形式，由多个通过上下文链接连接的文档组成。

**JavaScript**

Web 脚本的主要编程语言。

**Rendering engine**

Web 浏览器中负责将网页绘制到屏幕上并与之交互的部分。目前仍在积极维护的主流渲染引擎有三种：Chromium、WebKit 和 Gecko。

**Script**

一段为网页扩展更多功能的代码，通常用 JavaScript 编写。也是包含脚本的 HTML 标签的名称。

**URL**

Uniform Resource Locator（统一资源定位符），用于唯一地引用某个网页或资源的名称。

**Web**

WWW 的简化名称。

**Web browser**

允许人们加载和浏览网页的软件，通常也简称为“浏览器”（browser）。

**Web page**

Web 的基本单元；由一个返回 HTML 的唯一 URL 所定义。

**Web resource**

Web 上任何拥有自己 URL 的东西。网页是资源，但网页的许多组成部分（如脚本、图像和样式表）也是资源。不是 HTML 页面本身的资源称为子资源（subresource）。

**Web security**

有意限制 Web 浏览器、服务器或应用程序行为的能力，通常是为了防止伤害，无论这种伤害是否出于无意。安全有很多不同的方面：浏览器安全（使用户的计算机不会因其浏览器而受到损害）、Web 应用程序安全（使 Web 应用程序不会因其用户而受到损害）、隐私（使第三方无法伤害 Web 用户），以及许多其他方面。

**Website**

由多个网页构成的集合，共同提供某种用户服务。

**WWW**

World Wide Web（万维网）。指基于 HTTP、超链接、HTML、CSS 和 JavaScript 构建的网页网络，以及治理它们的开放且去中心化的规则的名称。

## 标准

**IETF**

Internet Engineering Task Force（互联网工程任务组）。HTTP 以及其他一些 API 的标准化组织。

**Khronos**

Khronos Group（Khronos 集团）。WebGL 和 WebGPU 的标准化组织。

**TC39**

Technical Committee 39（第 39 技术委员会）。JavaScript 的标准化组织。

**W3C**

World Wide Web Consortium（万维网联盟）。WWW 的核心标准化组织。除许多其他 API 外，CSS 就是在这里标准化的。

**WHATWG**

Web Hypertext Application Technology Working Group（Web 超文本应用技术工作组）。HTML、DOM 以及其他一些关键 Web API 的标准化组织。

## Web 文档

**Animation**

计算机屏幕上一系列被人眼解读为运动的视觉变化。

**CSS**

Cascading Style Sheet（层叠样式表）。一种格式，用于表示指定 DOM 中元素（主要是视觉方面）样式的规则。

**Document**

加载网页时创建、并通过与之交互而修改的概念对象，是对物理文档的类比。

**DOM**

Document Object Model（文档对象模型）。供 JavaScript 修改文档的面向对象 API 接口。它尤其包含一棵节点树；这棵树最初对应于 HTML 的嵌套结构。

**Element**

HTML 树中的大多数节点都是元素（文本节点和文档对象除外）。

**Event**

JavaScript 用来观察文档上发生了某件事并自定义其结果的一种方式。

**Focus**

元素（有时在网页中，有时在浏览器 chrome 中）被设定为接收后续键盘事件和其他用户交互的特性。通常，获得焦点的元素会在屏幕上以视觉方式高亮显示。

**HTML tree**

解析 HTML 后创建的树。有时也称为 DOM。

**Font**

将某种特定人类语言绘制到计算机屏幕上的一种特定风格的方式。Times New Roman 是基于拉丁字母语言的一个常见例子。

**HTML attribute**

元素上的一个参数，用于表明某种信息，例如图像的来源或样式表的 URL。

**Iframe**

将一个文档嵌入另一个文档中的一种方式。父文档中的一个矩形窗口显示子文档，并参与父文档的布局。

**Image**

要绘制到计算机屏幕上的图片的一种表示。

**Node**

DOM 树中的一个点，带有指向父节点和子节点的指针。

**Page**

文档的概念容器。一个页面可以通过 iframe 拥有多个文档。

**Parsing**

将序列化的表示形式（如 HTML 或 CSS）转换为数据结构（如文档树或样式表）的过程。

**Style sheet**

包含 CSS 规则的 Web 资源。

**Tag name**

某一特定类型 HTML 元素的名称，表明其在文档中的语义功能。通常带有专属于它的特殊样式规则和功能。

## 网络

**Cookie**

由 Web 浏览器存储的持久化、按站点区分的状态，用于支持诸如用户登录访问受控内容之类的用例。

**Domain**

网站的名称，用于在互联网上定位它。

**GET**

HTTP 的一种模式，用于获取服务器资源而不修改它。

**Path**

URL 中位于域名和端口之后的部分。

**Port**

URL 中位于域名之后、路径之前的数字，表示该域名上用于通信的一个编号位置。

**POST**

HTTP 的一种模式，用于提交对服务器状态的更改，并期望在响应中返回一个新更新的网页。

**Scheme**

URL 的第一部分，表明通信要使用的协议，例如 HTTP 或 HTTPS。

**TLS/SSL**

Transport Layer Security（传输层安全）和 Secure Sockets Layer（安全套接字层）。一种加密协议，HTTP 等其他协议可以在其之上安全地进行（即 HTTPS）。TLS 是取代 SSL 的较新协议，但 SSL 一词常被用来统称两者。

## CSS

**Cascade order**

多条 CSS 规则应用到单个元素上的顺序。

**Computed style**

按照层叠顺序应用所有规则后，作用于元素的各 CSS 属性的值。

**CSS property**

用于设置元素某一特定方面样式的单个概念（如 color 或 width）。

**CSS property–value**

一个 CSS 属性及其值的键–值对（例如 color 和 blue，或 width 和 30px）。

**CSS rule**

CSS 选择器和 CSS 属性值的组合。

**CSS selector**

CSS 规则中指定给定属性值列表将应用于哪些元素的部分。

**Inheritance**

元素的某个属性的计算样式取自其父元素。有时会被误称为“层叠”（cascading）。某些 CSS 属性（如字号）默认是继承的。

**Style**

确定元素视觉显示所需的全部信息。也是用于指定内联样式的相应属性的名称。

## 坐标空间

在浏览器中，2D 坐标空间用来确定元素彼此之间、相对于网页以及相对于屏幕的位置。这些坐标系大多采用标准的 x、y 方向，只是原点不同——但也并非全部如此。¹

**Element**

该坐标系的原点位于元素布局边界的左上角；如果使用了外边距或定位，这个左上角可能位于视口的上方或左侧之外。

**Layer**

该坐标系的原点位于合成层的左上角；合成层的选取方式是使其包含该层内的全部绘制对象。

**Page**

该坐标系的原点位于网页根元素的左上角。当网页滚动时，这个左上角可能移出视口顶部。

**Paint**

该坐标系的原点位于元素绘制边界的左上角；如果使用了 translate 之类的变换，它可能与元素坐标系不一致。真实浏览器还支持 rotate 等更复杂的变换。

**Viewport**

该坐标系的原点位于屏幕上用于绘制网页的矩形的左上角。

> ¹ 有些逻辑坐标系会根据语言书写模式的方向翻转 x 和 y 的方向。例如，在阿拉伯语中，x 向左增长是合理的，原点通常位于右上角而非左上角。当嵌套、包含块、滚动和定位组合使用时，这一点会变得令人困惑。

## 渲染

**Accessibility tree**

表示网页语义含义的树，供辅助技术使用。

**Canvas**

一个可以执行绘制命令的概念对象；也是一个用途相同的同名 Web API。通常以 surface 作为底层支撑。

**Compositing**

浏览器渲染管线中的一个阶段，将显示列表切分为适合渲染到 GPU 上各个独立 surface 的片段，以加速动画。

**Decode**

将资源的压缩格式（如图像）转换为内存中更简单的格式（如位图）。

**Device pixel ratio**

屏幕像素分辨率与“典型”屏幕（定义为 20 世纪 90 年代 CRT 显示器的像素分辨率）之比。

**Display list**

一串解释如何将网页绘制到计算机屏幕上的图形命令。

**Draw**

浏览器渲染管线中的一个阶段，将一组 surface 以不同的位置和视觉效果呈现到屏幕上。

**Event loop**

在接收用户输入与向屏幕绘图之间交替进行的循环。

**Hit testing**

确定屏幕上给定像素位置处是哪个元素或无障碍树节点。

**Invalidation**

将某些渲染状态标记为不再有效，因为其输入依赖发生了变化。

**Layout**

浏览器渲染管线中的一个阶段，确定 DOM 中各元素的尺寸和位置。

**Layout tree**

与 DOM 相对应的第二棵树，区别在于它表示布局管线阶段的输出。

**Paint**

浏览器渲染管线中的一个阶段，从 DOM 创建显示列表。

**Raster**

通过为 surface 的像素着色来执行显示列表的过程。

**Rendering pipeline**

浏览器将网页绘制到计算机屏幕上所经过的一系列阶段。

**Scroll**

响应用户输入而调整网页的水平或垂直偏移，以便查看当前不可见的部分。

**Style**

浏览器渲染管线中的一个阶段，应用 CSS 规则以确定 DOM 中元素的视觉外观和行为；也指该阶段之后应用到元素上的一组 CSS 属性。

**Surface**

GPU 中的一个缓冲区或纹理，表示一个由像素组成的二维数组。

**Visual effect**

不影响布局的 CSS 属性。

**Zoom**

更改 CSS 尺寸与像素之间的比率，以放大或缩小网页上的内容。

## 计算机技术

**Assistive technology**

用于帮助人们使用计算机或 Web 浏览器的计算机软件。最常见的是屏幕阅读器。

**CPU**

中央处理器（central processing unit），计算机中执行通用计算程序的硬件组件。

**DukPy**

Duktape（本书使用的 JavaScript 引擎）的 Python 绑定库。

**GPU**

图形处理器（graphics processing unit），一种针对在计算机屏幕上生成像素输出等任务优化的专用计算芯片。

**Process**

一个拥有自己的代码和内存的概念性执行环境，通过硬件和软件的计算机机制与其他进程隔离。

**Python**

一种常见的计算机编程语言，本书用它实现一个玩具浏览器。

**SDL**

一个供计算机程序使用的窗口库，在本书后面的章节中使用。

**Skia**

一个供计算机程序使用的光栅绘制库，在本书后面的章节中使用。

**Thread**

在 CPU 上执行的单个命令序列。如今大多数 CPU 都能同时执行多个线程。

**Tk**

一个供计算机程序使用的 UI 绘制库，在本书前面的章节中使用。

**Tkinter**

封装 Tk 的 Python 库。
