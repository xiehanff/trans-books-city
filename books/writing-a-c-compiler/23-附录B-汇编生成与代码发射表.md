# 附录 B　汇编生成与代码发射表

*Appendix B: Assembly Generation and Code Emission Tables*

在每一章中，只要我们更新了从 TACKY 到汇编的转换或代码发射遍，我都会附上总结这些遍的表格。从第 4 章开始，这些表格只展示该章所做的改动，而不是完整的遍。本附录给出第 I 部分、第 II 部分和第 III 部分结束时总结这些遍的完整表格。

## 第一部分

本节的第一组表格展示在第 I 部分结束时，你的编译器应如何把每个 TACKY 构造转换为汇编；第二组表格展示在第 I 部分结束时，你的编译器应如何发射每个汇编构造。
