# 分支语句

程序通常按代码顺序逐行执行，但有时需要根据条件选择不同的执行路径，这就需要分支语句。

## if 语句

`if`语句根据条件决定是否执行某段代码。条件为真（非0）则执行，为假（0）则跳过。

```c
int score = 85;
if (score >= 60) {
    printf("及格\n");
}
```

如果语句块只有一行，花括号可以省略，但建议始终使用花括号，避免后续添加语句时出错。

```c
if (score >= 60)
    printf("及格\n");  // 可行，但不推荐

if (score >= 60)
    printf("及格\n");
    printf("不错\n");  // 这行总是会执行，缩进骗人
```

## if-else 语句

`if-else`提供两个分支，条件为真执行`if`块，为假执行`else`块。

```c
int score = 55;
if (score >= 60) {
    printf("及格\n");
} else {
    printf("不及格\n");
}
```

## else if 链

多个互斥条件可以用`else if`串联，从上往下依次判断，遇到第一个满足的条件后不再继续。

```c
int score = 75;
if (score >= 90) {
    printf("优秀\n");
} else if (score >= 80) {
    printf("良好\n");
} else if (score >= 60) {
    printf("及格\n");
} else {
    printf("不及格\n");
}
```

条件顺序很重要。下面写法有问题，`score >= 60`会匹配所有及格的情况：

```c
if (score >= 60) {
    printf("及格\n");      // 90分也会进这里
} else if (score >= 80) {
    printf("良好\n");      // 永远不会执行
}
```

## switch 语句

`switch`根据一个整型表达式的值选择分支，适合多值匹配的场景。

```c
int day = 3;
switch (day) {
    case 1:
        printf("周一\n");
        break;
    case 2:
        printf("周二\n");
        break;
    case 3:
        printf("周三\n");
        break;
    default:
        printf("其他\n");
}
```

`switch`的几点规则：

- 表达式必须是整型或字符型
- `case`后面必须是常量表达式
- `break`用于跳出switch，否则会继续执行下一个case（称为"穿透"）
- `default`处理所有未匹配的情况，放在最后

穿透特性的一个应用：

```c
char c = 'a';
switch (c) {
    case 'a':
    case 'e':
    case 'i':
    case 'o':
    case 'u':
        printf("元音\n");
        break;
    default:
        printf("辅音\n");
}
```

## 条件运算符 ?:

条件运算符是C语言唯一的三元运算符，格式为`条件 ? 真值 : 假值`。

```c
int a = 10, b = 20;
int max = (a > b) ? a : b;  // max = 20
```

可以嵌套使用，但可读性会变差：

```c
int score = 75;
char* level = score >= 90 ? "优秀" : score >= 60 ? "及格" : "不及格";
```

## 常见问题

**悬空else**：多层嵌套时，`else`总与最近的未配对`if`匹配。

```c
if (a > 0)
    if (b > 0)
        printf("ab\n");
else
    printf("else\n");  // 这个else属于内层if
```

用花括号明确边界：

```c
if (a > 0) {
    if (b > 0) {
        printf("ab\n");
    }
} else {
    printf("else\n");  // 现在属于外层if
}
```

**赋值与比较混淆**：`=`是赋值，`==`是比较。

```c
if (x = 5) { ... }   // 把5赋给x，然后判断x是否非0（总是真）
if (x == 5) { ... }  // 判断x是否等于5
```

有些程序员习惯把常量写在左边：

```c
if (5 == x) { ... }  // 如果写成 5 = x 会编译报错
```
