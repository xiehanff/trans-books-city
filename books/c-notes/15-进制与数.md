# 第15章 计算机中的数与进制

计算机只认识 0 和 1，所有数据最终都以二进制形式存储。理解进制转换和数值表示，是理解计算机如何处理数据的基础。

## 进制基础

### 十进制

日常生活中使用的进制，基数为 10，每位的权是 10 的幂次。

```
1234 = 1×10³ + 2×10² + 3×10¹ + 4×10⁰
```

### 二进制

计算机内部使用的进制，基数为 2，每位的权是 2 的幂次。

```
1011 = 1×2³ + 0×2² + 1×2¹ + 1×2⁰ = 8 + 0 + 2 + 1 = 11（十进制）
```

C 语言里 `0b` 或 `0B` 二进制字面量在 C23 中正式加入标准；在更早版本里，很多编译器也提供了扩展支持：

```c
int a = 0b1010;  // 10
int b = 0B1111;  // 15
```

### 八进制

基数为 8，使用数字 0-7。C 语言中八进制字面量以 `0` 开头：

```c
int a = 012;  // 八进制 12，等于十进制 10
int b = 0755; // 八进制 755，等于十进制 493
```

注意：写代码时不要不小心在数字前加 `0`，会被当作八进制处理。

```c
int x = 010;  // 你以为是 10，实际是 8
```

### 十六进制

基数为 16，使用数字 0-9 和字母 A-F（或 a-f）。C 语言中十六进制字面量以 `0x` 或 `0X` 开头：

```c
int a = 0x1F;   // 31
int b = 0xFF;   // 255
int c = 0xDEAD; // 57005
```

十六进制常用于表示内存地址、颜色值、字节内容等。

## 进制转换

### 二进制转十进制

从右向左，每位乘以 2 的相应幂次，再求和。

```
1101 = 1×2³ + 1×2² + 0×2¹ + 1×2⁰
     = 8 + 4 + 0 + 1
     = 13
```

### 十进制转二进制

除 2 取余法：不断除以 2，记录余数，直到商为 0，余数倒序排列。

```
13 ÷ 2 = 6 ... 1
6  ÷ 2 = 3 ... 0
3  ÷ 2 = 1 ... 1
1  ÷ 2 = 0 ... 1

13 的二进制是 1101
```

### 二进制与十六进制互转

每 4 位二进制对应 1 位十六进制，这是最常用的转换方式。

```
二进制:  1101 0110 1011
十六进制:   D    6    B

验证: 0xD6B = 13×16² + 6×16 + 11 = 3435
```

十六进制转二进制同理，每位十六进制展开为 4 位二进制。

### 二进制与八进制互转

每 3 位二进制对应 1 位八进制。

```
二进制:  1 101 011
八进制:  1   5   3

验证: 0153 = 1×8² + 5×8 + 3 = 107
```

## 原码、反码、补码

计算机中表示有符号整数有三种编码方式。

### 原码

最高位为符号位（0 正 1 负），其余位表示数值的绝对值。

```
+5 的原码: 00000101（假设 8 位）
-5 的原码: 10000101
```

原码的问题：
- 0 有两种表示：`00000000` 和 `10000000`
- 运算复杂，符号位需要单独处理

### 反码

正数的反码与原码相同。负数的反码：符号位不变，数值位按位取反。

```
+5 的反码: 00000101
-5 的反码: 11111010
```

反码的问题：
- 0 仍有两种表示：`00000000` 和 `11111111`
- 运算仍需处理循环进位

### 补码

现代计算机普遍采用补码表示有符号整数。

正数的补码与原码相同。负数的补码：反码 + 1。

```
+5 的补码: 00000101
-5 的补码: 11111011
```

另一种理解：负数 -x 的补码等于 2^n - x（n 为位数）。

以 8 位为例，-5 的补码 = 2⁸ - 5 = 256 - 5 = 251 = 11111011

补码的优点：
- 0 只有唯一表示：`00000000`
- 加减法统一，符号位参与运算

```c
// 用补码计算 5 + (-5)
//  00000101
// +11111011
// ----------
// 100000000  -> 溢出，保留 8 位为 0
```

## 有符号数与无符号数

### 范围

以 8 位为例：

| 类型 | 范围 | 说明 |
|------|------|------|
| unsigned char | 0 ~ 255 | 0 ~ 2⁸-1 |
| signed char | -128 ~ 127 | -2⁷ ~ 2⁷-1 |

一般形式（n 位）：
- 无符号：0 ~ 2ⁿ - 1
- 有符号：-2ⁿ⁻¹ ~ 2ⁿ⁻¹ - 1

### 类型转换

有符号数与无符号数混合运算时，有符号数会被转换为无符号数。

```c
int a = -1;
unsigned int b = 1;

if (a < b) {
    printf("a < b\n");
} else {
    printf("a >= b\n");  // 实际输出这个
}
```

-1 转换为无符号数是一个很大的正数（所有位都是 1），所以比较结果出人意料。

建议：避免有符号数与无符号数直接比较，容易埋坑。

### 溢出

无符号数溢出会回绕：

```c
unsigned char x = 255;
x = x + 1;  // x 变成 0，不会报错
```

有符号数溢出是未定义行为：

```c
signed char x = 127;
x = x + 1;  // 未定义行为，可能得到 -128，也可能崩溃
```

## 浮点数表示（IEEE 754）

计算机中浮点数基于 IEEE 754 标准，采用科学计数法形式存储。

### 单精度浮点数（float）

占用 32 位，分三部分：

```
| 符号位(1位) | 指数(8位) | 尾数(23位) |
|     S       |    E      |     M      |
```

- 符号位 S：0 为正，1 为负
- 指数 E：采用偏移表示，实际指数 = E - 127
- 尾数 M：省略最高位的 1（隐含位），实际有效位为 24 位

值 = (-1)^S × 1.M × 2^(E-127)

数值 `12.375` 的存储过程：

```
1. 转二进制: 12.375 = 1100.011 = 1.100011 × 2³
2. 提取各部分:
   - S = 0（正数）
   - E = 3 + 127 = 130 = 10000010
   - M = 100011...（补零到 23 位）
3. 最终存储: 0 10000010 10001100000000000000000
```

### 双精度浮点数（double）

占用 64 位：

```
| 符号位(1位) | 指数(11位) | 尾数(52位) |
|     S       |     E      |     M      |
```

指数偏移值为 1023，实际指数 = E - 1023。

### 特殊值

- 正零/负零：指数和尾数全为 0，符号位区分
- 无穷大（Infinity）：指数全 1，尾数全 0
- NaN（Not a Number）：指数全 1，尾数非 0

```c
#include <math.h>
#include <stdio.h>

int main() {
    float a = 1.0f / 0.0f;   // 正无穷
    float b = -1.0f / 0.0f;  // 负无穷
    float c = 0.0f / 0.0f;   // NaN

    printf("%f %f %f\n", a, b, c);  // inf -inf nan

    printf("isinf(a) = %d\n", isinf(a));   // 1
    printf("isnan(c) = %d\n", isnan(c));   // 1

    return 0;
}
```

### 精度问题

浮点数不能精确表示所有十进制小数。

```c
float x = 0.1f;
printf("%.20f\n", x);  // 0.10000000149011611938
```

比较浮点数应该使用误差范围：

```c
// 错误方式
if (x == 0.1) { ... }

// 正确方式
if (fabs(x - 0.1) < 1e-6) { ... }
```
